## ٣. `StorePricing` — معادلة السعر الفعلية ✅

الملف: `cpp2il-cs-full/KammenlaAssembly/StorePricing.cs` — مُستعاد بالكامل.

```csharp
// @0x4FF47D8
public static int EffectivePrice(this StoreItem item)
    => item.virtualPrice - DiscountAmount(item);                     // ✅ حرفيًا

// @0x4FF6EA0
public static int TotalPrice(this StoreItem item, int recipients)
    => (item.virtualPrice - DiscountAmount(item)) * recipients;      // ✅ حرفيًا

// @0x4FF6CAC  ← آلية الخصم الوحيدة في اللعبة
public static int DiscountAmount(this StoreItem item) {
    var me = SFS.MySelf;
    if (me == null)                                  return 0;
    if (!SFSKammelnaUserExtensions.IsSubscribed(me)) return 0;       // ← الخصم للمشتركين فقط
    var cfg = RemoteConfig.Current;
    if (cfg?.SubscriberCategoryDiscounts == null || item == null) throw NullReference;
    if (!cfg.SubscriberCategoryDiscounts.TryGetValue(item.category, out int pct)) return 0;
    if (pct < 1)                                     return 0;
    return (int)Math.Floor(item.virtualPrice * pct / 100.0);         // FRINTM = floor
}
```

**تفاصيل تثبت القراءة:** الثابت `4636737291354636288L` في الشفرة المفكوكة = `0x4059000000000000` = **`100.0` double** بالضبط، والتعليمة المذكورة `FRINTM` = تقريب نحو −∞ = **floor**. والثابت `9218868437227405312L` = `0x7FF0000000000000` = `+∞` (فحص تحويل float→int).
