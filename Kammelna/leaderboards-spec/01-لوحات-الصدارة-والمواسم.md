## ١. ⭐ شجرة `ILeaderboardSource` — ١٥ مصدرًا ملموسًا

```
ILeaderboardSource
└── BaseLeaderboardSource
    ├── SfsLeaderboardSource            ← أوامر SmartFox
    │   ├── BombersLastWeek / Overall / LastThreeMonths
    │   ├── TournamentCurrentMonth / LastMonth
    │   └── MassTournamentStage
    ├── JsonLeaderboardSource           ← ملفات JSON ثابتة على BlobHost
    │   ├── RankedWeekly / RankedMonthly / RankedOverall
    │   └── PredictionsCurrent
    ├── ClanInternalLeaderboardSource   ← HTTP REST
    │   └── ClanRankedGames / ClanTournaments / ClanContribution
    └── FriendsLeaderboardSource        ← HTTP REST
        └── FriendsPoints / FriendsTournamentPoints
```

**عقد الواجهة**: `Name` · `Title` · `IsLive` · `IsGameDependent` · `Load(…)` · `GetMyRanking(cb)` ·
`GetETag()` · `SetETag(s)` · `GetCacheFilePath()`.

| المصدر | القناة | معاملات |
|---|---|---|
| `Bombers*` | SFS **`cbl`** (zone) | `{ lbt: 0\|1\|2 }` |
| `Tournament{Current,Last}Month` | SFS **`mtlb`** | `{ ty: 0\|1 }` |
| `MassTournamentStage` | SFS **`mlb`** (**غرفة**) | `{ stg }` |
| `Ranked{Weekly,Monthly,Overall}` | GET `{BlobHost}leaderBoards/{game}/top*.json` | `If-None-Match` |
| `PredictionsCurrent` | GET `{BlobHost}leaderBoards/PredictionSeason/current_season.json` | ↑ |
| `Clan*` | GET `api/Clans/leaderboards/internal/{kind}` | `?game=&clanId=` |
| `Friends*` | GET `api/Friend/GetFriendsLeaderboard` | `?game=` |

> 🛑 **تصحيح لـ[الاجتماعي ٠٣](../social-spec/03-العشائر-والإشراف.md)**: `kind` **جزء من المسار**
> `internal/{kind}` لا معامل استعلام؛ ومعاملات الاستعلام هي `game` و`clanId` فقط.
>
> 🛑 **تصحيح لـ[الاجتماعي ٠١](../social-spec/01-المعمارية-والدردشة.md)**: `cbl` **أمر واحد**
> يُميَّز بـ`lbt` لا ثلاثة أوامر.

### سلوك `Load` ✅

* **`SfsLeaderboardSource.Load`** @`0x4F2BABC`: إن كان `IsAvailableForCurrentGame == false`
  **يُرجع لوحة فارغة فورًا بلا أي طلب شبكة**. و`TournamentCurrentMonth`/`LastMonth` تتجاوزانها بـ
  `CurrentGame == Baloot` ⇒ ⭐ **بطولات كملنا الشهرية في البلوت فقط**.
* **الرد**: `error` · **`sta`** (⭐ **`304` ⇒ استعمل الكاش** — نمط *Not Modified*) · `d` (الصفوف).
* **`JsonLeaderboardSource.Load`** @`0x4F2A15C`: `Config.BlobHost + GetWebPath()` بترويسة
  **`If-None-Match`** ⇒ ⭐ **لوحات الترتيب المصنّفة ملفات ثابتة على CDN لا API حيّ**.
* **`ClanInternal*`**: `GetCacheFilePath` يُرجع **`null`** ⇒ **لا كاش على القرص للعشائر**.

## ٣. ⭐ المواسم — نفي صارم

> **لا يوجد في العميل أي مؤقّت أو مقارنة تاريخ لتدوير أسبوع/شهر/موسم.** ✅

الأدلّة:
1. لا تواريخ بداية/نهاية في أي نموذج لوحة. `PredictionSeasonModel` يحمل `Description` + `Image` + `Rewards` **بلا تواريخ**.
2. **أسماء ملفات JSON غير مُمَعلمة بالتاريخ** — الخادم يعيد توليد نفس الملف، والعميل يكتشف التغيّر بـ`ETag` فقط.
3. نقاطي ورتبتي تصل جاهزة في `PlayerProfileModel.ranking`.
4. `mte` متغيّر مستخدم يدفعه الخادم.
5. الأثر التقويميّ الوحيد: `firstDayOfTheMonth` بصيغة `yyyy-MM-dd` في طلب لوحة الدواوين — **إدخال لا قرار**.

**«الموسم» ثلاثة أشياء مختلفة، كلها خادمية**:

| النوع | الدورة |
|---|---|
| النقاط المصنّفة | أسبوع / شهر / تراكمي |
| بطولات كملنا (الدوري) | **شهري** (`mtlb ty:0\|1`) |
| موسم التوقّعات | مُعرَّف خادميًّا بلا مدّة معروفة للعميل |

### الكؤوس الشهرية ✅

`GetTrophyAsset` @`0x371E4CC`:
```csharp
if (id == "monthly_ranker") return ranker;
if (1 <= levelId <= 4) return assets[levelId-1];   // platinum, gold, silver, bronze
```
⇒ ⭐ **`levelId` في كأس شهريّ = فئة البطولة** بنفس ترقيم `MonthlyTournamentEligibilityType`.

🟡 `monthly_winner` = المركز الأول و`monthly_second` = الوصيف **لكل فئة** (يدعمه `Take(2)`).
🟡 `monthly_ranker` مرتبط بالترتيب لا بالبطولة.

## ٤. `MonthlyTournamentEligibilityType` — محسوم ✅

```csharp
enum MonthlyTournamentEligibilityType { NotEligible=0, Platinum=1, Gold=2, Silver=3, Bronze=4 }
enum TournamentSubType               { Platinum=0, Gold=1, Silver=2, Bronze=3 }

// ToTournamentSubType @0x5035110
if ((uint)(type - 1) <= 3) return (TournamentSubType)(type - 1);
return null;                                   // NotEligible
```

المصدر: متغيّر المستخدم **`mte`** (`GetMonthlyTournamentEligibility` @`0x4ED002C`) —
**يحسبه الخادم ويدفعه**، ويُربط حيًّا عبر `VariableBinderExtensions.Bind(…, "mte", …)`.

`IsOverQualified` @`0x50351A0` يمنع النزول لبطولة أدنى ⚪ «أنت مؤهل لبطولة ذات مستوى أعلى».

**العتبات** ⚪ (نصّ التطبيق — الحساب خادميّ، **لا كود يطبّقها**):
بلاتينية **١–٦٤** · ذهبية **٦٥–١٢٨** · فضية **١٢٩–١٩٢** · برونزية **١٩٣–٢٥٦**.

`Prefs["MonthlyTournamentEligibilityType"]` يحفظ آخر فئة، ويُمسح **فقط** عند `SFS.Logout`.

## ٦. الكاش والـETag ✅

```csharp
ETagKey = IsGameDependent ? $"ETag_LeaderBoard_{Name}_{CurrentGame}" : $"ETag_LeaderBoard_{Name}";
CacheFilePath = IsGameDependent ? $"{CachePath}leaderBoards/{CurrentGame}/{Name}.json"
                                : $"{CachePath}leaderBoards/{Name}.json";
```
كاش الذاكرة `LeaderboardsCache` مفتاحه `source.Name`، ويُقرأ **فقط عندما `!IsLive`**.
استثناءان يُرجعان `null` لمسار القرص: `ClanInternal*` و`MassTournamentStage`.

`TopPlayersList.OnEnable`: `IsLive` ⇒ إعادة جلب كل فتح؛ وإلا اعرض المخزَّن.

> ⚠️ `LeaderBoardUI.leaderboardSources` معلَّم `[SerializeReference]` ⇒
> **ترتيب التبويبات مُعدّ في مشاهد Unity لا في الكود.**

## ٧. الجوائز ✅

`PredictionSeasonRewardModel` — **جدول الجوائز الرقميّ الوحيد الصريح في العميل**:

⇒ الجوائز **نطاقات مراكز `[place, place2]`** يعرّفها الخادم.

## ٨. ما لم يُحسَم 🟡

1. هل `monthly_winner`/`monthly_second` لكل فئة أم للعليا فقط؟
2. معيار منح `monthly_ranker` بالضبط.
3. مدّة/حدود موسم التوقّعات.
4. ~~إزاحات الإسناد داخل `TournamentCurrentMonth/LastMonth.GetMyRanking`.~~ ✅ جدول `TournamentRankingModel`
   كامل (٢٧ سبتمبر). ⭐ 🛑 **`secondLastMonthRank @0x24` هو الحقل نفسه في التبويبين** ⇒ تبويب «الشهر الحالي»
   يقارن رتبتك **برتبة قبل شهرين لا بالشهر الماضي**؛ ولا يُسنَد `MonthlyWinningTier` ولا `Points` من نموذج البطولة.
5. ~~ترتيب تبويبات `LeaderBoardUI`.~~ ✅ **١٣ نسخة** في ٧٥٨ حزمة، بترتيباتها من `references.RefIds`.
   🛑 ترتيب تبويبات `Bombers` = `lbt 0 → 2 → 1` (لا يتبع الـenum). ونفيٌ مفيد: مصادر العشائر و`MassTournamentStage`
   **لا تظهر في أيّ `LeaderBoardUI`**.
6. بقيّة قيم `sta` عدا `304`.
