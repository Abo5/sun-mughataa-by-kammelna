## ١. `GetNearestFTAwardStage` @`0x50B1DA8` (560B) ✅

```csharp
int[] GetNearestFTAwardStage(int points = -1) {
    if (points == -1) points = SFS.MySelf.GetRank().Points;   // ldr w19,[x0,#0x18] @0x50B1E3C
    for (levelIdx = 0; levelIdx < FastTrack.LevelStages.Count; levelIdx++)
        foreach (stage in LevelStages[levelIdx])
            if (points < stage)                               // cmp w19,w0 ; b.lt @0x50B1F34
                return new[] { levelIdx + 1, stage };         // ترقيم ١-أساس في الخانتين
    return new[] { -1, -1 };                                  // 0x50B1FA8
}
```

| الحقيقة | التفصيل |
|---|---|
| **`-1` سنتينل لا قيمة** | و**كلّ المستدعين العشرة يمرّرون `-1` حرفيًّا** (`mov w0,#-1` في العشرة) ✅ |
| 🛑 **معيار «الأقرب»** | **ليس أقرب مسافة** — بل **أوّل عتبة في مسحٍ متسلسل (مستوى ثمّ مرحلة) تكون أكبر من النقاط تمامًا**. والمساواة تُعَدّ محقَّقة ⇒ من بلغ العتبة بالضبط يُدفَع إلى ما بعدها |
| **الترقيم** | `arr[0] = levelIdx + 1` · `arr[1] = stage` — **١-أساس في الخانتين** |
| **أدنى قيمة** | `{1,1}` |
| **مستوى فارغ** | يُقفَز بلا استثناء |
| **تجاوز آخر مرحلة** | **`{-1,-1}`** — تعامل معها في الواجهة |
| 🚩 **بلا حراسة** | `RemoteConfig`/`FastTrack`/`LevelStages` معدومًا ⇒ **`NullReferenceException`** |
| 🟡 **تنفيذٌ مزدوج** | كلّ مستدعٍ ينادي الدالّة **مرّتين** (واحدةً لكلّ خانة) ⇒ احتمال خانتين من جدولين مختلفين لو تغيّر الإعداد بينهما |

## ٢. `RemoteConfig.Current.FastTrack` ✅ — البانِي @`0x5186F04` (1864B)

| الحقل | الإزاحة | الافتراضيّ المخبوز |
|---|---|---|
| `TicketPrice` | `+0x10` | **٨٥** |
| `MaxWaitingTimeSeconds` | `+0x14` | **١٠** |
| `LevelStages` | `+0x18` | `List<List<int>>` |
| `MatchMakerTimerSeconds` | محسوبة | **١٥** = `MaxWaitingTimeSeconds + 5` (`0x5187B1C`) |

الأوّلان يُقرآن معًا من `ldr d0, [0x7253208]` حيث البايتات `55 00 00 00 0a 00 00 00` ✅
(⇒ `0x55 = 85` و`0x0A = 10`) — وهذا نمط جداول الثوابت المعروف في هذا الثنائي.

### العتبات المخبوزة
| المستوى | العتبات |
|---|---|
| **١** (٦) | `1001` · `2501` · `4001` · `6001` · `8001` · **`10500`** |
| **٢** (٨) | `12501` · `15001` · `17501` · `20001` · `25001` · `30001` · `35001` · `40001` |

> أم سهوًا — لكنّه **مخبوزٌ فعلًا**، فانسخه كما هو إن أردت تطابقًا سلوكيًّا.

## ٤. معيار «الرتبة الصالحة» = **`Rank != 0`** ⇒ إقصاء البوتات ✅

الدوالّ في `SFSKammelnaRoomExtensions` **لا في `PlayerRank`** (تصحيحٌ لموضعها):
`GetHighestRankInRoom` @`0x4ECA5C0` · `GetLowestRankInRoom` @`0x4ECA8A4` · `GetAverageRank` @`0x4ECAB88`

* المعيار في الثلاث: **`Rank != 0`** — و`Ranks.AI = 0` ⇒ **الاستثناء يُقصي البوتات**.
  السبب البنيويّ: `static readonly PlayerRank AI` يشترك فيه كلّ بوت.
* **المتوسّط**: `scvtf` · `scvtf` · `fdiv` @`0x4ECAFC8`–`0x4ECAFE0`
  ⇒ **قسمة `float` مفردة الدقّة بلا أيّ تقريب أو اقتطاع** ✅
* 🛑 **حالتان حدّيّتان خطرتان**:
  * `count == 0` ⇒ **`NaN`** (لا استثناء) — سيظهر نصًّا في الواجهة إن لم تحرسه.
  * `FirstOrDefault` على الفراغ يُعيد **`0` = AI** — أي **القيمة المستثناة نفسها تعود كافتراضيّ**.

## ٥. ما لم يُحسَم 🟡

1. نيّة العتبة `10500`.
2. وحدة `TicketPrice = 85` (أيسات؟ نقاط؟) — الرقم ✅ والوحدة 🟡.
3. هل يُنادى `GetNearestFTAwardStage` عبر مفوَّض أو انعكاس (المسح يغطّي `bl`+`b` فقط).
4. ~~هل `GetPlayersInfo` @`0x4EC9980` يشمل المشاهدين؟~~ ✅ **الدالّة لا تُرشّح**: تحوّل مصفوفة لاعبي
   الغرفة كاملةً (`ToModelArray`) بلا فحص `IsSpectator`؛ فوجود المشاهدين تابعٌ لعضويّة غرفة SFS لا لهذه الدالّة.
   ومقام المتوسّط في [§٤](#٤-معيار-الرتبة-الصالحة--rank--0--يقصي-البوتات-) يستثني `Rank == 0` (البوتات) على أي حال.
