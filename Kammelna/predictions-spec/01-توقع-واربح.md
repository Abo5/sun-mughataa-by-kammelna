## ٢. ⭐ التحقّق من صحّة النتيجة — المنطق العميليّ الوحيد

`MatchPredictionModel.GetValidScores()` @`0x50A7BAC` (176B):
`Open → null` (بلا قيد) · `BestOf → GetFirstTo()` · `NumberOfGames → NumberOfGames()` · وإلا استثناء.

### `NumberOfGames` @`0x50A7E78` (596B) ✅
```csharp
n = league.scoreValue;
for (i = 0; i < n; i++) { add (i, n-i); add (n-i, i); }   // بفحص Contains
```
⇒ كل الأزواج التي **مجموعها = `scoreValue`**؛ والتعادل `(n/2, n/2)` يُضاف مرّة واحدة.

### 🛑 `GetFirstTo` @`0x50A7C5C` (540B) — **خلل مؤكَّد**
```asm
0x50A7CF8  scvtf  s0, w19, #1      ; scoreValue / 2
0x50A7D00  fcvtps w21, s0          ; Ceiling ⇒ firstTo   (ديناميكيّ ✅)
…
0x50A7D74  mov    w1, #2           ; ⭐ قيمة الفوز مكتوبة صلبًا
0x50A7DE4  mov    w2, #2
```
```csharp
firstTo = (int)Math.Ceiling(scoreValue / 2f);
for (i = 0; i < firstTo; i++) { list.Add((2, i)); list.Add((i, 2)); }
```

> 🛑 **حدّ الحلقة مشتقّ من `scoreValue` لكن قيمة الفوز ثابتة `2`.**
> صحيحة فقط لـ`BestOf(3)` ⇒ `(2,0) (0,2) (2,1) (1,2)`.
> وعند `BestOf(5)` تُنتج `(2,0) (0,2) (2,1) (1,2) (2,2) (2,2)` — فائز بـ**٢** بدل ٣، وتعادل
> `(2,2)` في وضع لا يسمح بالتعادل. 🟡 كونه خطأً لا تصميمًا لا يُحسم بلا بيانات خادم.

> ⭐ **لا يوجد أي أمر SFS للتوقّعات** ✅ — كله REST + ContentPush + ملف CDN.

## ٤. التقييم — خادميّ بالكامل ⭐

`predictionReward` يصل **مُقيَّمًا** من الخادم. و`GetRewardText` @`0x4F5D4DC` مجرّد `switch`
على القيمة الواردة. **لا توجد في العميل أي مقارنة بين النتيجة المتوقّعة والفعلية لاشتقاق مكافأة** —
المقارنة الوحيدة تجميلية في `AssignWinnerOrDrawTags` @`0x4F5CBCC`.

### نقاط الموسم — `PredictAndWinRewardPopup.Populate` @`0x4F601AC` (856B) ✅
```csharp
if (model.isSeasonMatch) {                       // ldrb w8,[x20,#0x70]
    scorePts  = RemoteConfig.Current.Predictions.SeasonCorrectScorePoints;   // [Predictions+0x10]
    winnerPts = RemoteConfig.Current.Predictions.SeasonCorrectWinnerPoints;  // [+0x14]
} else scorePts = winnerPts = 0;
…
AddReward(Participation, participationAces, participationSubDays, 0);        // mov w4,#0
```
⇒ **جائزة المشاركة لا تمنح نقاط موسم أبدًا**، والنقاط تُعرض فقط على `isSeasonMatch`.

> 📌 `RemoteConfigModel.Predictions` عند الإزاحة **`0x20`** ✅، والمستهلك الوحيد لـ
> `SeasonCorrectScorePoints`/`WinnerPoints` في الثنائي كلّه هو هذه الدالّة.

## ٥. التكلفة والأهلية

> ⭐ **مجّاني تمامًا** ✅ — لا أسِس ولا تذاكر ولا بوابة اشتراك. صفر إشارة إلى
> `Aces`/`Wallet`/`Purchase`/`Price` في مسار التوقّع. (`SalesChannel.PredictAndWin = 24`
> هي قناة **صرف** أيام الاشتراك الممنوحة كجائزة.)

**البوّابات الفعلية**:
1. **المنصّة** ✅ — `if (KUtil.GetPlatform() == Web(3) || KUtil.NoPlayServices) return false;`
   ⇒ النظام **معطّل كليًّا** على الويب وعلى الأجهزة بلا خدمات Play.
2. **الوقت** ✅ — `m.expiryDate > DateTime.Now`.
3. **منع التكرار** ✅ — `UserMatchPredictions.All(upm => upm.predictionMatch.id != pm.id)`.
4. **X/تويتر** ⚪🟡 — `Ineligible` يصل من الخادم؛ الشروط: ربط الحساب، أن يكون عامًّا،
   متابعة `@Kammelna`، وإكمال التغريد بعد التوقّع.

## ٨. ما لم يُحسَم 🟡

1. ~~أسماء مفاتيح JSON الحرفية للنماذج الواردة.~~ ✅ **camelCase** (`id` · `homeTeamScore` · `expiryDate`…)
   لا PascalCase — صفر `[JsonProperty]` في عشرة نماذج. استثناءان: `PredictionSeasonModel`
   (`Description`/`Image`/`Rewards`) وحمولة الـPOST.
2. ~~شكل حمولة الـdelta لمفتاح `predictions` (`ListDeltaApplier` لم يُفكّ).~~ ✅ **مفكوك في [`data-spec/05`](../data-spec/05-محرّك-الدلتا-مفكوكًا.md)**. وفيه أنّ `predictions.onApplied = NotifyPredictionsApplied` و**`onChanged` معدوم** ⇒ إشارة `changed` بلا حمولة لا تفعل شيئًا لهذا المفتاح.
3. ~~TTL كاش `CachedModel<List<MatchPredictionModel>>`.~~ 🛑 **السؤال ساقط**: [`data-spec/01`](../data-spec/01-طبقة-البيانات.md) أثبت **لا TTL إطلاقًا** في `CachedModel` — الصلاحية مدفوعة بختم `lru` حصرًا.
4. ~~صنف `UserFeedData` المقابل لـ`PredictionWarning = 13`.~~ 🛑 **لا صنف له**: جدول القفز @`0x7253230`
   يعطي الفرع الافتراضيّ = `UserFeedData` وهو **`abstract`**، و`ReadJson` @`0x52A8B14` ينادي
   `Activator.CreateInstance` عليه ⇒ **استثناء**. ونفسه للأعضاء ٥ · ٦ · ٢٠ · ٢٣🚩.
5. كسر التعادل في الترتيب (⚪ «الأولوية لمن توقّع نتائج صحيحة أكثر») — بلا أثر في العميل.
6. قيم الـprefab (`closedHeight`/`openHeight`، ألوان عدّاد الأحرف) — مُسلسلة في الأصول.
