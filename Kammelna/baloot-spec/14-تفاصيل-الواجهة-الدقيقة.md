## ١. لوحة الألوان

📄 **المرجع الكامل**: [`refs/colors-palette.md`](refs/colors-palette.md)

**٣٦ لون فريد** عبر مشهدي الجوال والتابلت. الألوان المعتمة (α=1.00) هي لوحة الهوية الفعلية:

| HEX | الاستخدام |
|---|---|
| `#FFFFFF` | الأبيض الافتراضي — ٤٩٩ عنصر (صور ونصوص بلا تلوين) |
| **`#5B4C3D`** | **بني الطاولة/الإطار — اللون الأساسي للهوية** (٨ عناصر) |
| **`#333333`** | **الرمادي الداكن — لون النص الأساسي** |
| `#ECECEC` | أبيض مائل للرمادي — العناوين |
| `#F9E606` | أصفر ذهبي — التمييز والفوز |
| `#8EFF4C` / `#29FF00` | أخضر — مؤشرات موجبة |
| `#FF8391` / `#FF8A94` | وردي — مؤشرات سالبة |
| `#A30000` | أحمر داكن — خطأ/خسارة |
| `#787878` | رمادي متوسط — عناصر معطّلة |
| `#272727` | رمادي داكن جدًا |
| `#000000` | أسود، ويُستخدم بشفافيات `0.15 / 0.23 / 0.34 / 0.42 / 0.89` للتعتيم والظلال |

> ⭐ **لبناء نسختك**: استبدل هذه القائمة فقط. الألوان ذات `alpha = 0.00`
> (`#FF006E`، `#00FFC7`، `#C500FF`، `#2F00FF`، `#0061FF`، `#FF0000`) عناصر
> **مخفية بالشفافية** — مناطق لمس أو عناصر يفعّلها الكود، ولا تحتاج مقابلًا لونيًا.

### الألوان المثبّتة في الكود (لا تظهر في المشهد)

## ٢. شجرة الواجهة والإحداثيات

📄 **المراجع**:
- [`refs/ui-hierarchy-phone.txt`](refs/ui-hierarchy-phone.txt) — **١٠٣٢ كائن** (جوال)
- [`refs/ui-hierarchy-tablet.txt`](refs/ui-hierarchy-tablet.txt) — **١٣١٣ كائن** (تابلت)

**الصيغة**:
```
- الاسم  pos(x,y) size(w,h) anchor[minX,minY→maxX,maxY] pivot(x,y) [scale(x,y)] {المكوّنات} [مخفي]
```

**القياس المرجعي**: `1080 × 1920` (الخلفية بهذا المقاس بالضبط) ✅

**الجذور الاثنا عشر في مشهد الجوال**:
```
Ads Handler · AnimatedGiftController · Baloot Game · Cameras ·
Game Replay Manager · Game Room Theme · Game Ui Canvas · …
```

**مثال حقيقي من الملف**:
```
- Game Room Theme  {AutoAssignMainCamera, Canvas, CanvasScaler, GraphicRaycaster, RoomThemeUi, SportTeamRoomTheme}
  - Background  pos(0,0) size(1080,1920) anchor[0.50,0.50→0.50,0.50]  {Image, SpriteToggler}
    - Room Theme  pos(0,0) size(1080,1920) anchor[0.50,0.50→0.50,0.50]  {Image}
    - Userbox Dimming Background  pos(0,0) size(1080,1920) …  {Canvas, Image}
  - Dissmisser  pos(0,0) size(0,0) anchor[0.00,0.00→1.00,1.00]  {DismissibleBlocker}
    - Blocker  … {Image}  [مخفي]
```

> الملفان يحتويان **كل** عنصر في الشاشة: مؤشّر التحميل (أربعة رموز أنواع بمقياس 0.10)،
> صناديق اللاعبين، الميدان، الأزرار، النوافذ، وشاشة التقييد.

### ٣.٤ المحاذاة
القيمة `514` = **Center** (وسط). القيمة `65535` تعني **غير محدّد/موروث** من الإعداد الافتراضي.

## ٥. ماذا تحتاج لإعادة بناء الواجهة

بهذه الملفات الأربعة تقدر تعيد بناء الشاشة كاملة:

1. **الشجرة** (`ui-hierarchy-*.txt`) → أنشئ نفس التسلسل والمراسي والأحجام على قماش `1080×1920`.
2. **الألوان** (`colors-palette.md`) → استبدل كل لون بمقابله في هويتك.
3. **الخطوط** (`fonts-and-text.md`) → طبّق سُلّم الأحجام على خطك العربي.
4. **الصور** (`sprite-inventory.md`) → اطلب من مصمّمك رسومات بنفس الأسماء والأبعاد.

ثم اربطها بالمنطق من الفصول [٠١](01-الأوراق-والتعريفات.md)–[٠٧](07-القطع-والتقييد.md)
والحركة من [٠٨](08-الأنيميشن-الكامل.md).
