### 5.1 🛑 قرار لعب الورقة — أُعيد فكّه بالكامل

> 🛑 **هذا القسم كان يحوي أخطاء جوهرية وأُعيدت كتابته.** التصحيحات مفصّلة في §٥.٤.

#### ⭐⭐⭐ `BalootAiLogic.PlayCard` @`0x51FA500` (1,192B) — مفكوكة ١٠٠٪ ✅

```csharp
public override Card PlayCard(List<Card> cards, int playerIndex)
{
    Card[] played  = gc.AllPlayedCards.SelectMany(kv => kv.Value).ToArray();   // معلومة عامّة
    int    mateIdx = (playerIndex + 1) % 4;
    bool[] ekkah   = gc.Players.Select(p => p.HasEkkah).ToArray();             // معلومة معلَنة

    List<Card> mine = BalootUtils.PlayableCards(cards, gc.PlayedCards, gc.FirstPlayer,
                          playerIndex, gc.GameMode, gc.CurrentSuit, gc.TrumpSuit,
                          gc.IsHokomClose, ekkah);

    // ★★ يد الشريك الحقيقية — انظر §٥.٣
    List<Card> mate = BalootUtils.PlayableCards(gc.Players[mateIdx].Cards, …);

    Suit target;
    if (gc.FirstPlayer) {                                    // أنا أفتح
        Card win = GetEatingCards(mine, played).FirstOrDefault();
        if (win != null) return win;                         // ⭐ خروج مبكر: العب الضامنة

        Card mateWin = GetEatingCards(mate, played).FirstOrDefault();
        if (UnityEngine.Random.value > 0.8f && mateWin != null)
             target = mateWin.Suit;                          // ٢٠٪: العب لنوع شريكي
        else target = GetMaxCard(mine).Suit;                 // ٨٠٪: نوع أقوى ورقة عندي
    } else target = gc.CurrentSuit;                          // أنا تابع

    var ofSuit = BalootUtils.GetSuitCards(mine, target);
    return GetMinCard(ofSuit.Count != 0 ? ofSuit : mine);     // ⭐ دائمًا الأضعف
}
```

**الاحتمال `0.8f`** ✅ (قرأتُه بنفسي @`0x51FA968`):
`mov w8,#0xCCCD ; movk w8,#0x3F4C,lsl #16` = `0x3F4CCCCD` = `0.8f`، والشرط `value > 0.8`
⇒ **يقع بنسبة ٢٠٪**.

#### `GetEatingCards` @`0x51FBB78` (728B) ✅ — لم تكن موثَّقة
```csharp
private List<Card> GetEatingCards(List<Card> playable, Card[] played)
    => BalootCardUtils.AllBalootCards
         .Except(played)                                     // كل ما لم يُرَ بعد
         .OrderByDescending(c => gc.GetOfflineValue(c))
         .GroupBy(c => c.Suit).Select(g => g.First())         // أعلى متبقٍّ في كل نوع
         .Intersect(playable)
         .ToList();
```
> ⭐ **الدلالة**: «أوراق لو لعبتُها الآن فلا شيء متبقٍّ يأكلها **من نوعها**».
> **معلومة عامّة بحتة** — `Except(played)` لا تستثني يد أحد.
> 🟡 **قصورها**: تتجاهل **القطع بالحكم** — قد تُعدّ ورقة «ضامنة» ثم يقطعها خصم.

#### ⭐ دالّة التقييم — `GetOfflineValue` @`0x520722C` ✅
```csharp
int v = (Rank >= SEVEN) ? T[Rank - 5] : 0;        // T @0x7253448 = {1,2,3,7,4,5,6,8}
if (GameMode == Hokom && Suit == TrumpSuit) {
    if (Rank == JACK) return 10000;
    if (Rank == NINE) return  9000;
    return v * 1000;
}
return (Suit == CurrentSuit) ? v * 100 : v;
```
**جدول `0x7253448` = `{1, 2, 3, 7, 4, 5, 6, 8}`** (فهرسة `Rank − 5`) ✅ — قرأتُه بنفسي.
⇒ الصن: `7 < 8 < 9 < J < Q < K < 10 < A` · الحكم: `J > 9 > A > 10 > K > Q > 8 > 7` ✅

`GetMaxCard` @`0x51FBFB0` / `GetMinCard` @`0x51FC17C`: فرز بـ`CompareCards` @`0x51F9B40`
= `GetOfflineValue(b) − GetOfflineValue(a)` ⇒ **تنازليّ**، ثم `.First()` / `.Last()`.
⚠️ **الفرز في المكان** — يعدّلان القائمة الممرَّرة.

#### 🟡 ماذا يعني هذا سلوكيًّا
1. **عند الفتح بضامنة**: يلعبها فورًا ⇒ يحرق آصاته مبكرًا، ويبدأ بالحكم (معامله ١٠٠٠).
2. **عند الفتح بلا ضامنة**: ٨٠٪ أضعف ورقة من نوع أقوى ورقة عنده؛ ٢٠٪ من نوع فيه ضامنة عند شريكه.
3. **عند المتابعة**: **يلعب الأضعف دائمًا** — ⛔ **لا يحاول أبدًا كسب الطرحة**، ولا يوازن
   الأبناط، ولا يعرف أن شريكه يقود. القانونية وحدها تُجبره على القطع حين توجب القواعد.
4. **لا ذاكرة ولا إحصاء ولا استنتاج توزيع** — كل شيء يُحسب من الصفر كل دور.

### 5.2 🛑 قرار المزايدة — `BalootAiLogic.Bid` @`0x51FC250` (528B) ✅

```csharp
if (biddingState == 3) return EmptyBid;            // ممنوع من المزايدة

if (options.Contains(Hokom2) && !decided) { if (CheckIfAiCouldBuyHokom2(...).Key) result = Hokom2; }
if ((options.Contains(HokomClubs) || options.Contains(HokomDiamonds)) && !decided) {
    var kv = CheckIfAiCouldBuyHokom2(...);         // استدعاء ثانٍ

```
**جدول `0x72534C0` = `{17, 18, 15, 16}`** ✅ (قرأتُه بنفسي) — فهرسة `(int)Suit`:
`♠→HokomSpades(17)` · `♥→HokomHearts(18)` · `♣→HokomClubs(15)` · `♦→HokomDiamonds(16)`.

> ⭐ **الصن له أولوية على الحكم** (الفحص الأول يوقف الباقي).

#### ⛔ ما لا يفعله ذكاء المزايدة — نفي مُثبَت
المخرجات الممكنة **حصرًا**: `Pass` · `Sun` · `Hokom` · `Hokom2` · `ConfirmHokom` ·
`HokomClubs/Diamonds/Spades/Hearts` · `EmptyBid`.

⛔ **لا يضاعف أبدًا** (`Double` · `Triple` · `Qahwa` · `Four`) ·
⛔ **لا يلعب أشكل** · ⛔ **لا يقول «ولا»** · ⛔ **لا «قبلك» ولا «حوّل صن»** ·
⛔ **لا تعاون ولا إشارات مع الشريك** — كل مقعد يقيّم يده وحده.

> ⇒ **كل بنود المضاعفة في الأوفلاين لا تصدر إلا من اللاعب البشري.**

#### 🔴 علّتان مرصودتان
1. `decided` **لا يُحدَّث** بعد فرع `Hokom2` (`csel w24` بلا لمس `w22`). بلا أثر عمليًّا لأن
   الحالتين ١٢ و١٣ لا تحويان `15/16` — **لكن لا تنسخها.**
2. 🟡 في الحالات ٢١–٢٤ لا يوجد `Pass` في القائمة أصلًا؛ إن فشل `CheckIfAiCouldBuyHokom2`
   فسيُرسل `"pass"` وهو **بند غير مطروح**. أثره على `GetNextBidding` غير متتبَّع.

### 5.9 🛑 تصحيح: «المسار الجشع ومجموعة القوّة `O(2^n·n·Size)`»

`ProjectsUtility<T>.GetBestProjectCards` — أي **كشف المشاريع** ([١٥ §٤٥.٦](15-تدقيق-ARM64.md)).
✅ **`BalootAiLogic` لا تستدعي `GetPowerSet` ولا `GetBestProjectCards` إطلاقًا.**
✅ تكلفة قرار الورقة كاملة: نداءان لـ`PlayableCards` + نداءان لـ`GetEatingCards` + فرزان
لقائمة ≤ ٨ عناصر ⇒ **تافهة. لا بحث ولا شجرة ولا تعداد.**

### 5.10 دوال مساعدة في `BalootUtils` يستخدمها البوت ✅

### 5.11 «غشّ» التعليم المسرحيّ ⚠️ *(ليس غشّ الذكاء — انظر §٥.٣)*
