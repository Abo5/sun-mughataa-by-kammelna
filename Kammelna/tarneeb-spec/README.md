**النتيجة** (مُنقّحة بعد [تدقيق ARM64](10-تدقيق-ARM64.md)):

| القاعدة | أين هي؟ |
|---|---|
| **شرط نجاح المزايدة (العقد)** | 🛑 **في العميل** — ١٣ لفّة · `teamEating >= HighestBid` · سقوط عند `opponentEating > 13 − HighestBid` ([١٠ §١](10-تدقيق-ARM64.md)) |
| **قيد المزايدة** (رفع صارم ٧–١٣) | 🛑 **في العميل** — لا `bs` من الخادم ([١٠ §٣](10-تدقيق-ARM64.md)) |
| **نهاية الصكة** (`> 30`) | ✅ في العميل |
| صيغة النقاط لكل جولة | ❌ الخادم |
| حلّ اللفّة (`CheckWhoEats`) وإلزامات اللعب (`ppcs`) | ❌ الخادم — كلتاهما `NotImplementedException` ([١٠ §٤](10-تدقيق-ARM64.md)) |

ما يمكن استخراجه بيقين: نموذج الورق، **قاعدة العقد**، بنية المزايدة كاملة،

| المجال | الحالة |
|---|---|
| نموذج الورق ودالة القيمة | ✅ **مؤكَّد** — `GetValue = Rank + 2` |

| بنية المزايدة وأزرارها | ✅ **مؤكَّد** — 7..13 + 4 أنواع + بس + ورق |
| مراحل المزايدة | ✅ **مؤكَّد** — `EatingBid` ثم `PickingSuit` |
| مفاتيح الشبكة | ✅ **مؤكَّد** — مُستخرجة من الثنائي عبر `ScriptString` |
| حزمة نتيجة الجولة | ✅ **مؤكَّد** — `rndB`, `BidderWon` |
| توقيتات الأنيميشن | ✅ **مؤكَّد** — قيم Unity المُسلسلة |
| الألوان والخطوط والتخطيط والتصميم | ✅ **مؤكَّد** — من typetree |
