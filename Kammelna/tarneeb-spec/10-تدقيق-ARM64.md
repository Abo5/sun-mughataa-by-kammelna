# ١٠ — تدقيق ARM64 للطرنيب

[↩ الفهرس](README.md)

> الفصول ٠١–٠٩ بُنيت على مخرجات **Cpp2IL**، وهي غير موثوقة مع LINQ والمعمّمات.
> هذا الفصل حصيلة **تفكيك ARM64 مباشر** لكل دوال `Tarneeb*` (105 دالة، منها 39 ≥150 بايت)
> مع بناء **فهرس مراجع شامل** لكل أزواج `adrp+add` في الثنائي (203,230 هدفًا) للتحقّق من
> «مَن يستعمل هذه السلسلة فعلًا».
>
> **حيث يتعارض هذا الفصل مع ٠١–٠٩، هذا هو المرجع.**

## ١. ⭐⭐⭐ قاعدة العقد — أهمّ ما فات المواصفة القديمة

وصفت المواصفة `<UpdateEatingCount>b__0` @`0x4FBCBC4` (416B) بأنها «مساعد أنيميشن».
**هي تحمل منطق العقد كاملًا** ✅:

```asm
0x4FBCCB4  ldr  w8, [x19, #0x1c]   ; HighestBid
0x4FBCCB8  cbz  w8, → أبيض          ; لا مزايدة بعد
0x4FBCCBC  ldrb w9, [x19, #0x20]   ; isTeamBidder
0x4FBCCC0  cbz  w9, → أبيض
0x4FBCCC4  ldr  w9, [x19, #0x24]   ; teamEating
0x4FBCCC8  cmp  w9, w8
0x4FBCCCC  b.ge → أخضر              ; teamEating >= HighestBid
0x4FBCCD0  ldr  w9, [x19, #0x28]   ; opponentEating
0x4FBCCD4  mov  w10, #0xd          ; ⭐ 13 — عدد اللفّات، مكتوب حرفيًّا
0x4FBCCD8  sub  w10, w10, w8       ; 13 − HighestBid
0x4FBCCE0  cmp  w9, w10
0x4FBCCE4  b.le → أبيض
           → أحمر                   ; opponentEating > 13 − HighestBid
```

```csharp
if (HighestBid != 0 && isTeamBidder) {
    if      (teamEating >= HighestBid)              state = Fulfilled;  // #B2FFB9
    else if (opponentEating > 13 - HighestBid)      state = Broken;     // #FFA0A3
    else                                            state = Pending;    // #FFFFFF
}
eatingContainerImage.DOColor(color, 0.3f);
```

> ⭐⭐⭐ **ثلاث حقائق مُثبَتة من كود الآلة**:
> 1. الجولة **13 لفّة** — الثابت `13` مكتوب حرفيًّا.
> 2. العقد = **أخذ `HighestBid` لفّة أو أكثر** (`>=` لا `==`).
> 3. العقد يسقط **حتميًّا** عند `opponentEating > 13 − HighestBid` — أي حين يصير بلوغه
>    مستحيلًا رياضيًّا.

## ٣. ⭐⭐ قواعد المزايدة كاملة

### ٣.١ خريطة الأزرار — `BidValue` @`0x4F85A68` (584B) ✅
`button7…button13` (الحقول `0x80`…`0xB0`) → **7 … 13**، وأي زر آخر → `0`.
**المدى: ٧ إلى ١٣ حصرًا.**

### ٣.٢ 🛑 `isValidBid` @`0x4F851E8` — **٨٠٤ بايت لا ٢٦٠**

```csharp
private bool isValidBid(Button b) {
    if (tGame.BiddingStage != EatingBid) {              // [tGame+0x174]
        if (tGame.BiddingStage != PickingSuit) return false;
        return b == buttonClubs || b == buttonDiamonds
            || b == buttonSpades || b == buttonHearts;
    }
    if (b == buttonPass) return true;
    return BidValue(b) > tGame.HighestBid;              // [tGame+0x170] ، SFS "hb"
}
```

> 🛑 **تصحيح مزدوج**: المواصفة سجّلت الحجم `260B` (الصحيح **804**) ووصفتها بأنها
> «تحقّق **مرحلة** لا قيمة». **هي تفحص القيمة**: رفع صارم `> HighestBid`.

### ٣.٣ 🛑 قيد المزايدة **محليّ لا خادميّ**

```csharp
// getStateButtons @0x4F84C08 (336B)
protected override Button[] getStateButtons() =>
    tGame.BiddingStage != EatingBid
        ? allSuitButtons
        : round1DefaultState1
             .Where(b => b == buttonPass || BidValue(b) > tGame.HighestBid)
             .ToArray();
```

> 🛑 **أخطر تصحيح في هذا التدقيق**: المواصفة و README يقولان «قيد المزايدة ✅ مُثبَت أنه من
> الخادم كقائمة أزرار مسموحة — نفس نمط البلوت (`bs`)». **خطأ.**
> **لا يوجد أي مرجع لـ`bs` في مسار الطرنيب إطلاقًا.** العميل يحسب القائمة بنفسه ويفرض
> قاعدة الرفع **قبل الإرسال**.

### ٣.٥ رسالة المزايدة — `SubmitBid` @`0x4F855B0` (1208B) ✅


| المفتاح | الحقل | الإزاحة |
|---|---|---|
| `e1` / `e2` | أكلات الفريقين | `0x10` / `0x14` |
| `w` | `WinnerTeamIndex` | `0x18` |
| `s1` / `s2` | نقاط الفريقين | `0x1C` / `0x20` |

## ٩. البروتوكول ✅

**مفاتيح `TarneebGame`** (من `.cctor` @`0x53277A8`):

| الثابت | المفتاح | النوع |
|---|---|---|
| `HIGHEST_BID` | `hb` | int |
| `BIDDING_STAGE` | `bStg` | enum int |
| `EATING_COUNT` | `ecs` | int[4] |

**الرسالة الصادرة**: `a_bid` بحمولة `pass:bool` **أو** `b:int∈[7,13]` **أو** `s:string∈{s,h,c,d}`.

**الوارد الذي يقرأه الطرنيب فعلًا**: `hb` `bStg` `ecs` + (من `CardGame`) `ts` `current_suit`
`rb` `mn` `dealer` `sw` `anp` `opc` `opi` `b` `gStg` + (نتيجة الجولة) `e1 e2 w s1 s2 b cc lr rndB` + `bt`.

> 🛑 **تصحيح**: المواصفة (٠٧ §٤) تُدرج `pcs · apcs · pcsCount · bs · kasho · hks · cks ·
> emt · ne · gst · ghl · ait · seat · ss` كـ«مستعملة في الطرنيب». هذه من الطبقة المشتركة —
> **لا يُقرأ أيٌّ منها في أي دالة `Tarneeb*`**.
>
> 🛑 **`waraq` ثابت ميّت**: فهرس المراجع يُظهر أن السلسلة (`0x8D4A488`) مرجوعة من **البلوت
> فقط** (6 مراجع، كلها `BalootBiddingButtons`/`BalootUserbox`)، و**صفر مراجع من أي دالة
> طرنيب**. و`SubmitBid` لا يملك فرعًا رابعًا. **لا دليل على أن الطرنيب يرسل `waraq`.**
