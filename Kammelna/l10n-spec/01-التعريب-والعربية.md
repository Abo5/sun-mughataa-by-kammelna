## ٢. ⭐⭐ ماذا يحدث عند غياب المفتاح؟

`GetText(string key, GameObject go)` @`0x4EA9A5C` (584B) ✅:
```csharp
if (key == null) key = string.Empty;
Content.TryGetValue(key, out string v);
if (string.IsNullOrEmpty(v)) {
    string ctx = (go != null) ? ", Object: " + go.GetPath() : "";
    Debug.LogWarning("No text defined for " + key + ctx, go);
    return key;                 // ← 0x4EA9C8C: mov x0, x19  (x19 = key)
}
return v;
```

> ⭐ **المفتاح المفقود يعود نصًّا حرفيًّا** + `LogWarning` مع الكائن كسياق.
> هذا يفسّر بدقّة ما لوحظ في أرشيفات سابقة: مفاتيح في XML وغير موجودة في `ScriptString`
> **تظهر حرفيًّا على الشاشة بالإنجليزية الخام**.

## ٤. ⭐ قاعدة الجمع العربية — CLDR كاملة

`GetText(key, long n)` @`0x4EA9DAC` (324B) ✅:
```asm
cmp x19, #3 ; b.hs …                       ; n < 3 ⇒ form = n
; وإلا: m = n % 100 (قسمة سحرية 0xA3D70A3D70A3D70B ثم msub بـ100)
mov w10,#3 ; cmp x8,#0xa ; mov w8,#4 ; cinc w8,w8,le   ; m<=10 ⇒ 5 ، m>10 ⇒ 4
sub x9,x8,#3 ; cmp x9,#8 ; csel w8,w10,w8,lo           ; 3<=m<=10 ⇒ 3
```

| الشرط | الصيغة | CLDR |
|---|---|---|
| `n == 0` | `0` | zero |
| `n == 1` | `1` | one |
| `n == 2` | `2` | two |
| `n % 100 ∈ [3..10]` | `3` | few |
| `n % 100 ∈ [11..99]` | `4` | many |
| غير ذلك | `5` | other |

يطابق XML تمامًا: `Days` → `form=3` «{0} أيام» · `form=4` «{0} يوما» · `form=5` «{0} يوم» ✅.

### `SafeFormat` @`0x4EA9FF0` (396B) ✅
```csharp
try { return string.Format(GetText(s, null), i); }
catch (FormatException) { return i.ToString() + " " + GetText(s, null); }   // "5 أيام"
```
> ✅ **مفتاح جمع بلا `{0}` لا يُسقط التطبيق** بل يُنتج «العدد + مسافة + النصّ».

### الترتيبي — `GetOrdinalText` @`0x4EAA17C` (320B) ✅
```csharp
if (Exists(key + n)) return GetText(key + n, null);   // "ORDINAL_LEVELS1"
return string.Format(GetText(key, null), n);          // تراجُع: "المستوى {0}"
```
المفاتيح: `ORDINAL_LEVELS` · `ORDINAL_PLACES` · **`ORDINAL_STAGES`** · **`ORDINAL_PLAY_WINDOWS`**
(الأخيران لم يردا في أي أرشيف سابق).

## ٥. RTL ومعالجة العربية

### البوّابة — `ShouldFixArabic` @`0x4EABBC4` (484B) ✅
```csharp
if (LocalizationText.Language != "AR") return false;
if (input == null) return false;
return ArabicCharactersRegex.IsMatch(input);
```

### التعبير النمطيّ (من `.cctor` @`0x4EACE70`) ✅
```
[؀-ۿ]|[ݐ-ݿ]|[ﭐ-ﰿ]|[ﹰ-ﻼ]|^[\d,\.]+$
```
`U+0600–06FF` · `U+0750–077F` · `U+FB50–FC3F` · `U+FE70–FEFC`
**أو سلسلة أرقام/فواصل/نقاط بحتة** ⇒ ⭐ **الأرقام الخالصة تُعامل كعربية وتُعكَس أيضًا**.

### `IsArabicFixed` @`0x4EAC42C` + لامدا `b__13_0` @`0x4EAD4E0` ✅
```asm
add w8, w1, #0x190 ; and w8, w8, #0xffff ; cmp w8, #0x8d ; cset w0, lo
```
⇒ `c => (ushort)(c + 0x190) < 0x8D` ⟺ `0xFE70 ≤ c ≤ 0xFEFC` (الأشكال التقديمية العربية‑ب).
تمنع **المعالجة المزدوجة**.

### ⭐ المحرّك — `FixArabicHelper` @`0x4EAC058` (464B) ✅
```csharp
try {
    if (IsArabicFixed(input)) { /* لا يعيد التشكيل */ }
    string s = ArabicSupport.ArabicFixer.Fix(input, showTashkeel, useHinduNumbers);
    return StringsExtensions.Reverse(s);              // ⭐ عكس يدويّ للسلسلة
} catch (Exception e) {
    Debug.LogError("Arabic fixer input: (" + input + ") failed with : " + e);
    return "";
}
```
> ⭐⭐ المكتبة هي **`ArabicSupport.dll` (ArabicFixer الكلاسيكية)**، و**الاتجاه يُنفَّذ بعكس
> السلسلة يدويًّا لا بمحرّك BiDi**. هذا قرار معماريّ جوهريّ — انسخه أو استبدله بـHarfBuzz واعيًا.

### حماية Rich Text ✅
`FixTag` @`0x4EAC228` (516B) يفصل على `<` و`>` فيعالج الأجزاء النصّية فقط
— وإلّا لانقلب `<color=#AF5D21>` إلى نصّ مقروء.
`FixArabicMultipleLines` @`0x4EABDA8` (368B): `string.Join("\n", input.Split('\n').Select(…))`؛
يَعُدّ `<` و`>`، فإن تساويا وكانا ≥1 سلك مسار الوسوم.

### التشكيل ✅
`StringUtil.IsTashkeel` @`0x4EE9520` عبر لامدا @`0x4EEB7B0`:
`CharUnicodeInfo.GetUnicodeCategory(c) == UnicodeCategory.NonSpacingMark` (`cmp w0, #5`)
⇒ **التشكيل يُعرَّف بفئة يونيكود `Mn` لا بمجال محارف ثابت**.

## ٧. ما لم يُحسم — ✅ أُغلق كلّه (٢٧ سبتمبر ٢٠٢٦)

1. ~~ترتيب تراجع `Default` في `ParseSection`.~~ ✅ `اللعبة الحالية ≫ Default ≫ لا شيء`
   (`0x4EAA700`/`0x4EAAA0C`/`0x4EAAAD0`). 🛑 والمستعمَل هو **آخر `Default`** لا الأوّل (`csel` يكتب فوق)،
   ومطابقة اللعبة **تقصر الدائرة**. ومسارٌ رابع: `<AR>` بلا لعبة مطابقة وبلا `Default` ⇒ **المفتاح لا يُضاف** فيظهر حرفيًّا.
2. ~~`IsArabicFixed`: `Any` أم `All`؟~~ ✅ **`Any`** (قفزة ذيليّة إلى `Enumerable$$Any<char>` @`0x4EAC5AC`).
3. ~~`showTashkeel`/`useHinduNumbers`.~~ ✅ **القيم تختلف بين المواضع**:

   | الموضع | `showTashkeel` | `useHinduNumbers` |
   |---|---|---|
   | `FixArabicHelper` — كلّ نصّ معرَّب | `false` | **`false`** ⇒ أرقام غربيّة `0-9` ثمّ `Reverse` |
   | `DisplayTextCharAnimation` (كشف حرفًا حرفًا) | `false` | **`true`** ⇒ أرقام هنديّة `٠-٩` بلا `Reverse` |

   وأُغلقت الثغرة المنهجيّة: مسحُ كلّ `adrp+add` نحو `ArabicFixerTool_TypeInfo` @`0x8CA7230` ⇒ **٣ مواضع فقط**
   (كاتب `Fix` · قارئ `FixLine` · `.cctor`). ⚠️ والعلمان **حالة ساكنة عامّة** ⇒ غير آمن خيطيًّا.
4. ~~`TextCountdownFormat`.~~ ✅ `FormatDate` @`0x51663DC` مفكوكة. ⚠️ مَزلَق: `activeUnits` يُحسب في **كلّ لفّة**
   ⇒ «يوم + ٥ دقائق» بـ`activeUnits=2` يُنتج «يوم واحد» و**الدقائق تُفقد**. والصفر ⇒ `""`، والسالب ⇒ قيمة مطلقة.
5. ~~`DateRangeMessage` و`FormatDateTime`.~~ ✅ مفكوكتان (`0x4EAC5B0`/`0x4EAC8E4`). و`FormatDateTime`
   بـ`InvariantCulture` (`yyyy/MM/dd` ميلاديّ غربيّ) وقالب `{0} {1}/{2} -` **مضمَّن غير معرَّب**.
6. ~~بنية `LocalizableText`.~~ ✅ الحقول + المنشئان + المُوزِّع @`0x4ED3788` + ٤ مصانع.
7. ~~قوالب `MetricNumberFormatter`.~~ ✅ من الأصل الوحيد (UnityPy): `thousandsTemplate="thousands_template"`
   · `millionsTemplate="millions_template"` · `useCommas=0` ⇒ مفتاح `..._commas` **كود ميّت**. والآلاف **تبتر الكسر**
   والملايين `F2`. ⚠️ خطر 🟡: `normalTemplate=""` ⇒ `ToString("N0")`+`FixArabic`، والنمط `^[\d,\.]+$` قد يعكس `«750»→«057»` (لم يُتحقّق على الشاشة).

> 🛑 **تصحيحات على §٥ و§٦ و§١** (٢٧ سبتمبر): عند `IsArabicFixed == true` يُتجاوَز **`Fix` و`Reverse` معًا**
> وتُعاد السلسلة كما هي؛ ومسار الاستثناء يعيد **الدخل الأصليّ** لا `""` (الفارغ عند `null` فقط)؛ و`IsArabicFixed`
> يعيد `true` لـ`null`/`""`. و`MetricNumberFormatter`/`DateTimeFormat.template` **مفاتيح تعريب** لا قوالب `String.Format`.
