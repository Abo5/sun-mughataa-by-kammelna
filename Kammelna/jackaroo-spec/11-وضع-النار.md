# ١١ — وضع النار (Fire Mode)

[↩ الفهرس](README.md)

## ⭐⭐ الخلاصة: **متجر داخل اللوح، لا قاعدة لعب**

زرّ واحد يقلب اليد إلى «وضع شراء»، فتظهر فوق كل حجر قابل للنقلة **بطاقة سعر بالآسات**.
إن دفعت، **تُستبدل الرسوم المتحركة فقط**. النقلة والمسار والأحجار المأكولة والنتيجة —
**كلّها تُحدَّد كما هي بلا وضع نار**.

---

## ١. الدليل القاطع: **فعلان فقط قابلان للشراء** ✅

`JackarooGame..cctor` @`0x51DDF88` — القاموس الساكن كامل، **مدخلان لا ثالث** (قرأتُهما بنفسي):
```asm
0x51DE01C  mov w1, #0x20000 ; mov w2, #0x66 → Add(PLANT(131072),      GameAction 102)
0x51DE030  mov w1, #8       ; mov w2, #0x65 → Add(MOVE_EAT_PATH(8),   GameAction 101)
```
```csharp
public static Dictionary<JackarooActions, GameAction> SpecialJackarooActions = new() {
    { JackarooActions.PLANT,         GameAction.PlantSpecial       /* 102 */ },
    { JackarooActions.MOVE_EAT_PATH, GameAction.MoveEatPathSpecial /* 101 */ },
};
```
> ⛔ **لا سرقة · لا حرق ورق · لا تبديل · لا تقسيم.** الزرع والأكل على المسار فقط.
> ✅ ويتّسق هذا مع أن `Swap` **لا تمرّر `emote` إطلاقًا** ([٠٨ §٩](08-الأنيميشن-حركة-الجلول.md)).

### أين تنتهي القيمة المدفوعة؟ في مصنع الأنيميشن وحده ✅
```
DoPlayJackarooMove(move, onComplete, emote)
   → MoveMarble(…) → AnimatedItemController.CreateCustomMarbleAnimation(gameAction)  @0x5016D30
        = _marbleAnimations.FirstOrDefault(x => x.GameAction == gameAction.Value)
```
المُنفِّذان الوحيدان لـ`ICustomMarbleMove`: **`SpecialKingMarbleMove`** (الملك الناريّ) و**`SpecialMarblePlant`** (الزرع المُصدِّع).
> ⇒ **القيمة المدفوعة تدخل في اختيار prefab لا غير** — لا تمسّ العقد ولا المسار ولا `AreNodesWalkable*`.
> 🟡 الربط `101 ↔ King` و`102 ↔ Plant` استنتاج تسمية (قويّ) — القيمة مُسلسَلة في الـprefab.

### ⭐ العجز عن الدفع **لا يمنع النقلة**
`DoPlayMove` @`0x531A2B4`: إن لم يكفِ الرصيد ⇒ ⚪ `not_enough_aces` @`0x8D44058`، ثم
**`gameAction = null` والنقلة تُرسَل عادية** ✅. تأكيد إضافي على أن الأثر تجميليّ بحت.

## ٢. 🚩 البوّابة **عميليّة بحتة**

```csharp
// JackarooHand.CanAffordSpecialPlay @0x531E2C4 — فكّكتُها بنفسي
return SessionModel.Instance.LocalUser.GetAces() >= price;   // cmp w0, w19
```
* **لا نداء شراء منفصل** — لا `Store.Buy`، لا استجابة تُنتظَر.
* الفحص الوحيد قبل الإرسال هو أعلاه، ويقرأ **نسخة العميل من الرصيد**.
* الإرسال: `JackarooGame.SendToSfs` @`0x51DD5D8` — أمر **`a_card_played`** نفسه، مع حقل إضافيّ:
  ```csharp
  if (gactId.HasValue) o.Put("gact", gactId.Value);   // ⭐ StoreItem.id لا GameAction
  ```
  ⚪ المفتاح `gact` @`0x8D3E920` ✅.
* **الاستقبال**: `CardGameLastActionInfo..ctor` @`0x530D200` يقرأ `gact` إلى `GameActionItemId`
  ⇒ **الخادم يعيد بثّه لجميع اللاعبين** فيشغّلون الأنيميشن الخاص بلا تحقّق من جهتهم.

> 🚩 **هل يخصم الخادم ويرفض العاجز؟ غير قابل للإثبات من العميل.**
> **لا يوجد في العميل أي مسار يتعامل مع رفض خادميّ لـ`gact`** — لا رسالة خطأ، لا تراجع، لا إعادة ضبط.
> غياب مسار الرفض **مؤشّر قويّ** 🟡 على أن العميل يفترض القبول دائمًا.
> ⇒ عميل معدَّل يستطيع وضع `gact` في كل نقلة زرع/أكل-مسار بلا أي عائق محليّ.
> **في نسختك: اجعل الخصم والتحقّق خادميّين.**

### التسعير ✅
`StorePricing.EffectivePrice(item)` @`0x4FF47D8` = `item.virtualPrice − DiscountAmount(item)`،
و`DiscountAmount` @`0x4FF6CAC` = خصم بنسبة من `RemoteConfig.StoreInfo[category]` **للمشتركين فقط**، وإلّا صفر.
> ⚠️ الشيفرة تستعمل ثابتًا اسمه `CoinSprite = "<sprite=0>"` في بطاقة السعر، **لكن الرصيد المفحوص آسات لا كوينز** — لا تُضلَّل بالاسم.

## ٣. ⭐ الميزة مرهونة بمفتاح خادميّ

`JackarooHand.FetchSpecialPlayFromStore` @`0x5322684` ✅:
```csharp
gameEventsChannel.TriggerHideFireModeButton();      // يبدأ مخفيًّا دائمًا
Store.CallWhenLoaded(b__100_0);
```
و`b__100_0` @`0x5323FB4`:
```csharp
foreach (var (jAction, gAction) in JackarooGame.SpecialJackarooActions) {
    StoreItem item = Store.GetStoreItem(gAction);   // = GetCategoryItems(ItemCategory.GameActions /*7*/)
    if (item == null) continue;                     //   .FirstOrDefault(i => i.GameAction == ga)
    _specialJackarooActions.Add(jAction, item);
    any = true;
}
if (any) TriggerShowFireModeButton(); else TriggerHideFireModeButton();
```
> ⭐ **الزرّ لا يظهر أصلًا** ما لم يُرجع الكتالوج الخادميّ عنصرًا من الفئة `7` بـ`gameAction ∈ {101, 102}`.
> ⇒ **مفتاح تشغيل/إطفاء الميزة عن بُعد.**

و`GameStateHandleFireMode` @`0x53223BC` يقرّر قابليّة النقر:
`player.Cards.Any(DoesCardHasAllowedSpecialMove)` ⇒ `Enable`/`Disable`.

**إيقاف الوضع** — كل المستدعين ✅: نهاية الشوط · إخفاء الحاجب · أي نقرة على حجر أو ورقة ·
فتح المتجر · `SawaButtons.SendSawa` · `JackarooHand.ResetPlay`.

## ٥. أنيميشن الحرق ✅

```csharp
// JackarooMarbleMono.PlayBurnAnimation @0x51DFDE8
darkSmoke.Play();
Material m = new Material(burnMarbleMaterial);       // ⚠️ نسخة جديدة لكل استدعاء
MarbleImage.material = m;
MarbleImage.SetAtlasRectInfo("_TextureRect");
MarbleImage.material
    .DOFloat(1.0f, animationProperty /* Shader.PropertyToID("_Animation") */, burnEffectDuration)
    .SetEase(burnEffectCurve)
    .OnComplete(() => {
        MarbleImage.material = AnimatedItemController.GetDefaultCardMaterial();
        CoroutineDummy.WaitForSeconds(0.5f, () => darkSmoke.Stop());       // ⭐ 0.5 ث
    });
```
**القيم الافتراضية من البانِي** @`0x51E01D0` ✅: `burnEffectDuration = 2.0` ·
`_fireModeLabelDefaultLocalPosition = (0, 50, 0)` · `_plantEffectTime = 1.0` · `_defaultDuration = 0.7`.

> ⭐ **الأصول محلّية لا من المتجر**: `burnEffectCurve` · `burnMarbleMaterial` · `darkSmoke`
> كلّها `[SerializeField]` على الـprefab ⇒ **أنيميشن الحرق موجود دائمًا حتى لو كان المتجر فارغًا**.
> الذي يأتي من المتجر هو **prefab التأثير `ICustomMarbleMove`** فقط.

### ⭐ تجميع تسميات السعر المتقاربة
`CollectNearbyMarbles` @`0x5323700` — **flood-fill تعاوديّ** بشرط
`(a.pos − b.pos).sqrMagnitude <= _checkRadius²`، ثم `GroupFireModeLabelForGroup` @`0x5323A2C`:
```csharp
foreach (var m in group) m.HideFireMode(onlyLabel: true);   // ⭐ يُبقي FireModeActive = true
group[0].ShowFireMode(price, new Vector3(sumX / group.Count,
                                         maxY + _yFireModeOffset,
                                         group[0].pos.z));
```
> ⭐ **تسمية واحدة مشتركة للعنقود**: أفقيًّا عند متوسّط `x`، وفوق أعلى حجر بمقدار `_yFireModeOffset`.
> وسبب إبقاء `FireModeActive = true` أن **مُنتقي التكبير** (`JackarooZoomInPicker`) ما زال يحتاج `FireModePrice`.

## ٦. الربط بـ`CustomDeath` ✅

**`PlayBurnAnimation` له مستدعٍ واحد في الثنائي كلّه**: `SpecialKingMarbleMove.CustomDeath` @`0x53179F0`.

> ⇒ أنيميشن الحرق **ليس واجهة وضع النار** — هو **أنيميشن موت الحجر المأكول** الذي يشغّله الملك
> الناريّ بدل `MoveMarbleToGraveyard`. والسلسلة كاملة:
> **شراء وضع النار على أكل-المسار ⇒ `SpecialKingMarbleMove` ⇒ `CustomDeath` ⇒ `PlayBurnAnimation`
> على كل حجر مأكول.** (تفاصيل `CustomDeath` في [١٠ §٤](10-نهاية-الشوط-والاحتفال.md).)
