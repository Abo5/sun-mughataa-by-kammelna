## ١. مولّد المدى الدوّار — `ArraysExtensions.GetCycledRange` ✅

المُعدِّد @`0x449F0C8`:
```csharp
sign  = (count >= 1) ? +1 : -1;
count = |count|;
for (i = 0; i < count; i++)
    yield array[(start + len + sign*(i+1)) % len];
```

> ⭐ **لا تُرجع خانة البداية** — تبدأ من `start+1`. ومع `count` سالبة تسير للخلف (ورقة ٤).

```asm
IntegerExtensions.GetRotatedNextIndex @0x4EC1D7C
  range = max − min;  result = ((index − min + steps) mod range) + min
```
`GetLocalNode(index, steps)` = `Nodes[GetRotatedNextIndex(index, steps, 0, 76)]` — لفّ بمقياس **٧٦**.

## ٢. مولّد المسار — `GetWalkingNodes` @`0x51CABA0` ✅

```csharp
GetLocalWalkingNodes(marble, count, rp) =>
    GetWalkingNodes(Nodes, NodesAndBases.IndexOf(marble.Node), count, marble, rp);

IEnumerable<JackarooNode> GetWalkingNodes(nodes, start, count, marble, rp)
{
    int mpi = marble.PlayerIndex;
    if (IsSameSide(mpi, rp))                        // حجري أو حجر شريكي
    {
        if (marble.Node.Type == Base)
            return GetWalkingNodesFromBase(marble, count);

        int entry = GetPlayerEntryIndex(mpi);
        if (count >= 1 && start <= entry && start + count > entry)
            return GetWalkingNodesEnteringBase(nodes, start, count, mpi, entry);
    }
    return nodes.GetCycledRange(start, count);      // مسار عادي مع اللفّ
}
```

## ٣. ⭐ دخول القاعدة — `GetWalkingNodesEnteringBase` @`0x51CAF18` ✅

```csharp
if (count + start > entry + 4) return _emptyList;                    // تجاوز ⇒ حركة غير قانونية
int stepsOnRing = entry - start;
var list = nodes.GetCycledRange(start, stepsOnRing).ToList();         // حتى المدخل تمامًا
list.AddRange(_basesNodes[(5-mpi)%4].GetCycledRange(3, count - stepsOnRing));
```

> ⭐ **قاعدة ثابتة**: من يعبر مدخل قاعدته **يجب** أن يدخلها ولا يجوز التجاوز —

## ٤. الحركة داخل القاعدة — `GetWalkingNodesFromBase` @`0x51CAD5C` ✅

```csharp
if (count >= 5)                  return _emptyList;
if (IsMarbleInLastBase(marble))  return _emptyList;      // الخانة الرابعة ⇒ لا حركة
var baseNodes = _basesNodes[(5 - marble.PlayerIndex) % 4];
int idx = baseNodes.IndexOf(marble.Node);
if (count >= 4 - idx)            return _emptyList;      // يُسمح فقط بـ count ≤ 3−idx
return baseNodes.Skip(idx + 1).Take(count);
```
> **داخل القاعدة يجب أن تكون العُدّة مضبوطة تمامًا؛ لا تجاوز.**

## ٥. فحص قابلية المسار — `AreNodesWalkable` @`0x51E5688` ✅

مُوزِّع حسب نوع الحركة:

| الحركة | القيمة | المُعالِج |
|---|---|---|
| `MOVE`, `MOVE_REVERSE`, `MOVE_ANY`, `MOVE_CHOICE_1`, `MOVE_CHOICE_11` | 1,2,4,16,32 | `AreNodesWalkableForMove` |
| كل الـ SPLITs | 0x40…0x1000 | `AreNodesWalkableForMove` |
| `MOVE_EAT_PATH` | 8 | `AreNodesWalkableForMOVE_EAT_PATH` |
| غير ذلك (`SWAP`…) | — | `ArgumentOutOfRangeException` |

### ٥.١ مسار الشايب «آكل الطريق» — `AreNodesWalkableForMOVE_EAT_PATH` @`0x51E57B0` ✅

```csharp
foreach (node in nodes) {
    var m = node.Marble;
    if (m == null) continue;
    if (board.IsMarbleAtHome(m)) {                 // حجر جالس على بيته = محميّ
        onGuardedMarbleAdded?.Invoke(card, m.MarbleMono);
        return false;                              // الطريق مسدود
    }
    if (node.Type == Base) return false;           // لا يدخل قاعدة أحد
}
return true;                                       // وكل ما على المسار يُؤكَل
```

### ٥.٢ الحركة العادية — `AreNodesWalkableForMove` @`0x51E59B0` ✅

```csharp
lastNode = nodes.Last();                           // الوجهة — تُحسب قبل أي عكس
if (action == MOVE_REVERSE) nodes.Reverse();
JackarooMarble prev = null;

foreach (node in nodes) {
    var m = node.Marble;
    if (m == null) { prev = null; continue; }

    if (isLastIteration && node.Type == Base) return false;     // لا هبوط على خانة قاعدة مشغولة

    // ① حجب بنفس اللون
    if (!HasRuleFlag(DISABLE_SAME_COLOR_MARBLE_BLOCK /*0x40000*/))
        if (marbleToMove.PlayerIndex == m.PlayerIndex && m.Node != lastNode)
            return false;

    // ② حجب مدخل القاعدة
    if (IsBaseEntryBlocked(board, rp, marbleToMove, node, lastNode, action)) return false;

    // ③ حجر محميّ على بيته
    if (board.IsMarbleAtHome(m)) {
        if (isLastIteration) onGuardedMarbleAdded?.Invoke(card, m.MarbleMono);
        return false;
    }

    // ④ حجران متتاليان
    var previousMarble = (action == MOVE_REVERSE)
                       ? board.PreviousLocalNode(node).Marble : prev;
    if (IsBlockedByTwoMarbles(m, previousMarble)) return false;

    prev = m;
}
if (action == MOVE_REVERSE) nodes.Reverse();       // استرجاع الترتيب
return true;
```

> ⚠️ العكس يقع **بعد** حساب `lastNode`، فيصبح الفحص من الوجهة نحو الأقرب.
> 🟡 قد يكون مقصودًا أو أثرًا للمترجم — يستحق التحقق عند إعادة البناء.

## ٦. شروط الحجب الأربعة ✅

```csharp
// @0x51E5F40
IsBlockedInBase(node) => node.Type == Base;

// @0x51E4F68 — IsMarbleAtHome @0x51CA954
IsBlockedByHome(board, m) => m.Node == _homesAndBasesEntryNodes[m.PlayerIndex-1].Item1;

// @0x51E5D4C
IsBlockedBySameColorMarble(m, marbleToMove, lastNode) {
    if (HasRuleFlag(DISABLE_SAME_COLOR_MARBLE_BLOCK)) return false;
    if (m.PlayerIndex != marbleToMove.PlayerIndex)   return false;
    if (m.Node == lastNode)                          return false;   // ⭐ الهبوط على حجرك مسموح
    return true;                                                      //    والعبور فوقه ممنوع
}

// @0x51E4F80
IsBlockedByTwoMarbles(marble, previousMarble) {
    if (previousMarble == null) return false;
    if (HasRuleFlag(DISABLE_BLOCKED_BY_TWO_CONSECUTIVE_MARBLES /*0x20000*/)) return false;
    if (HasRuleFlag(BLOCKED_BY_TWO_CONSECUTIVE_MARBLES_SAME_COLOR /*0x10000*/))
        return previousMarble.PlayerIndex == marble.PlayerIndex;
    return true;
}

// @0x51E5E08
IsBaseEntryBlocked(board, rp, marbleToMove, node, lastNode, action) {
    if (action == MOVE_REVERSE)                              return false;
    if (HasRuleFlag(DISABLE_BASE_ENTRY_BLOCKING /*0x8000*/))  return false;
    if (node.Type != BaseEntry)                               return false;
    int mpi = marbleToMove.PlayerIndex;
    if (mpi != rp && mpi != board.GetTeamMateIndex(rp))       return false;
    return !(board.GetBaseEntryNode(mpi) == node && node == lastNode);
    // ⇒ العبور فوق مدخل قاعدتك ممنوع؛ يجب التوقّف عليه بالضبط
}
```

## ٨. خلاصة القواعد الثابتة

1. **الهبوط على حجرك مسموح** (فيُؤكَل)، بينما **العبور فوقه ممنوع** — ما لم يُفعَّل `DISABLE_SAME_COLOR_MARBLE_BLOCK`.
2. **الحجر على بيته محميّ مطلقًا**: لا يُعبَر ولا يُؤكَل ولا يُبدَّل ولا يُحرَّك بورقة ٥ — ويُبلَّغ عنه عبر `onGuardedMarbleAdded` لتمييزه في الواجهة.
3. **لا تجاوز لمدخل قاعدتك**: إمّا الدخول بالعدد المضبوط أو تُرفض الحركة. الاستثناء الوحيد `MOVE_REVERSE`.
4. **ورقة ٤ بعدد خطوات سالب (−4)** تمرّ عبر `GetCycledRange` بقيمة سالبة، ولذلك تُستثنى من قواعد مدخل القاعدة.
5. **حاجز الحجرين المتتاليين** يمنع العبور (قابل للتعطيل أو للتقييد بنفس اللون عبر `jcr`).
