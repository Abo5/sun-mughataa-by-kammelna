## ١. ⭐⭐ التوزيع — الفجوة المُغلقة

### `DealerPileSO` ← `JackarooDealerPileConfig`

```json
{
  "_totalCardsPerPlayer": 13,
  "CardsPerBatch": [4, 4, 5],
  "PerspectiveFadeDuration": 0.17,
  "BatchFadeDuration":       0.05,
  "FadeInDuration":          0.10,
  "FadeInDurationMultiplier": 3.0,
  "FadeInEase":  12,          // OutQuart
  "PunchDuration":   0.20,
  "PunchStrength":   0.07,
  "PunchVibrato":    5,
  "PunchElasticity": 5.0,
  "PunchEase":  27            // OutBack
}
```

> ⭐⭐ **التوزيع ثلاث دفعات: ٤ ثم ٤ ثم ٥ = ١٣ ورقة لكل لاعب.**
> وهذا يربط مباشرةً بـ`jdp` في [٠٥ §٧.٢](05-البروتوكول.md): `jdp ∈ {0,1,2}` = عدد الدفعات المُنفَّذة،
> و`-1` = استنتِجها من أحجام اليد. و`_dealBatches.Length == 3`.

**الهاتف والتابلت متطابقان تمامًا** في هذا الإعداد ✅.

### 🛑 نتيجة سلبية قاطعة — نظام الكومة **حصريّ لجكارو**

مسحتُ **الحزم الـ٧٥٨ كلّها** عن أربعة أصناف، فكانت كل النتائج داخل مشهدَي جكارو وحدهما:

| الصنف | عدد النسخ | أين |
|---|---|---|
| `DealerPileSO` | 2 | مشهدا جكارو (هاتف + تابلت) فقط |
| `CardDistributorSO` | 2 | مشهدا جكارو فقط |
| `DealerPileVisuals` | 2 | مشهدا جكارو فقط |
| `PlayersPiles` | 4 | مشهدا جكارو فقط (٢ لكلٍّ) |

ومشهدا **البلوت والطرنيب لا يحتويان أيّ مكوّن** اسمه يتضمّن
`Distributor` أو `Pile` أو `Dealer` أو `Deal` — **صفر**.

> ⇒ **`CardsPerBatch` مُعطًى من ScriptableObject في جكارو وحده.**
> البلوت يستعمل الصنف الأساس `CardDistributor` (بدليل `GetUserboxByRotatedIndex` @`0x51C08A0`
> الموثَّقة في [بلوت ١٥](../baloot-spec/15-تدقيق-ARM64.md))، لكن **تقسيم دفعاته ليس مُدارًا بالبيانات**
> 🟡 — مصدره الكود أو مُسبَق غير مُفهرَس في Addressables.
> هذا يُقوّي ما ورد في [بلوت ٠٣](../baloot-spec/03-التوزيع-والمزايدة.md): تقسيم `3+2` **عرضيّ بحت**.

### `CardDistributorSO` ← `JackarooDistributorConfig`

```json
{
  "FirstDealDelay":      0.10,
  "CardFlightDuration":  0.50,
  "CardFlightEase":      12,     // OutQuart
  "DelayBetweenCards":   0.09,
  "GroundCardsGoToPile": true
}
```

⇒ الورقة تطير **٠.٥ ثانية** بـ`OutQuart`، والفاصل بين ورقة وأخرى **٠.٠٩ ثانية**،
وأول توزيع بعد تأخير **٠.١ ثانية**.

**زمن الدفعة الواحدة** 🟡 = `0.10 + (n − 1)×0.09 + 0.50` حيث `n` = عدد الأوراق في الدفعة
× ٤ لاعبين — يُدقَّق مقابل كود `CardDistributor` حين يُفكّ.

## ٢. ⭐ الجلّة — `JackarooMarbleMono` (مُسبَق `marble.prefab`)

```json
{
  "_jumpEndValue":   7.0,
  "_jumpPower":     25.0,
  "_numJumps":       1,
  "_snapping":       false,
  "_plantJumpPower": 50.0,
  "_moveSnapping":   false,
  "_scaleVector":  { "x": 1.0, "y": 1.0, "z": 0.0 },
  "_scalePower":     0.5,
  "_vibrato":        0,
  "_elasticity":     0.0,
  "_defaultDuration": 0.70,
  "_plantEffectTime": 1.0,
  "burnEffectDuration": 1.25
}
```

| القيمة | الدلالة |
|---|---|
| `_jumpPower = 25` · `_numJumps = 1` | حركة `DOJump` **قفزة واحدة** بارتفاع ٢٥ |
| `_plantJumpPower = 50` | **الزرع يقفز ضعف ارتفاع الحركة العادية** |
| `_defaultDuration = 0.70` | المدّة الافتراضية للحركة |
| `_vibrato = 0` · `_elasticity = 0` | **لا اهتزاز ولا مرونة** في نبضة المقياس |
| `_scalePower = 0.5` · `_scaleVector.z = 0` | النبضة في المستوى XY فقط |

### المنحنيات — بإطاراتها المفتاحية الحرفية

كلها `m_PreInfinity = m_PostInfinity = 2` (Clamp).

**`_plantMoveCurve`** — ٣ إطارات: الحركة تكتمل عند **٤١٪** من المدّة ثم تثبت.
```
(0.0000, 0.0000, in=2.419, out=2.419)
(0.4134, 1.0000, in=-0.109, out=0.000)
(1.0000, 1.0000, in= 0.000, out=0.000)
```

**`_plantJumpCurve`** — ٥ إطارات، بمسطّح واضح في المنتصف:
```
(0.0000, 0.0000, in=3.704, out=4.525)
(0.4188, 0.5000, in=0.230, out= 0.000)
(0.5000, 0.5000, in=0.000, out=-0.212)     ← ثبات عند نصف الارتفاع
(0.5921, 1.0000, in=0.066, out= 0.000)
(1.0000, 1.0000, in=0.000, out= 0.000)
```
> ⭐ **قفزة الزرع ليست قوسًا بسيطًا**: ترتفع إلى النصف، **تتعلّق ساكنة من 0.419 إلى 0.500**،
> ثم تُكمل. هذا ما يعطي الزرع إحساسه المميّز — لا يُختزل إلى `Ease`.

**`burnEffectCurve`** — ٨ إطارات، ارتداد متكرّر ثم اندفاع نهائي:
```
(0.0000, 0.0000, in=4.972) ; (0.0644, 0.3201, in=0.834) ; (0.1492, 0.0398, in= 4.256)
(0.2507, 0.3224, in=-0.014) ; (0.3628, 0.0269, in=-3.664) ; (0.3928, 0.3183, in=0.682)
(0.5175, 0.0832, in=4.639) ; (0.9978, 1.0000, in=0.113)
```
> **ثلاث ذبذبات** (‏0.32 → 0.04 → 0.32 → 0.03 → 0.32 → 0.08) ثم صعود إلى ١.٠ — على مدى **١.٢٥ ثانية**.

## ٣. ⭐ اللوح — `JackarooBoardMono`

```json
{
  "_plantReferenceMultiplier": 0.75,
  "_localPositionY":    0.0,
  "_localRotationX":   30.0,
  "_verticalOffset":   43.0,
  "_horizontalOffset": 43.0,
  "_baseVerticalOffset":   43.0,
  "_baseHorizontalOffset": 43.0,
  "_graveyardVerticalOffset":   60.0,
  "_graveyardHorizontalOffset": 60.0,
  "_swapAtSameTime": false,
  "_volume": 0.30,
  "startPitch": 0.75,
  "endPitch":   1.50,
  "_blockedBaseFadeSpeed": 0.10,
  "_totalAnimationDuration": 2.0,
  "_delayBetweenFireworks":  0.10,
  "_fireworksAudioDelay":    0.20
}
```

| القيمة | الدلالة |
|---|---|
| **`_localRotationX = 30°`** | ⭐ **اللوح مائل ٣٠ درجة** — منظور شبه ثلاثي الأبعاد |
| `_verticalOffset = _horizontalOffset = 43` | تباعد عقد الحلقة |
| `_baseVerticalOffset = _baseHorizontalOffset = 43` | **القواعد بنفس تباعد الحلقة** |
| `_graveyard*Offset = 60` | ⭐ **المقبرة أوسع تباعدًا (٦٠)** من الحلقة والقواعد |
| **`_swapAtSameTime = false`** | ⭐⭐ **التبديل تتابعيّ لا متزامن** — الجلّتان تتحرّكان واحدة بعد الأخرى |
| `_plantReferenceMultiplier = 0.75` | معامل مرجع موضع الزرع |
| `_blockedBaseFadeSpeed = 0.10` | سرعة تلاشي مؤشّر «القاعدة محجوبة» |

**الصوت** ✅: `_volume = 0.3` مع **تدرّج الطبقة من `0.75` إلى `1.5`** —
أي أن صوت كل قفزة يرتفع تدريجيًّا عبر المسار (نمط «سُلّم صاعد»).

**الألعاب النارية** (عند إكمال لاعب لأحجاره الأربعة) ✅:
مدّة كلّية **٢.٠ ث** · فاصل بين الانفجارات **٠.١ ث** · تأخير الصوت **٠.٢ ث**.
