## ٣. ⭐ توقيت القفزة الواحدة

### `GetDurationForNodes(int nodesCount)` @`0x51D485C` (276 B) ✅

`FloatExtensions.Map(int v, float inMin, float inMax, float outMin, float outMax)` @`0x4EC1C30` (36 B) ✅ — **بلا أي تقييد (clamp)**:
```
slope = (outMax - outMin) / (inMax - inMin)
return v * slope + (outMin - inMin * slope)
```
⇒ **`GetDurationForNodes(N) = MinD + (N − 1)·(MaxD − MinD)/12`** ✅

* `get_MinDuration` @`0x51D3AA0` (136) و`get_MaxDuration` @`0x51D3FAC` (136) يقرآن الحقلين نفسيهما مباشرة.
* 🛑 **المدّتان ليستا حقلين مُسلسلين في المشهد** — تأتيان من `RemoteConfig` عبر `JackarooConfig`. لا تبحث عنهما في الـprefab.
* ✅ **الافتراضيان استُخرجا لاحقًا من بانِي `JackarooConfig` @`0x5186EF0`**:
  `0x7253200` = `9a 99 99 3e | 00 00 20 40` ⇒ **`MinD = 0.3` ث** و**`MaxD = 2.5` ث**.
  التفصيل في [إعدادات الخادم §٢](../config-spec/01-RemoteConfig.md).

  ```
  GetDurationForNodes(N) = 0.3 + (N − 1) × 0.18333…
  N=1 → 0.300 ث · N=4 → 0.850 · N=7 → 1.400 · N=13 → 2.500
  ```

### الإجابة الصريحة: هل المسار تغريدة واحدة أم عقدة‑بعقدة؟ ✅

**عقدة بعقدة.** في `Move` @`0x51D2CCC–0x51D2D30`:
```

```
ثم `MoveMarble` يُنشئ **`Sequence` مستقلًّا لكل قفزة**، ويُعيد استدعاء نفسه من `onComplete` بـ`index+1` (§٥). فالمدّة الكلّية للمسار = `GetDurationForNodes(N)` بالضبط، موزَّعة بالتساوي على `N` قفزات، كل قفزة `Sequence` منفصل بالكامل.

| السياق | المدّة المُمرَّرة إلى `MoveMarble` |
|---|---|
| `Move` (عادي/تقسيم/أكل‑مسار) | `GetDurationForNodes(N)/N` لكل قفزة ✅ |
| المرحلة الثانية من `HandleSplitMove` | `GetDurationForNodes(N2)/N2` (يُعاد الحساب) ✅ |
| `Plant` | `2 × MinMarbleMoveDuration` ✅ (ثم يُضرب ×0.5 داخل `MoveMarble` ⇒ الفعلي = `MinD`) |
| `Swap` (كلا الشكلين) | `2 × MinMarbleMoveDuration` لكل حجر ✅ |
| `MoveMarbleToGraveyard` | `MinMarbleMoveDuration` (بلا مضاعفة) ✅ |

## ١٥. ما لم أحسمه

1. **`DOTween.defaultEaseType` العام** — `SpecialMarblePlant.Move` و`SpecialKingMarbleMove.OnArrived` و`JackarooMarbleMono.DoLocalMove` لا تستدعي `SetEase`؛ سلوكها يعتمد على الإعداد العام الذي يُهيَّأ في مكان لم أفكّكه (مُهيّئ `DOTween`/`DOTweenSettings` asset). **لم أتحقّق من قيمته**، فلا تفترض `OutQuad` الافتراضية بلا تأكيد.
2. ~~بقية مواضع استدعاء `onGuardedMarbleAdded`~~ — ✅ **حُسم: ستّة مواضع بالضبط**، انظر [§١٧](#١٧--تصحيحات-محسومة-).
   🛑 **وتصحيح**: `0x51E58F0` و`0x51E5B8C` **مواضع نداء داخل الدوالّ لا بداياتها** — تحقّقتُ بنفسي:
   الأولى `+0x140` داخل `AreNodesWalkableForMOVE_EAT_PATH` (البداية `0x51E57B0`)،
   والثانية `+0x1DC` داخل `AreNodesWalkableForMove` (البداية `0x51E59B0`).
3. ~~شرط `nodes.Count == 1`~~ — ✅ **حُسم: المعنى «آخر عقدة» (`isLastIteration`) فعلًا**، والشكّ كان في محلّه.
   انظر [§١٧](#١٧--تصحيحات-محسومة-).
4. ~~`CheckMarbleBlocksBase` فرع `Type == Base(3)`~~ — ✅ **حُسم بالكامل، والدلالة منطقيّة لا معكوسة**.
   انظر [§١٦](#١٦--حجب-مدخل-القاعدة--محسوم-) أدناه.

## ١٦. ⭐ حجب مدخل القاعدة — محسوم ✅

> كان البند ٤ في §١٥ موسومًا بأنه «يبدو معكوسًا حدسيًّا». **فُكّت الدالّة كاملة، والدلالة منطقيّة تمامًا.**

### البنية اللازمة ✅ (من `dump.cs`)
```csharp
class JackarooMarble { int PlayerIndex; /*0x10*/  JackarooMarbleMono MarbleMono; /*0x18*/  JackarooNode Node; /*0x20*/ }
class JackarooNode   { JackarooNodeType Type; /*0x10*/  JackarooNodeMono NodeMono; /*0x18*/  JackarooMarble Marble; /*0x20*/ }
class JackarooBoard  { … ValueTuple<JackarooNode, JackarooNode>[] _homesAndBasesEntryNodes; /*0x38*/ … }
```
> ⭐ **`_homesAndBasesEntryNodes` مصفوفة `ValueTuple` بطول ١٦ بايت لكل عنصر** — وهذا يفسّر
> `add x8, x8, w9, sxtw #4` (خطوة ١٦) و`ldr x8, [x8, #0x28]`:
> `Item1` @`+0x20` (مدخل البيت) و**`Item2` @`+0x28` (مدخل القاعدة)** لعنصر الفهرس `i`.

### ⭐⭐ البوّابة أوّلًا — قاعدة مخصّصة تُعطّل السلوك كلّه ✅
```asm
0x51D003C  ldr  x8, [JackarooRules_TypeInfo]
0x51D0040  ldr  x8, [x8, #0xb8]        ; الحقول الساكنة
0x51D0044  ldrb w8, [x8, #1]           ; البايت ١ من JackarooRules.AllowedRules
0x51D0048  tbnz w8, #7, →ret           ; البتّ ١٥
```
والبتّ ١٥ = القيمة **`32768`** = **`JackarooAllowedRules.DISABLE_BASE_ENTRY_BLOCKING`** ✅

> ⇒ **إن فُعِّلت القاعدة المخصّصة `DISABLE_BASE_ENTRY_BLOCKING` فالدالّة تخرج فورًا بلا أي أثر.**
> (انظر [٠٤ — القواعد المخصّصة](04-القواعد-المخصصة.md).)

### الشجرة الكاملة ✅
```csharp
private void CheckMarbleBlocksBase(JackarooMarble marble)   // @0x51CFFFC (428B)
{
    if (JackarooRules.AllowedRules.HasFlag(DISABLE_BASE_ENTRY_BLOCKING)) return;   // بتّ ١٥
    var entries = board._homesAndBasesEntryNodes;      // ValueTuple<Node,Node>[]

    switch (marble.Node.Type)
    {
    case 2:   // ⬅ الحجر واقف على عقدة مسار عاديّة
        // حلقة مفرودة على الفهارس ٠..٣ (العناصر عند 0x28 · 0x38 · 0x48 · 0x58)
        for (int i = 0; i < 4 && i < entries.Length; i++)
            if (entries[i].Item2.Marble == marble) {           // هل هو واقف على مدخل قاعدة اللاعب i+1؟
                if (marble.PlayerIndex == i + 1) return;       // ⬅ صاحب القاعدة نفسه ⇒ لا حجب
                BlockBase(i + 1);                              // ⬅ حجر أجنبيّ ⇒ احجب قاعدة اللاعب i+1
                return;
            }
        return;

    case 3:   // ⬅ الحجر داخل قاعدة
        var node = entries[marble.PlayerIndex - 1].Item2;      // مدخل قاعدة اللاعب نفسه
        var m    = node.Marble;
        if (m == null) return;                                 // المدخل خالٍ ⇒ لا شيء
        if (m.PlayerIndex == marble.PlayerIndex) return;       // حجر صاحب القاعدة ⇒ لا حجب
        BlockBase(marble.PlayerIndex);                         // ⬅ حجر أجنبيّ يسدّ مدخلي ⇒ احجب
        return;
    }
}
```
الخروج إلى `BlockBase` **نداء ذيليّ** (`mov x0, x19 ; b #0x51D7E40`) مع `w1` محمّلًا مسبقًا برقم اللاعب ✅.

### 🛑 لماذا لم تكن «معكوسة»
القراءة السابقة فهمت الفرع `Base(3)` على أنه «يحجب قاعدة صاحب الحجر». وهو كذلك **لكن بسبب وجيه**:
الدالّة تسأل **«هل مدخل قاعدتي مسدود بحجر أجنبيّ؟»** — فإن كان كذلك **تُحجَب قاعدتي أنا**،
لأنّي لا أستطيع الدخول إليها. والفرعان يقولان الشيء نفسه من جهتين:

| الفرع | السؤال | من يُحجَب |
|---|---|---|
| `Type == 2` (حجري على المسار) | هل أنا واقف على مدخل قاعدة **غيري**؟ | **صاحب تلك القاعدة** |
| `Type == 3` (حجري في القاعدة) | هل مدخل قاعدتي عليه حجر **أجنبيّ**؟ | **أنا** |

> ⭐ **القاعدة الواحدة**: *حجر أجنبيّ واقف على مدخل قاعدة ⇒ تُحجَب تلك القاعدة على صاحبها.*
> الفرعان مجرّد نقطتَي رصد مختلفتين للحالة نفسها. **انسخها كما هي — لا تعكسها.**
