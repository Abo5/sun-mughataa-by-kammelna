## ٢. المراحل — مُعاد استعمالها بلا تعديل ✅

جكارو **لا يُعرّف enum مراحل خاصًّا**؛ يستعمل `CardGameStages` كما هو:
`None=0 · Bidding=1 · Playing=2 · WaitingForEating=3 · InCheatCatch=4 · MoveNextRequired=5`

ولا يستدعي أي صنف `Jackaroo*` الدوالَّ `IsPlaying`/`IsBidding`/… البوّابة الوحيدة هي المشتركة:

```csharp
CardGamePlayer.CanPlayCard @0x5302C84 => KPlayer.CanPlay && Stage.CurrentStage == Playing(2);
KPlayer.CanPlay           @0x5316594 => Game.Mover == this.Index;      // مقعد مطلق 1..4
```
🛑 **تصحيح**: كان مكتوبًا «لا مستهلك للقيم 1/3/4/5». **غير صحيح.**
جاكارو **يلعب** عند `gStg = 2`، لكن **للقيم 1 و3 و5 مستهلكون أحياء** في مشهده ✅:

| المرحلة | المستهلك الحيّ |
|---|---|
| **1** Bidding | `Userbox.OnGameStatusUpdate` @`0x4FB9D80` — و**`JackarooUserbox.OnGameStatusUpdate` @`0x51EC354` يستدعي الأساس أوّلًا** (`bl #0x4FB9D80` @`0x51EC368`، تحقّقتُ بنفسي) |
| **2** Playing | `CardGamePlayer.CanPlayCard` @`0x5302C84` |
| **3** WaitingForEating | `GameStateUI.AcceptNext` · `CardGamePlayer.CanEat` · `Userbox.StartTimer` |
| **5** MoveNextRequired | `CardGamePlayer.ShouldAcceptNext` · `Userbox.StartTimer` |
| **4** InCheatCatch | 🟡 **الوحيدة بلا مستهلك معروف** (`get_IsCheatCatch` @`0x53037DC` بصفر مستدعٍ — لكنه جالب ١٦ بايت قابل للتضمين) |

> ⚠️ **ولا يمكن إثبات ما إذا كان الخادم يرسل 1/3/4/5 في غرف جاكارو** — ذلك سلوك خادم غير مرئيّ من العميل.

**موروثة وميتة في جاكارو**:

* 🛑 **`anp` — تصحيح معاكس**: **حيّ ومطلوب** — يُستهلك في `CardGamePlayer.ShouldAcceptNext`

**غائبة تمامًا** (بلوتية حصرًا) ✅: `prcs` · `dp` · `hc` · `fc` · `apcs` · `gm` · `gem`.

### 🛑 تصحيح: `brd2` **غير موجودة**

`JackarooGame` يُعرّف `private const string BOARD2 = "brd2";` لكن فحص جدول سلاسل il2cpp
يُظهر **صفر تطابق** للسلسلة `"brd2"`؛ السلاسل التي تبدأ بـ`brd` هي **`brd` وحدها**.

```

strings starting 'brd': ['brd']
'jdp' present: True   'jcr' present: True
```

## ٤. حمولة `last_action` ✅


```csharp
// JackarooGame.ParseLastActionInfo @0x51DC4BC ✅
var info = base.ParseLastActionInfo(p);
```

## ٥. ⭐ ترميز الجلول على السلك

### ٥.١ قراءة `brd` ✅
```csharp
// GetServerBoardMarbles @0x51DD218
_board = gameState.GetSFSArray("brd");
for (int i = 0; i < 4; i++) _p[i] = _board.GetIntArray(i);
```

`brd` = `SFSArray` من **٤ عناصر**، العنصر `i` = مواضع جلول اللاعب بالمقعد `i+1`.
كل عدد = **فهرس داخل `ServerNodesAndBases`** (`0..91`).

> ⭐ **الجلول في المقبرة لا تُذكر إطلاقًا** — طول المصفوفة = عدد الجلول على الرقعة (٠..٤).
> **لا يوجد ترميز sentinel للمقبرة.** ما ينقص من الأربعة فهو في المقبرة ضمنيًّا.

### ٥.٢ ⭐ التحقّق من الرقعة — `DoCheckWithServer` @`0x51D3128` (1800B) ✅

```
game_state → UpdateGameState → GetServerBoardMarbles (brd → _p)
                             → LastAction
                             → OnPlayerDidLastAction @0x51CBB94:
     if (LastAction.Action != "a_card_played") return;
     if (!game.IsNewLastAction) return;
     AddMarblesSnapShot();          // لقطة قبل الحركة
     AddToMovesQueue(lambda);
lambda @0x51D9780:
     if (!DoCheckWithServer(snap)) { ScreenManager.ReloadScene(); return; }
     DoPlayJackarooMove(ToJackarooMove(lastAction, …), …);
```

سلاسل التشخيص المقروءة حرفيًّا:
`"Miscount for player {0}. Server marbles count: {1} != Local marbles count: {2}"` ·
`"Player {0} local marble was not found"` ·
`"Player {0} sever marble was not found"` *(خطأ إملائي في الأصل)*

> ⭐ **العميل يعيد تمثيل الحركة محليًّا ثم يقارن الرقعة الناتجة بـ`brd`، وعند أي اختلاف
> يعيد تحميل المشهد بالكامل.** هذا يُثبت أن **`brd` هو مصدر الحقيقة الكامل**.

وردّ `a_card_played` لا يحمل حالة إطلاقًا — `OnPlayCard` @`0x51DD3C0`:
```csharp
string err = response.Get<string>("error");
if (!err.IsNullOrEmpty()) { Debug.LogError("OnPlayCard error: " + err); ScreenManager.ReloadScene(); }
```

### ٥.٣ كتابة `p1`/`p2` — `ToJackarooServerMove` @`0x51CBF70` ✅

```csharp
var sa = move.Action.ToJackarooServerAction();
int p1 = move.Marble1?.Node != null ? ServerNodesAndBases.IndexOf(move.Marble1.Node) : 0;
int p2 = (NeedsP2(sa) && move.Marble2 != null) ? ServerNodesAndBases.IndexOf(move.Marble2.Node) : 0;
if (p1 == -1) p1 = 0;
if (p2 == -1) p2 = 0;
```

* `p1`/`p2` = **موضع المصدر** لا الوجهة؛ الخادم يستنتج الوجهة من (الورقة + الفعل).
* عند الزرع الجلّة في المقبرة ⇒ `IndexOf` = `-1` ⇒ يُرسَل `0`.

> ⚠️ **`NeedsP2(a) = (a & 0xF) != 0`** @`0x51DD904` — تطبيق ساذج:
> يُرجع `true` لكل الأفعال ١..١٥ **و١٧** (لأن `17 & 15 == 1`)، و`false` للأفعال ٠ و١٦ و١٨.
> أي أن `p2` يُكتب أيضًا لأفعال لا تحتاجه (`MOVE`, `SWAP`, `BURN_MY_CARD`, `BURN_OTHER_CARD_RANDOM`).
> **يُحاكى حرفيًّا.**

## ٦. الأوامر الصادرة

### ٦.١ الخاصّة بجكارو — أمران فقط ✅

```csharp
// a_card_played — JackarooGame.SendToSfs @0x51DD5D8 (812B)
if (!CanPlayCard(player, m.Card)) return;
o.Put("card", m.Card.ToString());        // "s2" · "h10" · "dq" · "ck" · "sa"
o.PutInt("a",  (int)m.Action);           // 0..18
o.PutInt("p1", m.P1);
if (((int)m.Action & 0xF) != 0) o.PutInt("p2", m.P2);
if (emoteItemId.HasValue) o.Put("gact", emoteItemId.Value);
SFS.SendRoomExtensionRequest("a_card_played", o);

// a_card_thrown — JackarooGame.ThrowCard @0x51DD910 (252B)
o.Put("card", card.ToString());          // مفتاح واحد فقط
SFS.SendRoomExtensionRequest("a_card_thrown", o);
```

المستدعي الوحيد لـ`ThrowCard` هو `JackarooHand.TryPlayCard` @`0x531D178` تحت الشرط
`LastActionInfo.Action != "a_card_thrown"`.

✅ **الدلالة محسومة**: `LastActionInfo` = `JackarooGame.LastAction`، و**لا يُكتب إلّا من الخادم**
(`ParseLastActionInfo` @`0x51DC4BC` هو المستدعي الوحيد للـctor). و`DoPlayCard` @`0x531AC38`
**لا يرسل شيئًا** (بصريّ واقتصاديّ فقط) ⇒ `a_card_thrown` هو الأثر الشبكيّ الوحيد في ذلك الفرع.
⇒ 🟡 هو **حارس ضدّ إعادة الإرسال**: «لا تُرسل رميًا جديدًا ما دام أحدث فعل تعرفه من الخادم رميًا».

> ⚠️⚠️ **عقد خادم حرج**: `last_action` **عالميّ** (فعل أي لاعب، بلا مقارنة `ap`).
> ⇒ **يجب أن يستبدل خادمك `last_action.action` بقيمة غير `a_card_thrown` فور استهلاك الرمية**،
> وإلّا **فاللاعب التالي الذي يُجبَر على الحرق لن يستطيع إرسال رميته ويتجمّد الدور**.

> ⚠️ **`gact` على السلك معرّف عنصر متجر، لا قيمة `GameAction`** ✅
> (`ToGameActionId` @`0x51DDBD0` = `Store.GetStoreItem(itemId)?.GameAction`).

## ٧. ترتيب الأدوار والتوزيع

### ٧.١ الدور ✅
```csharp
// JackarooGame.GetNextPlayer @0x51DDA74
int next = p.Index.GetRotatedNextIndex(offset:1, min:1, max:5);
```
⇒ **تصاعديًّا بالمقعد المطلق: ١ → ٢ → ٣ → ٤ → ١.**

**جدول الفرق مُتحقَّق بايتًا ببايت** @`0x713BC70` (`CardGame.GetPlayerTeam` @`0x5300888`):
```
01 00 00 00  02 00 00 00  01 00 00 00  02 00 00 00   =  [1, 2, 1, 2]
```
⇒ الفريق ١ = المقعدان ١ و٣ · الفريق ٢ = المقعدان ٢ و٤ ⇒ **الأدوار تتناوب بين الفريقين.**

الدوران للعرض: `GetRotatedPlayerIndex` @`0x5300F8C` = `IsSpectator ? i : ((i − MySeat + 4) % 4) + 1`.

### ٧.٢ التوزيع ✅
```csharp
// CardDistributor.CheckAndTriggerNextBatch @0x51BF520
if (_lastTrackedMoveNumber >= 2 && mn == 1) {      // التفاف mn من ٤ إلى ١
    _batchIndex++;
    DealFrom(GetRotatedPlayerIndex(game.Dealer), _dealBatches[_batchIndex]);
}
```
⇒ **`mn` يدور ١..٤؛ وعودته إلى ١ هي إشارة «دفعة توزيع جديدة».**

```csharp
// JackarooCardDistributor.ResolveMidGamePileState @0x51C3CA4
int dp = jg.DealPhase;                    // ← "jdp"
if (dp >= 0) return Math.Min(dp, batchCount);
return ResolvePileStateFromHandSizes(jg, batchCount);
```
⇒ **`jdp` = عدد دفعات التوزيع المُنفَّذة (٠-based)، و`-1` = «غير معلوم، استنتجه من أحجام اليد».**

> ✅ **الفجوة مُغلقة** — `DealerPileSO` مُستخرَج من حزمة المشهد:
> **`_totalCardsPerPlayer = 13`** و**`CardsPerBatch = [4, 4, 5]`**

## ١٠. ترميز الورقة ✅

* **نصًّا** (`Card.ToString` @`0x53003C4`) = `FriendlyName(Suit) + FriendlyName(Rank)`
  * `Suit`: `s`(♠0) `h`(♥1) `c`(♣2) `d`(♦3) `none`(4)
  * `Rank`: `2..10` للقيم 0..8 · `j`=9 · `q`=10 · `k`=11 · `a`=12 · `none`=13
  * أمثلة: `s2` · `h10` · `dq` · `ck` · `sa`
