## ✅ ما تحقّقتُ منه بنفسي

| الادّعاء | النتيجة |
|---|---|
| مسارات REST الأربعة | ✅ كلها حيّة في `ScriptString`: `api/Hints/List` · `api/Notifications/Since` · `api/AppAnnouncements/Since` · `api/PushNotification/RegisterToken` |
| مفاتيح `Prefs` | ✅ `FCMToken` · `FCMTokenLastSync` · `NotificationViews` · `notification_popup_shown` |
| مفاتيح حمولة الـPush | ✅ `command` · `payload` · `game` · وكذلك `General` و`Private` |

### ⚠️ دقّة في النفي «لا جدولة محلية»

مسحي وجد **٤٢ دالّة** يطابق اسمها `iOSNotificationCenter`/`ScheduleNotification` — **لكن كلها
داخل تجميعة `Unity.Notifications.iOS` نفسها** (الـSDK مُصرَّف ضمن الثنائي)، لا في كود اللعبة.

> ⇒ **الصياغة الدقيقة**: حزمة إشعارات Unity لـiOS **موجودة ومُصرَّفة**، لكن **لا مُستدعي لها من
> كود اللعبة** عدا صنف واحد لطلب الإذن (`AppleNotificationPermissionChecker`).
> ⚠️ النفي يقوم على مسح تجميعات C#؛ لو استُدعيت عبر reflection أو من `AricoKamlena.dylib`
> المحقونة بإعادة التوقيع فلن تظهر. 🟡

## ١. الإشعارات المحلية

**العميل لا يجدول أي إشعار محلي** ✅ — لا `ScheduleNotification`، ولا `iOSNotification`،
ولا مُطلِقات زمنية أو تقويمية، ولا قنوات.

⇒ كل إشعار خارج التطبيق مصدره **FCM**، وكل إشعار داخله مصدره **مركز الإشعارات**.

### نافذة طلب الإذن — `NotificationPopUp` ✅

**بوّابة العرض** ✅:

## ٢. الإشعارات الفورية — Firebase Cloud Messaging ✅

**المزوّد**: FCM (`Firebase.Messaging.dll` مدمجة؛ `FirebaseApp.CheckAndFixDependenciesAsync`
@`0x28EEBA4` تُستدعى من `InitializeNotifications` @`0x52A45CC`).
⇒ **لا استعمال مباشر لـAPNs من كود اللعبة**؛ يصل عبر طبقة Firebase الأصلية. 🟡

### ثوابت `NotificationPermissionUtils` ✅

| الثابت | القيمة |
|---|---|
| `FCM_TOKEN_KEY` | `"FCMToken"` |
| `FCM_TOKEN_LAST_SYNC_KEY` | `"FCMTokenLastSync"` |
| `GET_TOKEN_MAX_ATTEMPTS` | **5** |
| `GET_TOKEN_RETRY_DELAY_SECONDS` | **3** |
| `TOKEN_SYNC_INTERVAL_DAYS` | **7** |

```csharp
// HandleNewToken @0x52A4AC8 (568B)
if (newToken.IsNullOrEmpty()) return;
if (Prefs["FCMToken"] == newToken && (Now − Prefs["FCMTokenLastSync"]) < TimeSpan.FromDays(7))
    return;                                   // لا إعادة تسجيل
RegisterToken(newToken);                      // يتطلّب LocalUser != null
```

**التسجيل**: `POST {BackendURL}api/PushNotification/RegisterToken` بجسم `{ "Token": string }`.

> 🔒 رمز FCM موجود ويُخزَّن في `Prefs["FCMToken"]`. **لم تُقرأ ولن تُطبع أي قيمة.**
> ولا توجد في الثنائي أسرار خادم FCM — المُرسِل يملكها لا العميل.

## ٤. `app_announcements`

**المُطبِّق**: `ListDeltaApplier<AppAnnouncementModel, int>` بمفتاح `a.Id` ·
**نقطة الدلتا**: `api/AppAnnouncements/Since` · **الختم**: `luaa` · **الكاش**: `Cached_AppAnnouncements`

```csharp
class AppAnnouncementModel {
  int Id@0x10; string Name@0x18; GameCategory Game@0x20; AppAnnouncementType Type@0x24;
  DateTime ShowDate@0x28, EndDate@0x30;
  TimeSpan? DayCycleStart@0x38, DayCycleEnd@0x48;
  RoutingCommand RoutingCommand@0x58; string RoutingParam@0x60;
  List<AppAnnouncementTimingViewModel> AnnouncementTimings@0x68;
  FileInfoModel ButtonImage@0x70; List<ClientFilter> Filters@0x78;
}
enum AppAnnouncementType { GrandGameMode = 0, FlashSale = 1 }
```

> ⭐ 🛑 **التوقيت المرجعي للنافذة اليومية هو UTC+3** — `fmov d0, #3.0` ثمّ `TimeSpan.FromHours` مُثبت
> في `IsActive()` @`0x51833B8` (أُعيد التحقّق بالتفكيك). **تصحيحٌ لقراءةٍ سابقة قالت UTC+2** — الترميز
> `0x1E611000` هو `3.0` لا `2.0`. من يبني على UTC+2 يعرض الإعلانات في ساعاتٍ خاطئة.

**أين تُعرض**: `GrandGameModesArea` (شريط الأنماط الكبرى) و`FlashSaleUI` (شارة العرض الخاطف).

### 🛑 نفي صارم — لا تتبّع «شوهد/رُفِض» للإعلانات ✅

لا حقول نظيرة لـ`timesToAppear`/`gapTicks`، ولا صنف نظير لـ`NotificationView`، ولا مفتاح `Prefs`.
الشيء الوحيد الشبيه هو `FlashSaleUI._isSeen` — **متغيّر ذاكرة يموت مع المشهد**، يمنع فقط
إعادة تشغيل أنيميشن الدخول ضمن الجلسة.

⇒ **الإخفاء زمنيّ بحت** عبر `IsActive()` و`RemoveExpiredAnnouncements()`.

## ٥. `hints` — 🛑 معماريّة مختلفة

> **`hints` ليس مُزامَنًا بالدلتا** كالمفتاحين الآخرين. مُطبِّقه **`SignalApplier`** —
> **لا حمولة على السلك، مجرّد إشارة «المحتوى تغيّر، أبطِل الكاش»**، والمحتوى يُجلَب **كاملًا**
> من `GET api/Hints/List`.
>
> ✅ **مؤكَّد ببنية الأصناف**: `SignalApplier` له **دالّتان فقط** (`.ctor` و`ApplyChanged`) —
> بلا `ApplyDelta` ولا `ApplyBlob`.

```csharp
class InGameHintModel { int Id@0x10; Games? Game@0x14/0x18; string Hint@0x20;
                        List<ClientFilter> Filters@0x28; }
```

## ٩. ما لم يُحسَم 🟡

1. ~~**`ListDeltaApplier.ApplyDelta`** — شكل ظرف الدلتا على السلك.~~ ✅ **حُسم في [`data-spec/05`](../data-spec/05-محرّك-الدلتا-مفكوكًا.md)**: الظرف `Upserts@+0x10` · `RemovedIds@+0x18` · `Cursor@+0x20`، والدمج upsert-by-id ثمّ `RemoveAll`. 🛑 وهناك أيضًا تصحيحُ قطبيّة `Merge`/`Replace`.
2. ~~طريقة HTTP لنقاط `…/Since` — استُنتجت GET.~~ ✅ **`GET` مُثبتًا** (`mov w0,#0 ; ret` @`0x4492A48`) — [`data-spec/05`](../data-spec/05-محرّك-الدلتا-مفكوكًا.md).
3. ~~اسم المفتاح الذي يُرسَل به `FcmToken` داخل حزمة الدخول.~~ 🛑 **السؤال مبنيّ على فرض خاطئ**:
   `FcmToken` **لا يُرسَل في حزمة الدخول** (`SFS.Login` @`0x5261E08` = ٧ مفاتيح، لا FCM). المسار الحقيقيّ
   `OnUserLoggedIn` @`0x52A4D00` → `HandleNewToken` → `RegisterToken` → **`POST api/PushNotification/RegisterToken`**
   بجسم **`{"Token": …}`** (بحرف كبير — لا `[JsonProperty]`). و`get_FcmToken` @`0x52A4318` مستدعيه الوحيد
   `LogoScript.PrintFCMToken` (تنقيح). *(اسم المفتاح عقد بروتوكول لا سرّ.)*
4. ~~`AppAnnouncementModel.IsActive()`.~~ ✅ **مفكوكة** — و🛑 **تصحيح**: النافذة `TimeSpan.FromHours(3.0)` =
   **UTC+3** لا `+2h` (الترميز `0x1E611000` ⇒ `fmov` واحدة). يجب تصحيح كلّ نافذة يوميّة لإعلانات التطبيق.
5. ~~`RoutingManager.ValidateAndNavigate` / `ShowConfirm`.~~ ✅ نافذة التأكيد تُعرض **إذا وفقط إذا** مرّ
   كلّ المتحقّقين **و**`p.MessageTitle` غير فارغ؛ وإلّا `Navigate` مباشرةً. 🚩 **رفضُ أيّ متحقّق ⇒ سقوطٌ صامت
   بلا رسالة**. زرّا النافذة `"Show"`/`"Back"`.
6. ~~أذونات iOS من `Info.plist`.~~ ✅ **قُرئت**: `UIBackgroundModes = [remote-notification, fetch]`،
   و`NSUserTrackingUsageDescription` = «يستخدم التتبع لتحسين جودة المحتوى الدعائي». و`aps-environment`
   في الاستحقاقات (entitlements) لا `Info.plist`، وهذه نسخة مُعاد توقيعها (ESign) فقد يُستبدَل. 📦
7. 📦 النفي «لا جدولة محلية» لا يغطّي reflection ولا `AricoKamlena.dylib` المحقونة — **خارج كود اللعبة** (dylib حَقَنها ESign)، لا يُنتزع من تجميعة اللعبة.
