## ٤. ⭐ رياضيات القوس — محلولة بالكامل

### ٤.١ الوالدان — مُتحقَّقان بكود الآلة ✅

```asm
GetFirstParentId  @0x5059974:  lsl w8, w0, #1 ; sub w0, w8, w1 ; ret       ⇒ 2m − N
GetSecondParentId @0x5059980:  mvn w8, w1 ; add w0, w8, w0, lsl #1 ; ret   ⇒ 2m − N − 1
```

| الدالة | الصيغة |
|---|---|
| `GetFirstParentId(m, N)` | **`2·m − N`** ✅ |
| `GetSecondParentId(m, N)` | **`2·m − N − 1`** ✅ |
| `GetNumberOfRounds(N)` | `Mathf.CeilToInt(Mathf.Log(N, 2))` — وتُعيد `int.MinValue` إن كان اللوغاريتم `+∞` ✅ |
| `GetMatchRound(m, N)` | `Mathf.CeilToInt(Mathf.Log((float)N / (float)(N − m), 2))` ✅ |

### ٤.٢ نموذج القوس 🟡→✅ (متّسق مع كل الصيغ)

* `N = TournamentData.Size` (قوّة عدد ٢).
* المباريات مرقّمة **١ … N−1**، والنهائي هو **`N−1`**.
* والدا المباراة `m` هما `2m−N` و`2m−N−1`؛ وإن كانا `≤ 0` فالمباراة من الجولة الأولى.
* الجولة الأولى = `m ∈ [1, N/2]`؛ الجولة `k` حيث `N/(N−m) ∈ (2^{k−1}, 2^k]`.
* تحقّق: `m = N−1` ⇒ الوالدان `N−2` و`N−3`، والجولة `= log₂(N)` أي الأخيرة ✅.

### ٤.٣ ⚠️ خلل مُتحقَّق — `GetNextMatchId` معطّلة

```asm
TournamentMath$$GetNextMatchId @0x505998C (48B)
  mov  w8, #-1
  mov  w9, #0x80000000 ; cmp w0, w9          ; matchId == int.MinValue ?
  mov  w9, #0x80000001 ; add w9, w1, w9      ; size + int.MinValue + 1
  add  w9, w9, w9, lsr #31 ; asr w9, w9, #1  ; ÷2 بإشارة
  csel w0, w8, w9, ne                        ; NE ⇒ −1 ، EQ ⇒ المحسوب
```

**ما تفعله فعلًا**: تُعيد **`−1` لكل مُدخل واقعي**. والتعبير المحسوب على فرع المساواة هو
انتشار ثوابت لـ`(matchId + size + 1) / 2` — وهو **بالضبط معكوس صيغتَي الوالدين** ✅.

**المستهلك الوحيد** `BracketUnit.GetNextMatch` @`0x501E420` — وقد أكّدتُ أنه يستدعيها
(`bl #0x505998c` @`0x501E478`) ⇒ `GetTournamentMatch(-1)` ⇒ **دائمًا `null`**.

> ⚠️ **التنقّل «إلى المباراة التالية» في شجرة القوس معطّل في هذه النسخة.**
> عند إعادة البناء استعمل **`(m + N + 1) / 2`**.
> 🟡 سبب قطبية الشرط المعكوسة غير محسوم؛ **ما تفعله الدالة** مُثبت بكود الآلة.

**المستهلكون الآخرون** ✅: `SFSKammelnaRoomExtensions.GetParentMatches` @`0x4ECDD60` =
`[GetTournamentMatch(FirstParent), GetTournamentMatch(SecondParent)]` بعد إسقاط الـnull.
