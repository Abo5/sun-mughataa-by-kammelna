# ٠٢ — مشروع اليوم (MiniGame)

[↩ الفهرس](README.md)

**سوليتير بمشاريع البلوت** ⚪: تُوزَّع لك **١٣ ورقة**، وتحاول إظهار مشروع، ولك تبديلات
تستبدل بها أوراقًا، ثم تطالب بجائزتك **أوراقًا ذهبية**.

```csharp
enum ProjectType { RankSequence=0, SuitsGroup=1 }           // ⚪ متتالية من نفس الشكل / مختلفة الشكل
struct ProjectConditions { ProjectType Type@0x0; Rank MaxRank@0x4; Rank MinRank@0x8; int Size@0xC }
enum MiniGameRewardTiers { TierOne=5, TierTwo=15, TierThree=50, TierFour=400 }
```
مستويات الجائزة مؤكَّدة من `MiniGameVisuals.PlayRewardSound` @`0x4F4B2E0` (272B):
`cmp #0x190 → TierFour` · `#0x32 → TierThree` · `#0xF → TierTwo` · وإلا `TierOne` ✅.

## ١. المحاولات والمهلة

* `MiniGameRemainingTrials` @`0x4F471F8` = `IsTesting ? 2 : GetMiniGameTrials()` ← **`mg_t`**.
* ⭐ **`mg_t` يُمنَح ويُستهلَك في الخادم حصريًّا** — لا مسار كتابة في العميل ✅.
* **التجديد اليوميّ** — `MiniGameNextTrialTime` @`0x4F4C450` (236B) ✅:
  ```csharp
  DateTime t = DateTime.UtcNow.AddHours(3).AddDays(1).Date;   // منتصف ليل UTC+3
  return (t - TimeSpan.FromHours(3)).ToLocalTime();
  ```
  ⇒ **التجديد عند منتصف الليل بتوقيت السعودية، لا بتوقيت الجهاز.**
* **المهلة بعد آخر محاولة** — `MiniGame.SendStart` @`0x4F43A38` (712B):
  `MiniGameDelay = min(Now + 3h, NextMidnight)` تُخزَّن في `Prefs["mini_game_projects_Delay"]`.
  و`DelayIsActive` @`0x4F46590` ⇒ **المشتركون معفَون**.

> ⚠️ **خلل**: `SecondsTillNextMiniGameTrial` @`0x4F46920` ينتهي بـ`fminnm s0, s0, #0` ⇒
> **`Mathf.Min(seconds, 0)`** فالنتيجة دائمًا ≤ 0. يبدو انقلابًا لـ`Max`.

> ⚠️ **ثلاثة أرقام متعارضة** لمدّة قفل الخروج: النصّ الثابت «12 hours» · الترجمة العربية «يوم» ·
> وكود `SendStart` «min(+3 ساعات، منتصف الليل)». 🟡 الأرجح كود `SendStart` لأنه الوحيد الذي يكتب.

## ٣. الأوامر — إضافة `mg`

| `cmd` | الحمولة | المُرسِل |
|---|---|---|
| `play` | — | `SendStart` @`0x4F43A38` |

| `clear` | — | `SendCleanup` @`0x4F44024` |

**الرد**: `{ cmd, success, rewards, cards, cards_per_move, remaining_moves, error? }`
**تعريفات الجوائز**: `rewards_definitions` بمفاتيح `name` `value` `type` `size` `min_rank` `max_rank`
— مُخزَّنة في `Dictionary<Games, …>` ⇒ **الجوائز تختلف بحسب اللعبة** ✅.

⚪ `unknown_command` · `user_cant_play` · `invalid_move` (في الترجمة فقط — لأن `ShowError`
@`0x4F44C10` يترجم **مفتاح الخطأ نفسه**).
