## ✅ ما تحقّقتُ منه بنفسي

```asm
SFSKammelnaUserExtensions$$GetFTHearts @0x4ED11F0 (108B)
  add x20, x20, #0x638      "ft_rl"
  bl  SFSExtensions$$GetVariable
  mov w8, #5
  sub w0, w8, w0            ; ⇒ Hearts = 5 − ft_rl          ✅

FastTrackConfig$$MatchMakerTimerSeconds @0x5187B1C (12B)
  ldr w8, [x0, #0x14] ; add w0, w8, #5 ; ret                ; ⇒ MaxWaitingTimeSeconds + 5  ✅

PlayerRank$$FastTrackAward(level, stage) @0x50B1AB0 (332B)
  sub  w20, w20, #1 ; sub w19, w19, #1
  orr  w8, w19, w20 ; tbnz w8, #0x1f, → 0                   ; كلاهما غير سالب
  bl   RemoteConfig$$get_Current
  ldr  x8, [x0, #0x58]                                       ; FastTrack
  ldr  x0, [x8, #0x18]                                       ; LevelStages
  bl   List<object>$$get_Item      (level−1)
  bl   List<int>$$get_Item         (stage−1)
  bl   PlayerRank$$.ctor(points, false)                      ✅
```

⇒ **`LevelStages[level−1][stage−1]` هو عدد نقاط الرتبة التي تمنحها تلك المرحلة** — لا عتبة تأهُّل.

## ١. البنية

**الاسم داخل التطبيق: «كأس كملنا»** ⚪. بطولة كأس فردية سريعة تُلعب على **خادم SFS منفصل**
(`Config.FTServerForCurrentGame` @`0x509C440`). الدخول بتذكرة.

| المستوى | المراحل |
|---|---|
| الأول (`ft_lvl = 1`) | **٦** |
| الثاني (`ft_lvl = 2`) | **٨** |

* المرحلة = **٥ جولات فوز** + **٥ قلوب**. الجولة = صفقة واحدة مستقلّة.
* تخسر قلبًا مع كل جولة مخسورة ⇒ أقصى ما تلعبه **٩ جولات** («Win 5 out of 9» ⚪).
* ⚪ أصحاب لقب المحترف فما فوق يبدأون من المستوى الثاني.

**تأكيدان مستقلّان للأرقام ٦ و٨**:
`FastTrackPopupManager.Show` @`0x52EADE8` يفحص `ft_lvl==1 && ft_s==6` (نهاية المستوى الأول)
و`ft_lvl==2 && ft_s==8` (إكمال الكأس)؛ ومشهد `(FastTrack) Topbar` فيه `FT rank 1 … FT rank 8`
و`Active 1 … Active 5` للقلوب.

| **١** | 1001 | 2501 | 4001 | 6001 | 8001 | 10500 | — | — |
| **٢** | 12501 | 15001 | 17501 | 20001 | 25001 | 30001 | 35001 | 40001 |

القيمة تُمرَّر لبانية `PlayerRank` فتتحوّل إلى رتبة/لقب — انظر
[هويّة اللاعب ٠١](../identity-spec/01-الرتب-والألقاب.md).
**طول كل قائمة = عدد مراحل المستوى** — لا حقل منفصل لعددها.

### سقف المطالبة: لا تتراجع رتبتك ✅
```csharp
// FastTrackClaimAward(level, stage) @0x50B1C9C (268B)
int mine = SFS.MySelf.GetRank().Points;
var award = FastTrackAward(level, stage);
return (mine > award.Points) ? new PlayerRank(mine, false) : award;
```

### `GetNearestFTAwardStage(points)` @`0x50B1DA8` (560B) ✅
```csharp
if (points == -1) points = SFS.MySelf.GetRank().Points;    // قيمة حارسة
for (lvlIdx = 0; lvlIdx < LevelStages.Count; lvlIdx++)
  for (stage = 1; stage-1 < LevelStages[lvlIdx].Count; stage++)
    if (points < LevelStages[lvlIdx][stage-1]) return new[]{ lvlIdx+1, stage };
return new[]{ -1, -1 };
```
⇒ أقرب مرحلة **جائزتها أعلى من نقاط اللاعب**؛ و`[-1,-1]` إن كان أعلى من كل الجوائز.

## ٦. 🟡 ميزة معطّلة: نافذة الفتح والإغلاق

مفاتيح الترجمة ⚪ `Fast Track opens daily from` · `Time until Fast Track starts` موجودة،
والحقول `openWindow`@`0xF0` · `UntilOpenDateToText`@`0xF8` · `UntilCloseDateToText`@`0x100` معرّفة —
لكن **لا واحدة من تلك السلاسل في `ScriptString`**، و`UpdateFTCloseSection` @`0x52E4858`
**٤ بايت** تقفز إلى `HideFTClosedSection`.
⇒ 🟡 الأرجح **ميزة ميتة في 3.9.5**؛ الإغلاق الفعليّ الوحيد من خطأ الخادم `server_is_closed`.
