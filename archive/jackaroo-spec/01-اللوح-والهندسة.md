## ٢. `InitializeBoard` @`0x51C8C64` ✅

```csharp
Nodes = Enumerable.Range(0, 76).Select(i => new JackarooNode(None)).ToList();
for (int p = 0; p < 4; p++) {
    _homesAndBasesEntryNodes[p] = CreateHomeAndBaseEntry(p);
    _basesNodes.Add(CreateNodeGroup(JackarooNodeType.Base, 4));
    _graveyardsNodes.Add(CreateNodeGroup(JackarooNodeType.Graveyard, 4));
}
NodesAndBases = Nodes.Concat(_basesNodes.Flatten()).ToList();   // 76 + 16 = 92
ResetServerNodes();
```

> `NodesAndBases` = **٩٢ عنصرًا**: `[0..75]` الحلقة، `[76..91]` القواعد.
> **المقابر ليست ضمن فضاء الفهارس المُرسَل للخادم.**

## ٣. ⭐ `CreateHomeAndBaseEntry` @`0x51C8F8C` — مُتحقَّق بكود الآلة ✅

```asm
; ① البيت
0x51C8FE4  mov   w8, #-0x13          ; −19
0x51C8FE8  mov   w9, #0x4c           ; 76
0x51C8FEC  madd  w8, w19, w8, w9     ; 76 − 19·playerIndex
0x51C8FF0  mov   w10, #0x1af3
0x51C8FF4  movk  w10, #0x6bca, lsl #16
0x51C8FF8  smull x10, w8, w10        ; قسمة سحرية على 76 (بإشارة)
0x51C8FFC  asr   x10, x10, #0x25
0x51C9000  add   w10, w10, w10, lsr #31
0x51C9004  msub  w21, w10, w9, w8    ; ⇒ homeIndex = (76 − 19·p) mod 76
0x51C9024  bl    JackarooNode$$SetType(node, 1)      ; Home

; ② مدخل القاعدة
0x51C9030  add   w8, w21, #0x4a      ; ⭐ homeIndex + 74
0x51C9034  sxth  w9, w8              ; حساب 16-بت بإشارة
…          msub  w8, w9, #0x4c, w8   ; mod 76
0x51C9080  bl    JackarooNode$$SetType(node, 2)      ; BaseEntry
```

```csharp
homeIndex      = (76 - 19*playerIndex) % 76;
baseEntryIndex = (homeIndex + 74)      % 76;         // = homeIndex − 2
```

> ⚠️ القسمة **بإشارة** (دلالات `%` في C#) وحساب مدخل القاعدة **١٦-بت**؛
> كلاهما بلا أثر للمدى `0..3` لكنه يُنسَخ كما هو عند إعادة البناء.

### الجدول الهندسي الناتج ✅

`rp` = `rotatedPlayerIndex` وهو **١-based** (١ = أنا دائمًا).

| rp | playerIndex | Home | BaseEntry | مجموعة القاعدة | المقبرة |
|---|---|---|---|---|---|
| **١ (أنا)** | 0 | **0** | **74** | 0 | 0 |
| ٢ (خصم) | 1 | **57** | **55** | 3 | 1 |
| ٣ (شريكي) | 2 | **38** | **36** | 2 | 2 |
| ٤ (خصم) | 3 | **19** | **17** | 1 | 3 |

* البيوت موزّعة كل **١٩** خانة.
* من البيت إلى مدخل القاعدة **٧٤ خطوة**، ثم **٤ خانات** داخل القاعدة ⇒ **٧٨ نقطة** للحجر الواحد.
* 🟡 **اتجاه سير الأحجار تصاعديّ في فهرس الحلقة**: `rp1(0) → rp4(19) → rp3(38) → rp2(57)` —
  أي **عكس** ترتيب الأدوار `1→2→3→4`.

## ٤. فهرسة القوائم ✅

```csharp
GetPlayerHomeNode(rp)        => _homesAndBasesEntryNodes[rp-1].Item1
GetBaseEntryNode(rp)         => _homesAndBasesEntryNodes[rp-1].Item2
GetPlayerGraveyardNodes(rp)  => _graveyardsNodes[rp-1]
GetBaseNodes(rp)             => _basesNodes[(5 - rp) % 4]
GetPlayerEntryIndex(rp)      => (93 - 19*rp) % 75          // @0x51C98EC
AreAllMarblesInBases(rp)     => _playersPlantedMarbles[rp-1].Count == 4
                              && كلها IsMarbleAtBase
```

### ⭐ لماذا `(5 − rp) % 4` للقواعد؟ — مُتحقَّق ✅

```asm
GetBaseStartIndex @0x51C9808
  mov   w8, #5
  sub   w8, w8, w1
  and   w9, w8, #3
  negs  w8, w8
  and   w8, w8, #3
  csneg w0, w9, w8, mi        ; مُعامل الباقي بإشارة C#
```

مجموعات القواعد مرتّبة حسب **موقع البيت على الحلقة** لا حسب رقم المقعد:
المجموعة `k` تخصّ اللاعب الذي بيته عند `19k`.

| rp | `(5−rp)%4` | بيت ذلك اللاعب |

| ١ | 0 | ring 0 ✅ |
| ٢ | 3 | ring 57 ✅ |
| ٣ | 2 | ring 38 ✅ |
| ٤ | 1 | ring 19 ✅ |

## ٥. الأنواع والكيانات ✅

```csharp
enum JackarooNodeType { None=0, Home=1, BaseEntry=2, Base=3, Graveyard=4 }

class JackarooNode   { Type @0x10;        NodeMono   @0x18;  Marble @0x20 }
class JackarooMarble { PlayerIndex @0x10; MarbleMono @0x18;  Node   @0x20 }
```

**موقع الحجر** = مرجع `JackarooNode` ثنائي الاتجاه (`node.Marble` ↔ `marble.Node`)؛
ويُحوَّل إلى `int` على السلك فقط. `PlayerIndex` **١-based ومُدوَّر**.

## ٦. فضاء فهارس الخادم — `ResetServerNodes` @`0x51C91CC` ✅

```csharp
_serverNodes         = Nodes.Rotate(19 * (_myPlayerIndex - 1));
_serverBases         = _basesNodes.Flatten().Rotate(4 * (_myPlayerIndex - 1));
_serverNodesAndBases = _serverNodes + _serverBases;                    // 92
GetNodeRelativeToServer(node) = _serverNodesAndBases.IndexOf(node);    // @0x51CA010
```

> العميل يدوّر اللوح ليكون «أنا» في الأسفل دائمًا: **١٩ خانة لكل مقعد** في الحلقة،
> و**٤ خانات لكل مقعد** في القواعد.
> إذن فهرس الخادم `0..75` = حلقة **مطلقة**، و`76..91` = القواعد بترتيب الحلقة.

**قراءة الحالة** — `SetBoardState(playerIndex, int[])` @`0x51CA0D0` ✅:
```csharp
if (!_isSpectator) playerIndex = GetPlayerRotatedIndex(playerIndex);  // ((pi − mySeat + 4) % 4) + 1
foreach (pos in marblesPositions) {
    var m = _playersGraveyardMarbles[playerIndex-1].First();
    MoveMarbleFromGraveyardListToPlantedList(m);
    var node = ServerNodesAndBases[pos];
    m.Node.SetMarble(null); m.SetNode(node); node.SetMarble(m);
}
```
> المصفوفة تحوي **فقط الأحجار على اللوح**؛ الباقي في المقبرة ضمنيًّا.
