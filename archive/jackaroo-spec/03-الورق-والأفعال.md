## ٥. ⭐ توليد الحركات — `GetAllowedJackarooMoves` @`0x51E268C` ✅

لكل ورقة في اليد، بهذا الترتيب:

```csharp
actions = IsCustomRule(card, AllowedRules, out a) ? a : card.GetDefaultJackarooActions();

if (actions & BURN_OTHER_CARD        && nextPlayerCards.Count > 0) Add(GetBurnCardMove(card, 0x8000));
if (actions & BURN_OTHER_CARD_RANDOM && nextPlayerCards.Count > 0) Add(GetBurnCardMove(card, 0x10000));
if (actions & STEAL                  && nextPlayerCards.Count > 0) Add(GetStealMove(card));
if (actions & PLANT)          GetAllowedPlantAction(...);
if (actions & SWAP)           GetAllowedSwapAction(...);
if (actions & MOVE_ANY)       GetAllowedMoveAnyAction(...);
if (actions & MOVE)           GetAllowedMoveAction(..., MOVE);
if (actions & MOVE_CHOICE_1)  GetAllowedMoveAction(..., MOVE_CHOICE_1);
if (actions & MOVE_CHOICE_11) GetAllowedMoveAction(..., MOVE_CHOICE_11);
if (actions & MOVE_REVERSE)   GetAllowedMoveReverseAction(...);
if (actions & MOVE_EAT_PATH)  GetAllowedMoveAction(..., MOVE_EAT_PATH);
if (actions & MOVE_SPLIT_7_0) GetAllowedMoveAction(..., MOVE_SPLIT_7_0);
if (card.Rank == SEVEN)       GetAllowedSplitMoveAction(...);

if (_allowedMoves.Count < 1)
    _allowedMoves = JackarooMove.GetBurnCardsMoves(cards);     // ⭐ مُجبَر على الحرق
```

> ⭐ **لا حركة قانونية ⇒ يجب حرق إحدى أوراقك (`BURN_MY_CARD`).**

### `GetAllowedSwapAction` @`0x51E3344` (الولد)
```csharp

others = board.GetAllPlantedMarblesExcept(rp);
// تصفية others: IsMarbleAtBase ⇒ تخطٍّ · IsMarbleAtHome ⇒ محميّ (تخطٍّ + cb) · IsBlockedByTwoMarbles ⇒ تخطٍّ
```

### `GetAllowedSplitMoveAction` @`0x51E434C` (السبعة)
لكل تقسيمة `(m1, m2)` → يحرّك `marble1` فعليًّا **مؤقتًا** عبر `SetNodeAndMarble` ليجرّب `marble2`،
ثم يُرجعه. قائمة `marble2` المرشّحة تأتي من `IsSharedFinal7`.
