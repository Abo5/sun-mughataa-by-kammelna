> ⛔ **ولا واحد منها يتّخذ قرار «انتهت اللعبة».** كل دوالّ النطاق التي تحمل `Win` في اسمها
> (`PlayWinAnimations` · `ResetWinAnimations` · `GetFirstWinnerIndex` · `ShowConfettiAnimation.PlayWin`)
> **عرضيّة بحتة**.

`GetFirstWinnerIndex` @`0x51D8364` **لا يحسب شيئًا** — يحوّل `WinnerTeamIndex` الجاهز إلى مقعد للعرض:
```csharp

if (s.WinnerTeamIndex == Game.MyTeamIndex)  return Game.MyPlayer.Index;
```

> ⭐ **الخلاصة**: قاعدة «٤+٤ جلول في الأمان» **مدعومة ببنية الشيفرة** (الخادم يرسل `ts1p1..ts2p2`
> = عدد جلول كل لاعب، وهي البنية المتوقَّعة للقاعدة) لكنّها **لا تُقيَّم في العميل**.
> العميل عارضٌ محض: يقرأ `winner`، ويحوّله إلى مقعد، ويشغّل الاحتفال.
>
> ⇒ **في نسختك: ضع التقييم على الخادم.** وإن أردت تقييمًا عميليًّا فهو **إضافة جديدة لا استعادة**.

## ٣. ⭐ احتفال اكتمال الأربع — `AllMarblesInBaseCelebrationIe` ✅

> ⚠️ **تنبيه منهجيّ**: `MoveNext` الحقيقيّ هو **`0x51D99D8`** (`d__215.MoveNext`)، و`0x51D6104`
> مجرّد **مصنع**. كلاهما بصفر مستدعٍ بمسح `BL` — وهو المتوقَّع للكوروتينات.

```csharp
var marbles = Board._playersPlantedMarbles[rot - 1].ToList();
marbles.Sort(by index in Board._basesNodes[(5 - rot) % 4]);

float volumeStep = _volume * 0.25f;                                // 0.3 × 0.25 = 0.075
float pitchStep  = (startPitch - endPitch) / (marbles.Count - 1);  // (0.75 − 1.5) / 3 = −0.25

for (int i = 0; i < marbles.Count; i++) {
    marbles[i].MarbleMono.PlayEntryEffect();
    GameSoundManager.Instance.PlayClipWithExtras(
        _baseEntryClip, _soundOptions,
        volume: volumeStep * (i + 1),      // 0.075 · 0.150 · 0.225 · 0.300
        pitch:  startPitch - pitchStep * i, // 0.75 · 1.00 · 1.25 · 1.50
        loop: false, autoReturn: true);
    yield return new WaitForSeconds(_delayBetweenFireworks + _fireworksAudioDelay);   // 0.3 ث
}
```
> ⭐ **أربع نبضات على `0.0 / 0.3 / 0.6 / 0.9` ث**، بصوت **يتصاعد خطّيًّا** وطبقة **صاعدة**.
> ✅ وهذا يحسم البند ٥ في [٠٨ §١٥](08-الأنيميشن-حركة-الجلول.md): **`startPitch`/`endPitch` مقروءان هنا**.
> ⚠️ القسمة على `Count − 1` تعني أن **جلّة واحدة تُسبّب قسمة على صفر** 🟡 — لكن الكوروتين
> لا يُستدعى إلّا عند اكتمال الأربع. **احرس القسمة في نسختك.**
