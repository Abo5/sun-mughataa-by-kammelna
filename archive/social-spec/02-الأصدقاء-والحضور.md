## ٤. الدعوة إلى الغرفة — عبر SignalR لا SFS ✅

```
InvitePanel.OnInviteRequested / SendInviteToAll
  → CoordinatorService.SendGameInvitations @0x5250590 (692B)
    → Hub "SendGameInvitations"(int[] userIds, int roomId, string password, int tournamentId)
```
يستخرج من الغرفة الحالية: `IsTournamentHub` ⇒ `GetTournamentInfo` + `GetTournamentPassword`،
وإلا `GetPassword`. ويرمي `NullReferenceException` @`0x5250824` إن لم توجد غرفة.

الوارد: `ReceiveGameInvitation` → `GameInvitationModel { serverId, userId, roomId, tournamentId, password, game }`.
**`InvitePanel.SecondsForReply = 15`** ✅
