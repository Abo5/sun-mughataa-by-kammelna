# ٠٦ — الملفّ الشخصي: طبقة التحكّم

[↩ الفهرس](README.md)

> `PlayerProfileControls` — ٦٩ دالّة، ~٢٠ ك.ب. **صنف عرض وتحكّم فقط — لا يحرّر شيئًا.**
> البيانات في [`identity-spec`](../identity-spec/README.md)، والأنماط في [`cosmetics-spec/01` §٥](../cosmetics-spec/01-طبقة-عرض-التجميليات.md).

## ✅ ما تحقّقتُ منه بنفسي
| الادّعاء | النتيجة |
|---|---|
| البلاغ الثاني **مزيّف** | ✅ `FakeReport` بلا أي طلب شبكة — `set_interactable(false)` + `CoroutineDummy` |
| `_alreadyReported` (@`0xE8`) لا يُصفَّر | ✅ لا كتابة في `ResetUi` |

## ١. ⭐ ما يملكه هذا الصنف فعلًا — **أربعة حقول مرئية فقط**

| الحقل | الإزاحة | من يكتبه |
|---|---|---|
| `avatar` | `0x20` | `PopulateProfile` |
| `bio` | `0x60` | `PopulateBio` + `ResetUi` |
| **`aces`** | `0xB0` | 🛑 **لا أحد** — يُقرأ فقط في `MuteAndZeroCurrency` |
| `_monthlyTrophyUISetter` | `0xD8` | `AnimateMonthlyTournamentTrophy` |

> ⭐ **الاسم واللقب والنمط وظهر الورق والرتبة والإعجابات والعشيرة كلّها تُرسَم داخل `AvatarInitializer`**، لا هنا.
> الجسر `AvatarData.op_Implicit(PlayerProfileModel)` @`0x50C5D30` يُسقِط:
> `Dbid · Username · CardbackId · TitleId · TitleLevel · PatternId · AvatarDate · FeaturedSlot ·
> Likes · AchievementsCount · TournamentPoints · EligibilityType · ClanId/ClanName · Rank`.

### تسلسل `Populate(PlayerProfileModel)` @`0x512A5B0` ✅
```csharp
ResetUi();  _profile = model;
PopulateProfile();                 // صورة + حدث Firebase
PopulateBio(_profile.bio);
StopLoading();
AnimateMonthlyTournamentTrophy();
UpdateButtonsState();              // ⭐ يقرأ _profile ⇒ الترتيب إلزاميّ
HandleButtonVisibility();          // زرّ التحدّي فقط
```

### ثلاثة مصادر للبيانات ✅
| المسار | الدالّة | المصدر |
|---|---|---|
| **أ — HTTP** | `Populate(string dbId, Action err)` @`0x512DDD0` | `GET api/Users/Profile/{0}?game={Games}` |
| **ب — SFS** | `PopulateFromSFS(string userId)` @`0x512ED54` | `GET api/Users/IsLiked/{id}` ثم بناء النموذج من `User` في الغرفة |
| **ج — بثّ** | `OnPlayerProfileLoaded` @`0x512DDA0` | يُعيد البناء **فقط إن طابق `userDbId`** |

> ⭐ **ارتداد مزدوج**: إن فشل SFS في إيجاد المستخدم في الغرفة ⇒ **طلب HTTP كامل**.
> وهذا ما يجعل الملفّ يفتح فورًا داخل الطاولة وببطء خارجها.

## ٢. ⭐⭐ شروط الإظهار والتفعيل — **العقد**

`UpdateButtonsState` @`0x512E8D0` ✅ — كلّها مفكوكة بايتيًّا:
```csharp
bool isFriend  = FriendsManager.IsFriend(id);
bool isBlocked = FriendsManager.IsBlocked(id);
bool isRecv    = FriendsManager.IsReceivedFriendship(id);
bool isSent    = FriendsManager.IsRequestedFriendship(id);
int  myId      = LocalUser.GetIntDbId();
```

| العنصر | الشرط |
|---|---|
| **`add.interactable`** | `(myId != id) && !isFriend && !isBlocked && !isSent` |
| `add` نصّه | `isFriend ? "Friend" : "Add"` |
| **`like.interactable`** | `(myId != id) && !isLiked` |
| `like` نصّه | `isLiked ? "Liked" : "Like"` |
| **`remove.SetActive`** | `isFriend \|\| isRecv \|\| isSent` |
| **`block` / `unblock`** | `!isBlocked` / `isBlocked` (متبادلان) |
| `report` · `gift` · `preview` | **`true` دائمًا، بلا أي شرط** |

> ⭐ **`isRecv` ليس ضمن قناع تعطيل `add`** بينما هو **ضمن** شرط إظهار `remove`.
> ⇒ عند طلب صداقة وارد: **`Add` يبقى قابلًا للنقر** (= قبول) و**`Remove` يظهر** (= رفض). **سلوك مقصود.**
>
> 🛑 **نفي صارم**: الأزرار الإشرافية الستّة (`mod` · `muteAndZeroCurrency` · `adminPage` ·
> `removeBio` · `removeAvatar` · `generateBadge`) **لا تُظهَر ولا تُخفى من هنا إطلاقًا**.
> الإظهار الإشرافيّ يتمّ في `PlayerProfile` عبر `ObjectToggler`ات
> (`myProfileToggler` · `kickAndMuteToggler` · `editProfileToggler` · `privateInfoToggler` · `muteBeggarToggler`)
> — 🟡 منطقها لم يُفكّ، والأرجح `Can(pe, …)` (انظر [`lobby-spec/06` §٣](../lobby-spec/06-واجهة-البطولات.md)).

### ⭐ إخفاء «تبليغ» في البطولات الخاصّة ✅
```csharp
// Start @0x512DA74
if (CurrentRoom.GetTournamentInfo()?.Type == TournamentType.Private)
    report.gameObject.SetActive(false);
```
> ⚠️ **`SetActive(false)` لا `interactable`** — و`ResetUi` يلمس `interactable` فقط
> ⇒ **لا يُعاد إظهاره أبدًا** في تلك الجلسة.

### زرّ التحدّي — مسار مستقلّ ✅
```csharp
HandleButtonVisibility():
  إن كان RemoteConfig.Current.FriendlyChallenge.Enabled && !IsMyProfile ⇒ إظهار، وإلّا إخفاء
ConfigChanged() @0x512DCFC  ==  b HandleButtonVisibility        // ٤ بايت
```
> ⭐ مربوط بـ`RemoteConfig.OnChanged` ⇒ **يُعاد تقييمه حيًّا** — إطفاء الميزة عن بُعد بلا إعادة تشغيل.
> **ابنِ زرّك على قناة حدث لا على قراءة لمرّة واحدة.**

## ٣. 🛑 البلاغ الثاني **مزيّف** — أهمّ اكتشاف سلوكيّ

```csharp
// Report @0x512F310
if (_alreadyReported) { FakeReport(); return; }          // ⭐⭐
var m = TrollingReportModel.MakeDefaultInstance();
m.ReportedPlayerId  = Convert.ToInt64(_profile.userDbId);
m.ChatRecord        = "سجل المحادثة\n" + ChatHandler.GetChatText();
KammelnaRequests.SendTrollingReport(m, cb);              // POST api/CustomerSupport/ReportTrolling

// FakeReport @0x512F4B0 — تحقّقتُ منه بنفسي
report.interactable = false;
CoroutineDummy.WaitForSeconds(1.0f, () => PopupWindow.ShowInfo("Done", "Report Success", "OK"));
```

> ⭐⭐ **بلاغ وهميّ مقصود**: **بلا أي طلب شبكة** — تأخير ثانية ثم نافذة نجاح كاذبة.
> ⚠️⚠️ و**`_alreadyReported` (@`0xE8`) لا يُصفَّر في `ResetUi`** ⇒ **الإبلاغ عن لاعب ثانٍ مختلف
> في نفس نسخة الواجهة يذهب أيضًا إلى `FakeReport`.** أي: **بلاغ حقيقيّ واحد فقط لكل عمر مكوّن.**
>
> 🟡 خطورته تعتمد على دورة حياة الـprefab (هل يُعاد استعماله أم يُدمَّر؟) — لم تُفحَص.
> **في نسختك: صفّر العلم في `ResetUi`.**

## ٤. الأفعال ونقاط النهاية

| الفعل | الطريقة | المسار |
|---|---|---|
| قراءة الملف | GET | `api/Users/Profile/{0}?game=` |
| هل أعجبتُه | GET | `api/Users/IsLiked/{id}` |
| إعجاب | POST | `api/Users/LikeUser/{0}` |
| بلاغ إزعاج | POST | `api/CustomerSupport/ReportTrolling` |
| عقاب متسوّل | POST | `api/Moderators/PunishBeggar` |
| حذف نبذة | DELETE | `api/Moderators/RemovePlayerBio/{0}` |
| حذف صورة | DELETE | `api/Moderators/RemoveAvatar/{0}` |

وبالتفويض إلى `FriendsManager` (تطابق [٠٢](02-الأصدقاء-والحضور.md) ✅):
`POST api/Friend/Add|Block|Unblock/{0}` · `DELETE api/Friend/Remove/{0}`.

**أمر SFS واحد فقط**: `SFS.AnnounceBeggarBan(message, userId)` @`0x52631C8` بعد نجاح `PunishBeggar`.
⇒ الإعجاب والإضافة والحظر والحذف والتبليغ **كلّها HTTP**.

### ⭐ العميل يعرف مسبقًا أي مسار صداقة سيُستعمل ✅
```csharp
// Add @0x512F120 — الرسالة تُحسَم قبل الردّ
string msg = FriendsManager.IsReceivedFriendship(id) ? "Friend added successfully"
           : LocalUser.Can(UserPermission.ForceFriend /*16384*/) ? "Friend added successfully"
           : "Friend request sent successfully";
```
> ⇒ **إضافة لـ[٠٢ §٢](02-الأصدقاء-والحضور.md)**: التمييز بين `Add` و`ForceAdd` معروف للعميل
> عبر صلاحية `ForceFriend = 0x4000` في قناع `pe`.

### ⚠️ سلوك خاطئ في `Like`
```csharp
like.interactable = false;
KammelnaRequests.LikeUser(id, cb);
// النجاح: likes++ محليًّا · isLiked = true · إعادة تعبئة
// الفشل: ⚠️ لا شيء إطلاقًا — لا رسالة ولا إعادة تفعيل الزرّ
```
> ⇒ **الزرّ يبقى ميتًا حتى إعادة التعبئة** عند أي فشل شبكة. لا تنسخ هذا.

### الأفعال الإشرافية
`MuteAndZeroCurrency` @`0x5130030` يبني `BanRequestModel` بـ**`Duration = 3` مشفَّرًا**
و`Reason = "Currency Begging"`، ورسالة الإعلان:
⚪ `"تم تصفير {0} للتسول مع امتلاك {1} ورقة ذهبية"`
> ⚠️ **الرسالة تُبنى من `aces.text`** — وهو نصّ واجهة **لا يكتبه هذا الصنف** ⇒ اعتماد هشّ على مكوّن شقيق.

`OpenAdminPage` @`0x5130464` ✅:
```csharp
var ub = new UriBuilder(Config.BackendURL);
ub.Host = "admin." + ub.Host;                       // ⭐ قاعدة اشتقاق نطاق الإدارة
KUtil.OpenURL(ub.ToString() + "Users/" + userDbId);
```

## ٥. «ملفّي» مقابل «ملفّ غيري»

| المكان | ملفّي | ملفّ غيري |
|---|---|---|
| `PopulateProfile` | `InitializeMyAvatar()` — بلا تتبّع | `Initialize(AvatarData)` + `FirebaseTrack.Event("Visited_Profile")` |
| نبذة فارغة | ⚪ «Click here to add about me» | ⚪ «About me not available» |
| `add` / `like` | **معطَّلان** (`myId != id` يفشل) | يخضعان لبقية الشروط |
| زرّ التحدّي | **مخفيّ** | يظهر إن كان مفعَّلًا |

> ⚠️ **ازدواج**: `get_IsMyProfile` @`0x512CFC4` و`ThisIsMyProfile` @`0x512EF18`
> **متطابقتان بايتًا ببايت** (١٥٦ بايت لكلٍّ). صيغتان لنفس الشيء.

## ٧. الثوابت والكود الميّت

| الثابت | القيمة |
|---|---|
| حدّ النبذة | **٢٠٠** |
| إخفاء طبقة الحجب | `DOFade(0, **0.3**)` |
| **مهلة البلاغ الوهميّ** | **١٫٠ ث** |
| `BanRequestModel.Duration` | **٣** |
| `UserPermission.ForceFriend` | **16384** (`0x4000`) |
| `KammelnaError.UserNotFound` | **2000** |

**ميّت مؤكَّد** (خاصّتان غير ظاهريّتين، صفر مراجع، **ولا فتحة `Method$…`**) ✅:
`GetReportChatRecord` @`0x512F5F8` · `get_BioDefault` @`0x512D060` — **منطقهما منسوخ حرفيًّا**
داخل `Report` و`PopulateBio` (أثر تضمين لم يُحذف).

> ⚠️ **ليست ميتة رغم صفر مراجع**: `Like` · `Add` · `Report` · `Gift` · `Block` · `UnBlock` ·
> `Remove` · `Preview` · `Mod` · `MuteAndZeroCurrency` · … — **كلّها مربوطة برمجيًّا في `Awake`**
> عبر ١٥ `AddListener`، ولها فتحات `Method$…` مؤكَّدة.
> (يوافق التنقيح المسجَّل في [`replay-spec`](../replay-spec/README.md).)

🟡 **حقل شبه ميّت**: `aces` (@`0xB0`) **يُقرأ ولا يُكتَب** في هذا الصنف
⇒ إن لم يملأه مكوّن شقيق فرسالة إعلان الحظر تخرج بنصّ فارغ.
