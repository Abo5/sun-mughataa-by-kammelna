## ✅ ما تحقّقتُ منه بنفسي قبل الدمج

| الادّعاء | النتيجة |
|---|---|

| `[Clans] ConnectToClan() — no-op.` | ✅ موجودة حرفيًّا |
| `?serverId=` (لاحقة رابط الـHub) | ✅ موجودة |
| `ccbv` و`rcbs` ليسا اجتماعيّين | ✅ **تقاطع مستقلّ**: [تدقيق الاقتصاد](../economy-spec/02-تدقيق-ARM64.md) أثبت أنهما `SendClaimCurrencyBomb` و`GetRecentGiftBombs` — عميلان مختلفان وصلا للنتيجة نفسها |

## ١. ⭐⭐ الحقيقة المعمارية: **ثلاثة نواقل لا واحد**

خلافًا لطبقة الردهة (كلّها `ExtensionRequest`)، الطبقة الاجتماعية موزّعة على:

| الناقل | ما يحمله | نقطة الدخول |
|---|---|---|
| **① SFS2X** | دردشة الغرفة/العامة/العشيرة · الكتم داخل اللعبة · الرسائل المثبّتة · الإيموتات | `SendZoneExtensionRequest` @`0x5261CC8` · `SendRoomExtensionRequest` @`0x5261B2C` |
| **② SignalR WebSocket Hub** ("Coordinator") | **الرسائل الخاصّة** · الحضور · حالة الأصدقاء · دعوات الغرف · **دفع أحداث العشيرة** | `SignalRWebSocketConnector.Connect` @`0x5253EDC` (1708B) · `SetHandlers` @`0x5254590` (2032B) |
| **③ HTTP REST** | الأصدقاء · الحظر · التبليغ · **نظام العشائر كاملًا (٤٢ مسارًا)** | `KammelnaRequests` · `ClanServerConnector` |

**رابط الـHub**: `hostUrl + "?serverId=" + serverId` ✅ (السلسلة مؤكَّدة @`0x5253FE0`).

> ⭐ **أي إعادة تنفيذ للخادم تحتاج Hub بـ١٨ طريقة واردة و٦ صادرة** — لا يكفي SFS.

## ٣. نموذج الرسالة `ChatMessageData` ✅

`.ctor(ISFSObject)` @`0x5083AC4` (664B) · `ToSFSObject(User)` @`0x5083E80` (980B)

| مفتاح | النوع | الحقل | الإزاحة |
|---|---|---|---|
| **`s`** | SFSObject متداخل | **`PlayerInfo` المرسل بالكامل** | — |
| `msg` | UtfString | `Message` | `0x20` |
| `t` | Long | `Timestamp` | `0x50` |
| `tag` | UtfString | `Tag` (اسم القناة) | `0x40` |
| `g` | Bool | `IsGenerated` | `0x29` |
| `i` | Int enum | `Ink` | `0x48` |

> ⭐ **لا تضارب** بين `i` هنا و`i` في `PlayerInfo`: الأخير **متداخل تحت `s`**
> (`param.GetSFSObject("s")` ثم `new PlayerInfo(...)` — تسلسل `0x5083B94→0x5083C1C`).

```csharp
enum ChatInk { Clean=0, Admin=1, Moderator=2, MonthlyWinner=3,
               Bomber=4, BomberWeeklyTop1=5, BomberWeeklyTop2=6, BomberWeeklyTop3=7 }
```
يُحسب في `GetInk` @`0x508399C` من متغيّر المستخدم **`in`**.

## ٤. ⭐ أمر `chat` واحد يخدم كل القنوات

```
SFS.SendChatMessage @0x52630E8 (224B) → Zone "chat"  { msg, tag }
```
(قفزة ذيلية `b #0x5261CC8` @`0x52631C4`)

| القناة | `tag` |
|---|---|
| الدردشة العامة | `"الدردشة_العامة"` (`ChatHandler.PublicChatGroupTag`) |
| دردشة العشيرة | **`"clan_{clanId}"`** — `ClanUtils.GetClanChatTag` @`0x5245E10` |
| كشف قناة عشيرة | بادئة `"clan_"` — `IsClanChatTag` @`0x5245E8C` |
| غرفة اللعب | 🟡 يُضبط في `ChatHandler.OnJoinRoom` @`0x50830A0` |

**تنقية اسم القناة** @`0x50812BC`: `Regex.Replace(tag, "<[^>]+>|&nbsp;|#", "")` ثم `Trim()` ثم `" " → "_"`.

**سلسلة الاستدعاء**:
```
BaseChatbox.Update @0x50FBCC4 (76B)  ← Enter فقط
  BaseChatbox.SendChat @0x50FBD10 (332B)  ← تنقية + رفض الفارغ
    PublicChatBox / ClanChatBox / MiniPublicChat → ChatHandler.SendChat @0x508040C (796B)
    PrivateChatBox → FriendsManager.HandleSendMessage  ⚠️ SignalR لا SFS
```

## ٥. الاستقبال والبوّابات

| الحدث | المعالج |
|---|---|
| `PublicMessage` | `SFS_OnPublicMessage` @`0x525F0C4` (560B) → `ChatHandler.OnPublicMessage` @`0x50824DC` (1232B) |
| `AdminMessage` | `SFS_OnAdminMessage` @`0x52617C4` (592B) — مفتاح `message`، يمرّ بالترجمة، مجموعة `"Admin"` |

`OnPublicMessage` **يُسقط رسائل المحظورين** (`IsBlocked` مرّتين @`0x5082678`, `0x5082690`)
ويقصّ القائمة عند **٢٠٠** رسالة.

**`ChatHandler.CanSend`** @`0x507F2A8` (776B) يجمع: `IsModerator` (يتجاوز كل شيء) ·
`IsChatDisabled` ← متغيّر الغرفة **`ce`** · `GetMuteStatus` ← متغيّر المستخدم **`ms`** ·
`IsSubscribed` مع `IsPublicChatSubsLocked` من `RemoteConfig` · وحالة الغرفة.

## ٦. ⚠️ التنقية والحدود

`StringUtil.SanitizeChatMessage` @`0x4EE9B5C` (416B) · `IsAllowedChatCharacter` @`0x4EE9814` (504B):
* يقبل `^[a-zA-Z0-9 ]*$` والحروف العربية والتشكيل
* **يحذف الأزواج البديلة** (`Char.IsSurrogate` @`0x4EE9A9C`) ⇒ **الإيموجي خارج BMP يُجرَّد من الرسالة** ⭐

**الحدود**: `MaxMessagesPerChannel = 200` · `FriendsManager.MaximumMessages = 200`.

> ⚠️ **لا تحديد معدّل على العميل إطلاقًا** — مُتحقَّق: `BaseChatbox.Update` ٧٦ بايت وجسمه
> كاملًا `IsSubmitted → SendChat → FocusInputField`. أي حماية من الإغراق **خادمية بالكامل**.

## ٨. ⭐ الرسائل الخاصّة — عبر SignalR لا SFS

```csharp
class PrivateMessageModel { string message@0x10; int sender@0x18;
                            long timestamp@0x20; bool isRead@0x28; string channelId@0x30; }
```

**عقد الـHub** ✅:

| الاتجاه | الطريقة |
|---|---|
| صادر | `SendMessage` · `MarkChatMessagesAsRead` · `UpdateConnectionStatus` · `SendGameInvitations` · `UpdateFriendStatus` · `SetPresence` |
| وارد | `ReceiveMessage` · `ConnectionStatusUpdate` · `OnlineFriendsUpdate` · `ReceiveGameInvitation` · `RemoveFriend` · `UpdateFriendStatus` · `Disconnect` · `OnPresenceUpdate` · `ClientReceiveVariableUpdate` · `ClanFeedAdded` · `ClanFeedRemoved` · `ClanFeedPinChanged` · `ClanFeedLikeChanged` · `ClanMembershipChanged` · `ClanRosterChanged` · `ContentBlob` · `ContentDelta` · `ContentChanged` |

**التخزين المحلّي**: `chats/{userId}.json` و`.archive.json`.

> ⚠️ `PrivateChatBox.SfsOnAdminMessage` @`0x510A57C` **٨ بايت** ⇒ دالّة فارغة —
