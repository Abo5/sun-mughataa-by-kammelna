## ست نتائج جوهرية

1. ⭐⭐ **البناء عربيّ فقط فعليًّا**: `"EN"` **غير موجودة في `ScriptString`**، و`SetLanguage` بلا مستدعين ⇒ عناصر `<EN>` الـ٢٨٣٦ كود ميّت.
2. ⭐ **المفتاح المفقود يعود نصًّا حرفيًّا** + `LogWarning`.
3. ⭐ **بُعد ثالث للترجمة: اللعبة الحالية** — نفس المفتاح يعطي نصًّا مختلفًا، والقاموس يُعاد بناؤه عند التبديل.
4. ⭐ **قاعدة جمع CLDR العربية كاملة بستّ صيغ** مُنفَّذة في كود الآلة.
5. ⭐ **الاتجاه يُنفَّذ بعكس السلسلة يدويًّا** بعد `ArabicFixer` — لا محرّك BiDi.
6. ✅ **3024 مدخلًا، صفر تكرار، صفر فراغ** ⇒ رسالتا الخطأ الداخليّتان لا تُطلقان أبدًا.
