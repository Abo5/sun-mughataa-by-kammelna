```asm

  sub  w8, w0, #1
  cmp  w8, #2

```
⇒ **صحيح لـ`ShouldWatchAds(1)` و`ShouldPay(2)` فقط**؛ خطأ لـ`CanPlay(0)` و`MustPay(3)` ✅

## ١. المزوّد

**Google AdMob** وحده كمزوّد مباشر، مع **AppLovin** و**Facebook Audience Network** كإطارَي
وساطة داخل `.app/Frameworks` بلا أي استدعاء من كود C# ⇒ محوّلا mediation لـAdMob 🟡.

```csharp
enum AdSDK { Admob = 0, Generic = 1 }
```
> ⭐ **`Generic` ليس شبكة خارجية** بل **إعلان بيتيّ** داخل اللعبة:
> `GenericAdUi` بثابتين `GenericAdID = "Generic AD"` و`GenericAdURL = "misc/store_cards_ann"`.

**نقاط التكامل** كلها في `GoogleAdsManager.AdUnitHolder`: `SetRewardedAd` @`0x507A284` ·
`SetInterstitialAd` @`0x507A6F0` · `SetBannerAd` @`0x5079110`، وجسور الأحداث
`FireAdLoaded` @`0x507AB50` · `FireAdFailedToLoad` @`0x507AC00` · `FireUserEarnedReward` @`0x507AD0C` …

## ٢. جرد الإعلانات — البنية

```csharp
class Ad : ScriptableObject { string AdId@0x18; AdPlace AdPlace@0x20;
                              AdType AdType@0x24; Platform Platform@0x28; Games Game@0x2C; }
enum AdType  { Rewarded=0, Interstitial=1, Banner=2 }
enum AdPlace { MiniGame=0, RankedPlay=1, Testing=2, Offline=3 }
enum AdAction{ Start=0, Complete=1, Error=2, Loaded=3, Closed=4,
               FailedToLoad3Times=5, Request=6, Clicked=7 }
```

**`AdInventory.GetAd`** @`0x5074C30` ✅: أوّل `Ad` يحقّق تطابق `AdPlace` و`AdType` و`Platform`
و`Game == Preferences.CurrentGame`، حيث:
```csharp
targetPlatform = (KUtil.GetPlatform() == Huawei) ? Platform.Android : KUtil.GetPlatform();
```
> ⭐ **هواوي تستهلك وحدات أندرويد نفسها.**

### ⭐ المصفوفة — ٣٤ أصلًا

**٣٠ وحدة حقيقية** = ٢ منصّة × ٣ ألعاب × **٥ توليفات**، + **٤ وحدات اختبار**.

| الموضع | الأنواع المسموحة |
|---|---|
| `Offline` | **Banner فقط** |
| `MiniGame` | Rewarded + Interstitial |
| `RankedPlay` | Rewarded + Interstitial |
| `Testing` | Rewarded + Interstitial (مسجّلة تحت `Game = Baloot` لكلتا المنصّتين) |

> ⭐ **لا يوجد Banner إطلاقًا خارج `Offline`** ⇒ لا بانرات في الردهة ولا في الأونلاين.
> 🟡 ووضع الاختبار عمليًّا لا يعمل إلا في البلوت.

> 📌 **معرّفات الوحدات الإعلانية لم تُنقَل إلى هذا الأرشيف عمدًا.** هي معرّفات حساب AdMob
> الخاص بمالك التطبيق، ولا قيمة لها في إعادة البناء — **ستحتاج معرّفاتك أنت**. المهمّ هنا
> هو **البنية**: أيّ التوليفات موجودة وأيّها غائبة، وقاعدة اختيار الوحدة.
> (خطأ إملائي في أحد الأصول: `Android_Tarneeeb_Rewarded_MiniGame` بثلاث «e».)

## ٣. دورة الحياة ✅

```
Awake → SceneManager.sceneLoaded
OnSceneLoaded @0x5077DC8:
    GetAdUnit(Offline, Banner) → BannerView.Destroy()      ; تدمير بانر المشهد السابق
    GetRewardedAdPlace() → إن رجع قيمة: RequestRewardedVideo(adUnit)   ; ⭐ تحميل مسبق
كل Show*Ad ← يُغلَّف بـ IdfaPermission.Check(resume) @0x5079E48
إن كان جاهزًا يُعرض، وإلا SetShowWhenReady ثم Request*
  → AdLoaded @0x50795F4 يتحقّق IsShowAdWhenReady ويعرض مباشرة
```

**كل ردود نداء الـSDK تمرّ عبر الخيط الرئيسي** — كل `On*Event` تبني `Action` وتستدعي
`CoroutineDummy.WaitForMainThread` ✅.

### ⭐ `GetRewardedAdPlace` @`0x5077F78` (636B) — البوّابة المركزية

```csharp
if (scene == Menu(3) || scene == Game(4)) {
    var cond = LocalUser.GetPlayingCondition();              // متغيّر المستخدم pc
    if (!cond.CanWatchAds()) return null;                    // ← الفحص المُتحقَّق أعلاه

```

### الفشل الثلاثي والاحتياط ✅

`AdFailedToLoad` @`0x5079820`: `cmp w9, #2` ⇒ **العتبة ٣ محاولات**، ثم:

| الحالة | الاحتياط |
|---|---|
| `!NoPlayServices` | تأخير عشوائي (`Random.Range`) ثم **`ShowVidAds`** ⇒ **Interstitial بدل Rewarded** |
| `NoPlayServices` (هواوي) | **`GenericAdUi`** (إعلان بيتيّ) ثم إطلاق `OnAdComplete` + `OnAdClosed` يدويًّا ⇒ **تُمنح المكافأة رغم غياب إعلان حقيقي** |

> ⭐ و`AdClosed` @`0x5079B2C`: إن كان النوع `Interstitial` يبني `Reward("Interstitial", …)`
> ويستدعي `UserEarnedReward` ⇒ **الإنترستيشيال يُحتسب اكتمالًا ويمنح المكافأة عند الإغلاق.**

> ⚠️ **في المحرّر أو على WebGL يُحاكى فشل ثلاثي فورًا** (`ShowRewardedAd` @`0x5076DC4`).

## ٤. أين تحكم الإعلانات اللعب

### ٤.١ اللعب المصنَّف — المسار الكامل ✅

```
RankedPlayManager.PlayRanked @0x4F30A94
  if (State == CanPlay || RemainingTrials > 0) → playAction(skipAd: false)
  else if (State == MustPay)                   → مسار الدفع
  else  /* ShouldWatchAds | ShouldPay */       → skipAdPopup.Popup(watchAd, payCoins)

  ├ «شاهد إعلانًا» → b__1 @0x4F40B00 → MenuAdsHandler.ShowAd @0x4F31308
  │                   → adsController.ShowRewardedAd(AdPlace.RankedPlay)
  │                   → b__2: success ⇒ playAction(skipAd:false) · fail ⇒ errorCallback(PlayError)
  └ «ادفع لتخطّي» → g__PayToSkipAds @0x4F40460
                     → FirebaseTrack "Payed_To_Skip_Ad"
                        أو "Payed_To_Skip_Ad_While_Ad_Cant_Be_Shown"
                     → playAction(skipAd: TRUE) ⇒ ينعكس على SendFindMatch كـ sk=true
```

> 📌 **ملاحظة منهجية من العميل تستحقّ التسجيل**: مسار «شاهد إعلانًا» يستعمل **قفزة ذيلية `b`**
> لا `bl` — ولهذا لا يجد مسحُ `bl` وحده أي مستدعٍ لـ`MenuAdsHandler.ShowAd`.
> **عند البحث عن مستدعين، امسح `b` و`bl` معًا.**

**المهلة**: `OnAdClosed` @`0x4F31798` = `mov w1,#5 ; b TryToPlayGame` ⇒ **انتظار ٥ ثوانٍ**
لورود تأكيد المكافأة قبل القرار.

**الجائزة**: انضمامة واحدة لمباراة مصنَّفة. البديل النقدي `JoinGamePrice` (المفتاح `jp`).

## ٥. السقوف والإعفاءات

| الآلية | التفصيل |
|---|---|
| إعفاء المشترك — مشروع اليوم | `IsSubscribed(true)` في `GetRewardedAdPlace` ✅ |
| إعفاء المشترك — بانر الأوفلاين | خروج مبكر في `BaseBannerAd.Start` ✅ |
| إعفاء المشترك — المصنَّف | 🟡 غير مباشر عبر `RankedPlayCondition` من الخادم |
| عتبة الفشل | **٣** محاولات |
| تهدئة إعادة المحاولة | **عشوائية** (`Random.Range`) لا ثابتة ✅ (الحدّان لم يُستخرجا) |
| مهلة بعد إغلاق إعلان المصنَّف | **٥ ثوانٍ** |
| عتبات IDFA | **٣٠ / ٦٠ / ١٢٠** إعلانًا ناجحًا بلا IDFA ⇒ إعادة طلب إذن ATT (`IdfaPermission`) |

> ⭐ **نفي صارم: لا يوجد أي سقف تردّد زمنيّ محلّي** في `AdsController` ولا `GoogleAdsManager`.
> كل التقنين خادميّ (`pc` · `JoinsAllowed`) أو من حالة مشروع اليوم.

> 🟡 `_adsCompletedBySameUser` حقل ساكن مُعلن **بلا أي قراءة أو كتابة** — يبدو كودًا ميتًا.
