# ٠٤ — طبقات الضباب ومكدّس نوافذ URP

[↩ الفهرس](README.md)

> **كل نافذة تحصل على `Canvas` وكاميرا خاصّة بها، والضباب يُطبَّق على كاميرا الطبقة التي *تحتها*.**
> هذه هي الآليّة التي تجعل خلفية أي نافذة في اللعبة ضبابيّة دون لقطة شاشة ولا `RenderTexture` يدويّ.
> `UI.Popups.BlurLayersManager` — `Singleton<BlurLayersManager>` · ٣٦ دالّة.

## ✅ ما تحقّقتُ منه بنفسي
| الادّعاء | النتيجة |
|---|---|
| قيم الضباب المطبَّقة | ✅ `downsample=2` · `blurSize=9.0f` · `iterations=2` — وسائط حرفيّة @`0x51B0A44`–`0x51B0A50` |
| خطوة عمق الكاميرات | ✅ `fmov s9, #10.0` @`0x51AFB04` و`fmov s1, #10.0` @`0x51AF50C` |
| الشيدر المستخدَم | ✅ `"Hidden/FastBlur"` @`0x51B1138` |
| الطبقة الأساس | ✅ `CanvasLayerExtensions.GetCanvas(1)` = `CanvasLayer.SecondaryCanvas` @`0x51AF06C` |
| من يستدعي الواجهة العامّة | ✅ `PopupUI` · `MenuMoreButton` · `SlideAnimationHelper` — **عبر `b` لا `bl`** (انظر §٨) |

---

## ١. ⭐⭐ الفكرة الأساسيّة: الضباب على الطبقة السفلى

المدير يحتفظ بقائمة `List<Canvas> _blurLayers` مرتّبة بالعمق. عند إظهار نافذة على الطبقة `i`،
يُطلَب الضباب على **كاميرا الطبقة `LayerBelow(i)`** — لا على طبقة النافذة نفسها:

```
_blurLayers[0]  SecondaryCanvas   ← الأساس، تُضبَّب ولا تُضبِّب
_blurLayers[1]  [Canvas] BlurLayer 1   ← نافذة أولى هنا ⇒ الضباب على كاميرا الطبقة 0
_blurLayers[2]  [Canvas] BlurLayer 2   ← نافذة ثانية هنا ⇒ الضباب على كاميرا الطبقة 1
```

في `SyncBlurs` @`0x51B066C` (1,500B):
```asm
bl  BlurLayersManager$$LayerBelow      ; 0x51B085C
bl  UnityEngine.Canvas$$get_worldCamera
bl  BlurLayersManager$$GetCameraBlur   ; 0x51B086C
bl  HashSet<object>$$Add               ; ← مجموعة "الضباب المطلوب"
```

> ⭐ نتيجة مباشرة: **النافذة العلويّة لا تُضبَّب أبدًا**، وكل ما تحتها يُضبَّب طبقةً طبقةً.
> لا حاجة لأي لقطة شاشة، والحركة خلف الضباب تبقى حيّة.

## ٢. حالة المدير

| الحقل | الإزاحة | النوع |
|---|---|---|
| `_popupPlacements` | `0x18` | `Dictionary<Transform, PopupPlacement>` |
| `_activeBlurs` | `0x20` | `HashSet<BlurOptimized>` |
| `_blurLayers` | `0x28` | `List<Canvas>` |
| `_blurLayersParent` | `0x38` | `Transform` |

`PopupPlacement` صنف داخليّ بحقلين فقط: `readonly Canvas Layer` @`0x10` · `bool BlurSuppressed` @`0x18`.

> 🟡 `BlurSuppressed` هو ما يسمح لنافذة أن تسكن طبقة دون أن تطلب ضبابًا — وهو الفرق بين
> `AppendToLayer` (بلا ضباب) و`AddBlurLayer` (بضباب).

### التهيئة — `Clear` @`0x51AEF38` (600B)
تُستدعى من `OnAwake` @`0x51AEE60` ومن `OnSceneLoaded`:
1. `_popupPlacements = new Dictionary<>()` · `_activeBlurs = new HashSet<>()` · `_blurLayers = new List<>()`
2. `_blurLayers.Add( GetCanvas(SecondaryCanvas).GetComponent<Canvas>() )` — **الطبقة `0` قائمة في المشهد، ليست مُنشأة**
3. `_blurLayersParent = new GameObject("BlurLayersParent").transform`
4. `CreateBlurLayer().worldCamera.gameObject.SetActive(false)` — طبقة واحدة جاهزة **مُعطَّلة** سلفًا (`mov w1, #0` @`0x51AF16C`)

`OnAwake` يسجّل `SceneManager.sceneLoaded += OnSceneLoaded`، و`OnDestroy` @`0x51AF190` يفكّه.
> 🚩 `OnSceneLoaded` @`0x51B1C40` طوله **٤ بايت** — أي `ret` مجرّد. الاشتراك قائم والمعالج فارغ:
> المدير **لا يعيد تهيئة نفسه عند تحميل مشهد**، خلافًا لما يوحي به اسم الاشتراك.

## ٣. إنشاء الطبقة — `CreateBlurLayer` @`0x51AFDAC` (816B)

```
UIExtensions.CloneObjectWithoutChildren( _blurLayers.Last() )     ; 0x51AFE84
  ↓ ينسخ الـCanvas بلا أبنائه
Object.Instantiate( source.worldCamera )                          ; 0x51AFED8
clone.worldCamera = النسخة                                        ; 0x51AFEEC
clone.worldCamera.gameObject.tag = "Untagged"                     ; 0x51AFF1C
clone.worldCamera.TryGetComponent<?>() → Behaviour.enabled = false ; 0x51AFF58
clone.name              = "[Canvas] BlurLayer " + index           ; 0x51AFFA8
clone.worldCamera.name  = "[Camera] BlurLayer " + index           ; 0x51B0000
clone.worldCamera.depth = source.worldCamera.depth + ١٠           ; 0x51B0040
RegisterAsUrpOverlay( clone.worldCamera )                         ; 0x51B0050
_blurLayers.Add( clone )
```

> ⭐ الطبقة الجديدة **نسخة من الطبقة الأخيرة** لا من قالب — فتَرِث كل إعدادات `CanvasScaler`
> و`GraphicRaycaster` تلقائيًّا. `CloneObjectWithoutChildren` ضروريّ حتى لا تُنسَخ النوافذ الساكنة فيها.
>
> ⚠️ `tag = "Untagged"` مقصود: الكاميرا الأصليّة غالبًا `MainCamera`، ووجود وسمَي `MainCamera`
> يجعل `Camera.main` غير حتميّ.

| ثابت | القيمة | المصدر |
|---|---|---|
| `UntaggedTag` | `"Untagged"` | `private const string` |
| اسم الـCanvas | `"[Canvas] BlurLayer "` + رقم | `0x51AFE48` |
| اسم الكاميرا | `"[Camera] BlurLayer "` + رقم | `0x51AFE3C` |
| اسم الأب | `"BlurLayersParent"` | `0x51AF000` |
| خطوة العمق | **`10.0f`** | `0x51AF50C` · `0x51AFB04` |

## ٤. الضباب نفسه — `BlurOptimized` + `Hidden/FastBlur`

`GetCameraBlur(Camera)` @`0x51B10FC` (260B) — **يُنشئ عند الطلب لا في التهيئة**:
```asm
bl  Component$$TryGetComponent<BlurOptimized>   ; 0x51B1164
;  إن غاب:
bl  GameObject$$AddComponent<BlurOptimized>     ; 0x51B1188
bl  Behaviour$$set_enabled                      ; 0x51B119C
bl  UnityEngine.Shader$$Find  ← "Hidden/FastBlur" ; 0x51B11D4
```

`BlurOptimized` من `UnityStandardAssets.ImageEffects` (حزمة Standard Assets القديمة، لا URP).

### القيم المطبَّقة — وسائط حرفيّة في `SyncBlurs` @`0x51B0A44`
```asm
fmov s0, #9.00000000      ; size        = 9.0f
mov  w1, #2               ; downsample  = 2
mov  w2, #2               ; iterations  = 2
mov  v1.16b, v8.16b       ; duration    = وسيط SyncBlurs
bl   #0x4ed9d1c           ; UIExtensions.TweenShowBlur
```
التوقيع: `UIExtensions.TweenShowBlur(BlurOptimized blur, int downsample, float size, int iterations, float duration)`.

| المُعامل | القيمة | الأثر |
|---|---|---|
| `downsample` | **٢** | يُصغّر هدف العرض ٤× في كل بُعد قبل الطمس ⇒ الكلفة الأكبر من التوفير |
| `blurSize` | **٩.٠** | نصف قطر الطمس بالبكسل (على الهدف المصغَّر) |
| `blurIterations` | **٢** | مرّتا تمرير ⇒ توزيع أقرب إلى غاوسي |
| `duration` | **٠٫٤ ث** افتراضيًّا | من `AddBlurLayer(popup, duration = 0.4f, …)` |

`TweenShowBlur` @`0x4ED9D1C`: `blur.enabled = true` → `DOKill` → `DOTween.Sequence()` مع **ثلاثة `To` مُدمَجة بـ`Join`**
(عدد صحيح للـ`downsample`، عشريّ للـ`blurSize`، عدد صحيح للـ`iterations`) — أي أنّ الثلاثة تتحرّك معًا من الصفر.

`TweenHideBlur` @`0x4EDA010`: العكس بالضبط، `mov w2, #0` @`0x4EDA1EC` ⇒ الأهداف كلّها **صفر**، ثم
`onComplete` يُعطّل المكوّن (`<TweenHideBlur>b__6`).

> ⭐ الطمس **يُحرَّك ولا يُقلَّب** — لا `enabled = true/false` مفاجئ، بل `downsample` و`blurSize`
> و`iterations` تتسلّق من الصفر خلال ٠٫٤ ث. هذا سرّ نعومة الانتقال.

## ٥. ⭐⭐ المزامنة التفاضليّة — `SyncBlurs` @`0x51B066C`

الدالّة **لا تُشغّل ولا تُوقف شيئًا مباشرةً**؛ تبني المجموعة المطلوبة ثم تفاضلها مع القائمة الحاليّة:

```
١) desired = new HashSet<BlurOptimized>()
   لكل (popup, placement) في _popupPlacements:
       إن popup != null  و popup.gameObject.activeSelf  و !placement.BlurSuppressed:
           desired.Add( GetCameraBlur( LayerBelow(placement.Layer).worldCamera ) )

٢) لكل blur في _activeBlurs:            ; 0x51B0924
       إن !desired.Contains(blur):  TweenHideBlur(blur, duration)     ; 0x51B09A4

٣) لكل blur في desired:                 ; 0x51B09FC
       إن !_activeBlurs.Contains(blur): TweenShowBlur(blur, 2, 9.0f, 2, duration)  ; 0x51B0A5C

٤) _activeBlurs = desired               ; 0x51B0A70  (str x20, [x19])
```

> ⭐⭐ **هذه هي النقطة الهندسيّة الأهمّ في الملفّ كلّه.** كل الواجهة العامّة (`AddBlurLayer`،
> `RemoveBlurLayer`، `ShowBlur`، `HideBlur`) تعدّل الحالة ثم تنادي `SyncBlurs` وحدها.
> لا عدّادات مراجع، ولا `blurCount++/--` — ومن ثَمّ **لا يمكن أن تتسرّب طبقة ضباب** مهما كان
> ترتيب الفتح والإغلاق. أي إعادة بناء تتخلّى عن هذا النمط لصالح عدّاد سترتدّ إليها أخطاء «ضباب عالق».

الاستدعاءات: من `AddBlurLayer` · `RemoveBlurLayer` · `ShowBlur` · `HideBlur` — أربعة مواضع بلا استثناء.

## ٦. الطبقة السفلى والاحتلال

### `IsOccupied(Canvas)` @`0x51B1200` (604B)
طبقة محتلّة إذا كان في `_popupPlacements` مدخل `placement.Layer == layer` ونافذته
`!= null` و`gameObject.activeSelf`. **وإلّا** يُسأل `HasShownOccupant(layer.transform)`.

### `HasShownOccupant(Transform)` @`0x51B145C` (888B) — `static`
يُمرّ على أبناء الطبقة (`Transform.GetEnumerator` @`0x51B14E0`)، ولكل ابن:
`child.gameObject.activeSelf` ثم **`TryGetComponent` مرّتين** (`0x51B164C` و`0x51B1670`).

> 🟡 المكوّنان المطلوبان غير محدَّدين نصًّا في المقطع، لكن الدور واضح:
> ابن ظاهر يَحمل مكوّن نافذة ⇒ الطبقة محتلّة **حتى لو لم تُسجَّل في `_popupPlacements`**.
> هذا شبك أمان لنوافذ تُوضع في الطبقة يدويًّا في المشهد بدلًا من المرور بالمدير.

### `LayerBelow(Canvas)` @`0x51B0EA8` (596B)
ليس `index - 1` البسيط: يبحث عن الطبقة ذات **أعلى `worldCamera.depth` أقلّ من عمق الطبقة المعطاة**
(أربع قراءات `get_depth` في حلقة المقارنة @`0x51B0FCC`–`0x51B1028`)، مع تخطّي غير المحتلّ عبر `IsOccupied`.
ومثله `TopOccupiedLayer` @`0x51AF284` (أعلى عمق محتلّ) و`HighestLayerDepth` @`0x51B00DC` (أعلى عمق مطلقًا)
و`FirstFreeLayer` @`0x51AFCEC` (أوّل طبقة غير محتلّة، أو `null` فتُنشأ واحدة).

> ⭐ الترتيب المرجعيّ هو **عمق الكاميرا**، لا فهرس القائمة. لذلك يصحّ النظام حتى بعد
> `NormalizeLayerDepths` الذي يُعيد ترقيم الأعماق.

## ٧. ترتيب مكدّس URP

### `NormalizeLayerDepths` @`0x51AF8A0` (1,100B)
```
base = _blurLayers[0].worldCamera.depth                 ; 0x51AF990
rest = _blurLayers.Skip(1).OrderBy(c => c.worldCamera.depth)   ; 0x51AF9A4 + 0x51AFAC0
لكل i:  rest[i].worldCamera.depth = base + (i+1) × ١٠   ; fmov s9, #10.0 @0x51AFB04
```
> `Skip(1)` مقصود: الطبقة `0` هي `SecondaryCanvas` القائمة في المشهد ولا يجوز المساس بعمقها.

### `SyncUrpStackOrder` @`0x51B01F8` (1,140B)
```
baseCam = OnScreenBaseCamera.Resolve()                        ; 0x51B032C
stack   = baseCam.GetUniversalAdditionalCameraData().cameraStack  ; 0x51B0378 + 0x51B0384
indices = فهارس المكدّس التي IsBlurLayerCamera(stack[i])       ; 0x51B03FC / 0x51B04CC
sorted  = تلك الكاميرات مرتّبة OrderBy(depth).ToList()         ; 0x51B0590 + 0x51B05A0
لكل k:  stack[ indices[k] ] = sorted[k]                       ; 0x51B0614
```

> ⭐⭐ **يُعيد ترتيب كاميرات طبقات الضباب داخل `cameraStack` دون تحريك أي كاميرا أخرى.**
> الفهارس تُجمَع أوّلًا ثم تُكتب القيم في الفهارس نفسها — فتبقى كاميرات اللعب والمؤثّرات
> في مواضعها بالضبط. هذه الخطوة **إلزاميّة في URP**: عمق الكاميرا لا يحكم ترتيب العرض
> لكاميرات `Overlay`؛ ترتيبها في `cameraStack` هو ما يحكم.

`RegisterAsUrpOverlay(Camera)` @`0x51B17D4` (808B) — `static`: يحلّ الكاميرا الأساس بـ
`OnScreenBaseCamera.Resolve()` @`0x51B1804`، ويضيف الكاميرا الجديدة إلى مكدّسها
(بحماية `Predicate<Camera>` @`0x51B1DE8` من التكرار).

`IsBlurLayerCamera(Camera)` @`0x51B1B04` (316B): مسح `_blurLayers` بـ`get_Item` ومقارنة
`worldCamera` بالمرجع — لا مطابقة أسماء.

## ٨. 🛑 فخّ منهجيّ: الواجهة العامّة تُنادى بـ`b` لا `bl`

مسح `bl` على امتداد `__TEXT` كلّه (`0x100000`–`0x94EB320`) يعطي:

| الدالّة | عدد `bl` | عدد `b` (نداء ذَيليّ) | المستدعون الحقيقيّون |
|---|---|---|---|
| `AddBlurLayer` @`0x51AF434` | **٠** | ٢ | `PopupUI` · `MenuMoreButton` |
| `RemoveBlurLayer` @`0x51B0C48` | **٠** | ٣ | `PopupUI` · `MenuMoreButton` |
| `AppendToLayer` @`0x51AF240` | **٠** | ٣ | `PopupUI` · `SlideAnimationHelper` |
| `ShowBlur` @`0x51B0D24` | **٠** | ١ | `PopupUI` |
| `HideBlur` @`0x51B0DC4` | **٠** | ١ | `PopupUI` |
| `IsOnTopLayer` @`0x51B0E68` | ١ | — | `PopupUI` |

> 🛑 **لو اعتُمد مسح `bl` وحده لأُعلِنت واجهة المدير العامّة كلّها ميتة.** كلّها في الحقيقة
> آخر عبارة في دوالّ مُغلِّفة قصيرة، فحوّلها clang إلى `b`. القاعدة المعمول بها في هذا الأرشيف
> (انظر [فهرس العناوين](../INDEX-العناوين.md)) تُستكمل بهذا: **امسح `b` مع `bl` دائمًا قبل الحكم بالموت.**

`get_IsBlurActive` @`0x51AEBFC` = `_activeBlurs.Count > 0`؛ مستهلكوه: `AshtrayGift` · `EgalGift`
(+ داخليًّا من `AddBlurLayer`/`RemoveBlurLayer` لإطلاق الحدث).

`OnPopupVisibilityChanged` — `static event Action<bool>` (`add_` @`0x51AECC0` · `remove_` @`0x51AED90`)،
مشتركاه **`AshtrayGift` و`EgalGift` فقط**: هديّتان عائمتان تختفيان متى ظهرت نافذة.

## ٩. تسلسل `AddBlurLayer` @`0x51AF434` (508B)

```
PruneDestroyedPopups()                              ; 0x51AF4B0
NormalizeLayerDepths()                              ; 0x51AF4B8
_popupPlacements.Remove(popup)                      ; 0x51AF4D4   ← إزالة قبل إضافة
layer = FirstFreeLayer()                            ; 0x51AF4DC
إن null:  layer = CreateBlurLayer()                 ; 0x51AF4E8
          layer.worldCamera.depth = HighestLayerDepth() + ١٠   ; 0x51AF504–0x51AF51C
إن !layer.worldCamera.gameObject.activeSelf: SetActive(true)   ; 0x51AF560
Canvas.ForceUpdateCanvases()                        ; 0x51AF568
UIExtensions.AttachToCanvas( popup, layer.transform )          ; 0x51AF588
_popupPlacements[popup] = new PopupPlacement(layer)            ; 0x51AF5E0
SyncUrpStackOrder()                                 ; 0x51AF5E8
SyncBlurs(duration)                                 ; 0x51AF5F4
إطلاق OnPopupVisibilityChanged( IsBlurActive )      ; 0x51AF604
```

> ⚠️ **`Canvas.ForceUpdateCanvases()` قبل `AttachToCanvas` مباشرةً** — بلا هذا السطر تظهر
> النافذة إطارًا واحدًا بقياس خاطئ (الطبقة أُنشئت للتوّ ولم يُحسَب `CanvasScaler` بعد).
> نقطة يسهل إسقاطها في إعادة البناء وأثرها وميض مرئيّ.

`RemoveBlurLayer` @`0x51B0C48` (220B) أبسط بكثير: `_popupPlacements.Remove(popup)` →
`SyncBlurs(duration)` → إطلاق الحدث. **لا يُعطّل الطبقة ولا يحذفها** — تبقى مُنشأة لإعادة الاستخدام.

`PruneDestroyedPopups` @`0x51AF630` (624B):
`_popupPlacements.Keys.Where(t => t == null).ToList()` ثم `Remove` لكلٍّ منها — إخلاء آمن أثناء التعداد.

`AppendToLayer` @`0x51AF240` (68B): `AttachToCanvas(popup, TopOccupiedLayer().transform)` فقط —
**يضع النافذة في طبقة نافذة قائمة بلا ضباب جديد ولا تسجيل**. وهذا ما تستخدمه `SlideAnimationHelper`
لتُمرّر لوحة منزلقة فوق نافذة موجودة.

`IsOnTopLayer(popup)` @`0x51B0E68`: `popup.parent == TopOccupiedLayer().transform` — تستعملها
`PopupUI` لتقرّر هل تستجيب لزرّ الرجوع.

## ١٠. خلاصة لإعادة البناء

| القرار | القيمة | ⚠️ |
|---|---|---|
| مصدر الضباب | `BlurOptimized` + `Hidden/FastBlur` | من Standard Assets، **ليس مؤثّر URP** |
| `downsample` / `size` / `iterations` | ٢ / ٩٫٠ / ٢ | ثوابت حرفيّة، لا إعدادات |
| مدّة الانتقال | ٠٫٤ ث | وسيط افتراضيّ في أربع دوالّ |
| خطوة العمق | ١٠٫٠ | تسمح بإدخال كاميرا بين طبقتين لاحقًا |
| الطبقة ٠ | `SecondaryCanvas` من المشهد | لا تُنشأ ولا يُعدَّل عمقها (`Skip(1)`) |
| الطبقة تُضبَّب؟ | **الطبقة التي تحت النافذة** | لا النافذة نفسها |
| نموذج الحالة | مزامنة تفاضليّة كاملة | **لا عدّاد مراجع** |
| ترتيب URP | إعادة كتابة فهارس `cameraStack` | العمق وحده لا يكفي في URP |
| إعادة استخدام الطبقات | نعم، لا تُحذف أبدًا | `FirstFreeLayer` قبل `CreateBlurLayer` |
