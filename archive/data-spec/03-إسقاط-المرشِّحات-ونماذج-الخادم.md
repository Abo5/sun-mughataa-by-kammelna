# ٠٣ — إسقاط المرشِّحات (`ClientFilterProjection`) ونماذج الخادم المخزَّنة

[↩ الفهرس](README.md)

> **الطبقة الصامتة بين القرص والواجهة.** [الفصل ٠١](01-طبقة-البيانات.md) وثّق كيف يصل النموذج
> ويُحفَظ ويُبطَل. هذا الفصل يوثّق ما يحدث **بعد** القراءة وقبل التسليم: مرشِّح يعمل على
> **العميل** يحجب عناصر لا تناسب نسخة التطبيق ولا المنصّة ولا اللعبة الحالية — مبنيٌّ
> بالانعكاس (reflection) مرّة واحدة لكل نوع، ومخزَّن بختم مركَّب.

## ٢. ما هي «المرشِّحات»؟ — النموذج على السلك ✅

```csharp
// Server.Models — TypeDefIndex 3299/3300
public class ClientFilter {
    public ClientOnlyFilterType Type      { get; set; }   // 0x10
    public ComparisonOperator   Operation { get; set; }   // 0x14
```

⭐ **القيمة `Value` نصّيّة دائمًا** ويحلّلها العميل بحسب `Type`. الخادم لا يرسل أنواعًا مضبوطة.

| 3 | `GreaterThan` | Greater Than |

| النوع | `TypeDefIndex` | قناة وصوله ([الفصل ٠١ §٢](01-طبقة-البيانات.md)) |

> ⭐ **نتيجة جوهريّة**: الترشيح على العميل **ليس عامًّا** في التطبيق. إنه محصور في
> **الإشعارات والإعلانات والتلميحات** — أي بالضبط المحتوى التحريريّ المُوجَّه لجمهور فرعيّ.

> العنصر قد يصل في الدلتا ثم **لا يظهر أبدًا** بلا أيّ نداء شبكة إضافيّ.

**التوزيع في الآلة** (للتدقيق): `cmp w8,#1 ; b.gt` ⇒ يفصل `{2,3}` · `cbz w8` ⇒ `0` ·
`cmp w8,#1 ; b.ne` ⇒ استثناء · `cmp w8,#3 ; b.eq` ⇒ `3` · `cmp w8,#2 ; b.ne` ⇒ استثناء.

> ⚠️ **مصيدة ثلاثيّة: كلّ فشل تحليل يُعيد `false` صامتًا.**
> ١ `Value` غير قابل للتحليل (`"iOS "` بمسافة، `"2"` بدل `"IOS"`، `"True"` مقابل `"true"` — هذا
> الأخير يمرّ لأن `bool.TryParse` غير حسّاس للحالة، بخلاف `Enum.TryParse` هنا الذي **حسّاس**
> لأنه يُنادى بلا راية `ignoreCase`).
> ٢ `AppVersion` معدومة على العميل (تحليل `Application.version` فشل) ⇒ **كلّ مرشِّح إصدار يفشل**.
> ٣ وبما أن `PassesFilters` تستعمل `All`، فإن **فشل مرشِّح واحد يحجب العنصر كلّه**.
> 🚩 ⇒ **يفشل مغلقًا**: خطأٌ مطبعيٌّ في لوحة إدارة الخادم يُخفي الإعلان عن الجميع بلا أيّ أثر
> في السجلّات على العميل (لا `LogError` في هذا المسار).

**الوسيط الرابع `"Check"`** هو اسم المُنادي (`caller`) الذي تأخذه
`UI.Conditions.ComparisonOperatorExtensions.Apply<T>(op, userValue, filterValue, caller)` —
مشترك مع طبقة شروط الواجهة، وهو ما يجعل `In`/`NotIn` متاحين نظريًّا لمرشِّحات العميل أيضًا.

## ٦. ⭐⭐ `Project` — الكاش المزدوج ✅ @`0x439EC74` (940B)

```csharp
public class ClientFilterProjection<T> {                 // TypeDefIndex 3278
    private static readonly Func<T,FilterableClientModel,T> FILTER;   // ثابت
    private T                    _projected;             // 0x10
    private int                  _projectedGeneration;   // 0x18   ← يبدأ −1
    private FilterableClientModel _projectedStamp;       // 0x20

    public T Project(T raw, int generation) {
        if (raw == null)    return raw;
```

دليل: `get_Key` @`0x437FEC0` ⇒ `ldrb w8,[x19,#0x2c] ; ldr x0,[x19,#0x30] ; cmp w8,#1` ثم دمج
`_key + "." + Preferences.CurrentGame`. و`get_Model` @`0x4380188` ⇒
`ldr x0,[x20,#0x10]` (المُسقِط) و`ldr w2,[x20,#0x28]` (الجيل).

### ٧.٢ الدالّة مفكوكة ✅

```csharp
private T RawModel {
    get {
        if (_modelKey != Key) {        // String.op_Inequality @0x543D478
            _model    = default;       // str xzr, [x19, #0x18]
            _modelKey = Key;
            _generation++;             // ① زيادة عند تغيّر المفتاح
        }
        if (_model != null) return _model;
        _model = FileUtils.LoadObject<T>(Path, null);   // @0x2E03FA4 — تحميل كسول من القرص
        _generation++;                 // ② زيادة عند كل قراءة قرص
        return _model;
    }
}
```

> ⭐ **الزيادة مرّتان** إن تغيّر المفتاح **و** احتاج تحميلًا: `_generation += 2` في نداء واحد.
> وهذا سليم وظيفيًّا (الجيل عدّاد إبطال لا عدّاد إصدار).

> 🚩🚩 **عِلّة الملفّ الغائب — مُثبَتة**: `FileUtils.LoadObject` تُعيد `null` إن لم يوجد الملفّ.
> إذًا `_model` يبقى `null`، فـ**كل** نداء `RawModel` تالٍ:
> ١ يُعيد ضرب القرص (`Path` + `File.Exists`)، و
> ٢ **يزيد `_generation`** ⇒ يُفوِّت كاش `Project` حتمًا ⇒ يُعيد تشغيل `Where`+`ToList` على
>   القائمة كلها… إلّا أن `raw == null` يقطع `Project` مبكّرًا، فالأثر الفعليّ هو **دوران قرص
>   لا نهائيّ بلا تخصيص LINQ**. وبمجرّد أن يصل النموذج فارغًا-لكن-غير-معدوم (`[]`) يصبح الأثر
>   **دوران قرص + إعادة إسقاط** في كل إطار تسأل فيه الواجهة.
> ⇒ في نسختك: خزِّن راية «حُمِّل ولو كان معدومًا» ولا تزد الجيل إلّا عند تغيّر فعليّ.

### ٧.٣ لماذا ٨٧٢ بايتًا مقابل ٢٩٦؟ ✅

النسخة `__Il2CppFullySharedGenericType` تعمل على `T` **بالمؤشِّر** لا بالقيمة، فتزيد:
`ldrh [x+0x135]` لفحص تهيئة الصنف قبل كل استعمال للنوع · نقل القيم عبر `memcpy` مُولَّد ·
حاجزٌ للكتابة (`0xAC174C`) عند كل إسناد مرجعيّ. **السلوك مطابق حرفيًّا**: دقّقتُ الفروع
الأربعة كلها مقابل نسخة `<object>`. ⚠️ لا تحسبها منطقًا إضافيًّا.
