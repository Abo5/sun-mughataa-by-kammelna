## ٣. ⭐ `ListDeltaApplier<TModel,TId>` — الثغرة المُغلقة

كانت هذه الفجوة مسمّاة صراحةً في [التوقّعات](../predictions-spec/README.md) و[الإشعارات](../notifications-spec/README.md).

### شكل الحمولة على السلك ✅

```csharp
class ContentDeltaModel<TModel, TId> {
    List<TModel> Upserts    { get; set; }   // إضافة وتحديث معًا — لا فصل بينهما
    List<TId>    RemovedIds { get; set; }
    long         Cursor     { get; set; }   // المؤشّر بعد الدفعة
}
```
```json
{ "Upserts": [ … ], "RemovedIds": [ … ], "Cursor": 123456 }
```
🟡 الأسماء PascalCase (لا `[JsonProperty]` ولا `ContractResolver` في هذا المسار؛ و Newtonsoft
غير حسّاس للحالة عند القراءة).

### خوارزمية الدمج — `ContentDeltaMerge.Merge` @`0x2D393E0` (904B) ✅

```csharp
foreach (var up in delta.Upserts) {
    int i = target.FindIndex(m => idOf(m).Equals(idOf(up)));
    if (i >= 0) target[i] = up;      // تحديث
    else        target.Add(up);      // إضافة
}
if (delta.RemovedIds?.Count > 0)
    target.RemoveAll(m => delta.RemovedIds.Contains(idOf(m)));
```
`HasChanges` @`0x2D391C4` = `Upserts.Count > 0 || RemovedIds.Count > 0`.

### `ApplyDelta` @`0x328B9C4` (408B) — 🛑 **هذا المقطع خاطئ، انظر [٠٥](05-محرّك-الدلتا-مفكوكًا.md)**

```csharp
// 🛑🛑 لا تعتمد على هذا المقطع — أُبطل بتفكيك لاحق كامل:
// var cache = _cacheOf(); _ = cache.Model;
// if (cache.IsValid()) Merge(cache, delta); else Replace(cache, delta);   // ❌ لا وجود لهذا الفرع
// cache.LastUpdate = DateTime.Now;                                        // ❌ مشروطة
// if (HasChanges(delta)) { _onApplied(); _onChanged(); }                  // ❌ onApplied وحده
```

**الصحيح، مُثبتًا من كود الآلة** ([٠٥ §٢](05-محرّك-الدلتا-مفكوكًا.md)):

| الدعوى هنا | الحقيقة |
|---|---|
| فرعٌ بين `Merge` و`Replace` بحسب `IsValid()` | ❌ **لا فرع**: `Merge` دائمًا (`bl` @`0x328BAC4`)، و`Replace` **لا تُستدعى من `ApplyDelta` قطّ** |
| `IsValid()` تختار الفرع | ❌ تحكم **كتابة `LastUpdate` وحدها** (`cbz w23` @`0x328BAC8`) |
| `_ = cache.Model;` قراءةٌ مُهمَلة | ❌ **حرسٌ**: `if (cache.Model == null) return;` @`0x328BA40` |
| `{ _onApplied(); _onChanged(); }` | ❌ **`onApplied` وحده** (@`0x328BB1C`)؛ و`onChanged` من `ApplyChanged` حصرًا |
| `Replace` الموضع الوحيد الذي يكتب `ServerCursor` | ❌ **`Merge` يكتبه أيضًا** بقفزة ذيليّة `b` @`0x328BDF0` |

> ⭐ والقطبيّة الحقيقيّة في **مسار REST** لا push، وشرطها **المؤشّر**:
> `cursor == 0 ⇒ Replace` · `cursor != 0 ⇒ Merge`.

### الاسترداد — `ContentSinceRequest<T,TId>` ✅
`EndPoint` = `Config.BackendURL + _path` · `QueryParams` = **مفتاح واحد `"cursor"`** ·
**`GET` ✅ مُثبتًا** (`mov w0,#0 ; ret` @`0x4492A48`).

### محرّك المزامنة — `ContentSyncService` ✅

| الدالّة | العنوان | السلوك |
|---|---|---|
| `EnsureFresh` | `0x524A080` | `Cache.IsValid()` ⇒ `onDone(true)` **بلا شبكة**؛ وإلا `Fetch(…, Cache.ServerCursor, …)` |
| `CatchUpAll` | `0x524BB90` | يمرّ على كل المُطبِّقات بمؤشّراتها |
| **`Rebaseline`** | `0x524C0A8` | **`Fetch(applier, cursor = 0)`** — إعادة تأسيس كاملة |
| `Fetch` | `0x524B5CC` | إزالة تكرار عبر `IN_FLIGHT : Dictionary<string, List<Action<bool>>>` |

## ٤. `CachedModel<T>` — كاش write-through بلا TTL

| العضو | العنوان | السلوك |
|---|---|---|
| `get_Key` | `0x437FEC0` | `_gameSpecific ? _key + "." + CurrentGame : _key` |
| `get_Path` | `0x437FDF8` | `CachePath + "models/" + Key + ".json"` |
| `get_RawModel` | `0x43801D8` | تغيّر `Key` ⇒ إبطال؛ ثم تحميل كسول من القرص |
| `set_RawModel` | `0x4380300` | `_generation++` ثم **كتابة فورية للقرص** |
| `get_Model` | `0x4380188` | `_clientFilter.Project(RawModel, _generation)` |
| **`IsValid`** | **`0x4380474`** | ↓ |

```csharp
bool IsValid() {
    var srv = CachedModels.GetServerLastUpdate(_key);
    if (srv.HasValue && !(ETagStorage.GetLastUpdate(Key) >= srv.Value)) return false;
    return !string.IsNullOrEmpty(ETagStorage.GetETag(Key))
        || ETagStorage.GetServerCursor(Key) != 0;
}
```

> ⭐⭐ **لا TTL ولا `TimeSpan` ولا مقارنة مدّة** — مُتحقَّق: ثماني استدعاءات، لا واحد منها زمنيّ.
> الصلاحية **مدفوعة بالختم حصرًا**، والإبطال يحدث بطريقتين فقط:
> ١ الخادم يرفع `lu*` فوق `lastUpdates[Key]` · ٢ `ClearLastUpdateDate` يُنزل المحلّي تحت الختم.

**خاص باللعبة — ثلاثة مفاتيح فقط** ✅ (`IsGameSpecific` @`0x5184508`):
`Cached_PersonalStatsConfigs` · `Cached_StoreHomePage` · `Cached_RemoteConfig`.
> تأكيد مستقلّ: `SurgeryDoctor.DeleteOrphanCaches` يحذف نسخ `Cached_Notifications_Model.{game}`
> و`Cached_AppAnnouncements.{game}` **بوصفها يتيمة** — أي أنهما كانا خاصّين باللعبة ولم يعودا.

`ClearLastUpdates` @`0x51847DC` يشمل **سبعة** نماذج فقط (الإعلانات · الإشعارات · واجهة المتجر ·
الأصناف · هدايا الملف · المنتجات · المجموعات) — **ولا يشمل** التوقّعات ولا الأحداث الجماهيرية
ولا الإنجازات ولا التلميحات ولا `remote_config`.

## ٥. `ETagStorage` — ثلاثة ملفات

| القاموس | الملف |
|---|---|
| `_eTags : Dictionary<string,string>` | `models/eTags.json` |
| `_lastUpdates : Dictionary<string,DateTime>` | `models/lastUpdates.json` |
| `_serverCursors : Dictionary<string,long>` | `models/serverCursors.json` |

**المفتاح** = `CachedModel.Key` (مع لاحقة `.{Games}` للثلاثة الخاصة باللعبة).
`Save()` **لا يكتب إلا إذا `_isDirty`**. و`GetInstance` @`0x51852A0`: إن لم يبدأ مسار النسخة
الحالية بـ`Config.CachePath` ⇒ **`Clear()`** ⇒ **تبديل البيئة يمسح كل الـETags** ✅.

### 🛑 نتيجة سلبية مهمّة

مسح كل مستدعي `SetETag`/`GetETag`/`SetServerCursor` أعطى **حصرًا**: `CachedModel<T>` ·
`SurgeryDoctor` · `CachedRequestDecorator.InitializeETagHeader`.

> ⇒ **`LeaderBoardManager.StoreInCache` و`source.SetETag` في
> [لوحات الصدارة](../leaderboards-spec/README.md) ليسا `ETagStorage` إطلاقًا** — فضاء أسماء
> مستقلّ تمامًا يخزّن الـETag داخل كائن المصدر ويكتبه في
> `{CachePath}leaderBoards/{game}/{Name}.json`. وكذلك `sta == 304` في ردود SFS قناة منفصلة.

### دورة `If-None-Match` ⇄ `304` ✅

```csharp
// Setup @0x438321C — الترويسة لا تُرسَل أصلًا إن كان الكاش غير صالح
if (CachedModels.GetModel<T>(key).IsValid()) InitializeETagHeader();

// InitializeETagHeader @0x438341C
var etag = ETagStorage.GetETag(Key);
if (etag.IsNullOrEmpty()) etag = "DummyValueRequiredByAsp";
SetRequestHeader("If-None-Match", etag);

// get_CachedModelUpdated @0x4D14E50 — 36 بايت، الشرط الدقيق
CachedModelUpdated = (Error == NoError /*1000*/) && (StatusCode != 304);

// Materialize @0x45A8D88
if (response.CachedModelUpdated) CachedModel.Update(model, headers, path);
else { result = CachedModel.Model; CachedModel.LastUpdate = Now; }   // 304 ⇒ استعمل المحفوظ
if (!response.Succeeded) CachedModel.Clear();
```

> ⭐ **اكتشاف**: `CachedModel.Update` يقرأ الترويسة **`ETag`** ثم يجرّب بديلًا **`KTag`** —
> على الأرجح لتجاوز CDN/proxy يجرّد `ETag`. وإن غابتا: `Debug.LogError("___# There is No ETag…")`.

## ٦. الثبات على القرص

| المسار | المحتوى |
|---|---|
| `models/{Key}.json` | كل `CachedModel<T>` |
| `models/eTags.json` · `lastUpdates.json` · `serverCursors.json` | الميتاداتا |
| `avatars/{userId}` · `{userId}_thumbnail` | صور المستخدمين |
| `leaderBoards/{game}/{Name}.json` | لوحات الصدارة |
| `{assetId}` تحت الجذر | أصول `RemoteAssetsCacher` |

**الصيغة**: JSON عبر **Newtonsoft**، بلا ضغط ولا تشفير ✅.
و`OBJECT_SETTINGS` يستعمل `WritablePropertiesOnlyResolver` ⇒ **الخصائص للقراءة فقط لا تُكتب**.

### الحدود والطرد ✅

> **لا حدّ على مجلّد `models/` إطلاقًا.** الحدّ الوحيد هو **١٥٠ ميغابايت على `avatars/`**
> (`mov w1, #0x9600000` ⇒ `FileUtils.CleanFolder`).

```csharp
// CleanFolder @0x4EE03EC — طرد LRU حقيقي
if (GetDirectorySize(path) <= maxSize) return;
files.OrderBy(fi => fi.LastAccessTime)          // ⭐ بزمن آخر وصول
     .TakeWhile(_ => size > maxSize)
     .ForEach(fi => { size -= fi.Length; fi.Delete(); });
```
ولهذا تُحدَّث `SetLastAccessTime` عند كل قراءة/كتابة أصل.

### طبقة الأصول — قناة ترويسة مختلفة ⭐

سلسلة المُحمِّلات: `InMemoryCacheAssetLoader(200)` → `LocalUnityWebRequestAssetLoader` →
`RemoteUnityWebRequestAssetLoader`. و`MaxNumberOfActiveRequests = 10`.

```csharp
// ValidateCachedFile @0x5098C44 — مفكوكة كاملة
valid = File.Exists(p) && (!ts.HasValue || File.GetLastWriteTime(p) >= ts.Value);
```
> 📌 **يُدقّق [هويّة اللاعب ٠٢](../identity-spec/02-الإحصائيات-والملف.md)**: الاتجاه هو
> `mtime >= serverTs`، و**`ts == null` تُعتبر صالحة دائمًا** (لا العكس).

> ⭐ **قناتان مختلفتان تمامًا**: طبقة الأصول تستعمل **`If-Modified-Since`** بصيغة RFC-1123،
> وطبقة النماذج تستعمل **`If-None-Match`**.
