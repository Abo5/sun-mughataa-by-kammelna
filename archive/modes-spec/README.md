## أربع نتائج جوهرية

1. **`LevelStages[level−1][stage−1]` = نقاط الرتبة الممنوحة** لا عتبة تأهُّل — مُثبت من `FastTrackAward`.
2. **`Hearts = 5 − ft_rl`** — الرقم ٥ مخبوز في كود الآلة.
3. **تجديد محاولات مشروع اليوم عند منتصف الليل بتوقيت السعودية (UTC+3)** لا بتوقيت الجهاز.
4. **لا HTTP إطلاقًا** في النظامين — كله `ExtensionRequest` عبر إضافتَي `ft` و`mg`.
