[↩ الفهرس](README.md)

> ⚠️ **لم تُنقَل أي أسرار إلى هذا الأرشيف.** حيث توجد مادّة حسّاسة يُذكر **اسم الحقل ومصدر تحميله فقط**.

## ✅ ما تحقّقتُ منه بنفسي

فجوة **عنوان الـCDN** كانت مفتوحة في [هويّة اللاعب](../identity-spec/README.md).
السبب أنها **ليست في الثنائي أصلًا** بل في `ScriptableObject` داخل حزمة addressable.
قرأتُ الأصل بـUnityPy فطابق حرفيًّا:

```json
KammelnaConfigLoader [DefaultConfigLoader]
  liveHostURL    : "https://kammelna.com/"
  preHostURL     : "https://staging.kammelna.com/"
  defaultBlobUrl : "https://kammelna.blob.core.windows.net/"

KammelnaEnvironmentProvider [Kammelna Environment Provider]
  environment    : 0          // Production
  localHostURL   : "http://localhost:5000/"
```

الحزمة: `duplicateassetisolation_assets_assets_scripts_server_defaultconfigloader.asset_fe949546…bundle`

## ١. `Config` — من أين تأتي كل قيمة

```csharp
// Config$$get_BackendURL @0x509BE50 (324B)
switch (Loader.environmentProvider.environment) {
  case Production(0)  : return Loader.liveHostURL;                     // https://kammelna.com/
  case Staging(1)     : return Loader.preHostURL;
  case Development(2) : return Loader.environmentProvider.localHostURL;
  default             : throw ArgumentOutOfRangeException;
}
```
القيم تنتهي بـ`/` فيُلحَق المسار مباشرة: `Concat(BackendURL, "api/…")`.

**عنوان الـCDN وقت التشغيل** = `defaultBlobUrl + environment.ToString().ToLower() + "/"`
(`get_defaultBlobUrlFallback` @`0x509FAA4`) ⇒ في الإنتاج
`https://kammelna.blob.core.windows.net/production/` 🟡 (التركيب ✅، اشتقاق الاسم من `Enum.ToString().ToLower()` ✅).
ثم يُدهس بـ`ConfigsModel.BlobHost` إن جاء غير فارغ.

**عنوان SignalR الافتراضي** مخبوز نصًّا: `https://coordinator.kammelna.com/socialHub`
(`get_defaultSignalRServerUrl` @`0x509FB54`) ✅ — يُكمل [الطبقة الاجتماعية ٠١](../social-spec/01-المعمارية-والدردشة.md).

`CachePath` @`0x5099254` = `"{persistentDataPath}/{environment}/"` ✅.

### `SFSConfig` — نموذج الخادم ✅

`ID`@`0x10` · `Name`@`0x18` · `MaxUsers`@`0x20` · `OnlineUsers`@`0x24` · `IP`@`0x28` ·
`Port`@`0x30` · `WebPort`@`0x34` · `IsMain`@`0x38` · `IsOnline`@`0x39` · `IsFastTrack`@`0x3A` ·

* `PlatformPort` = `WebGL ? WebPort : Port` ✅


## ٣. المصادقة

### ٣.١ الطرق المدعومة ✅

| الطريقة | ملاحظة |
|---|---|
| بريد + كلمة مرور | `UserCredentials { Email, Password }` |
| **Apple** (`SocialPlatform=3`) · **Google** (2) · **Facebook** (0) · **Twitter** (1) | عبر رمز Firebase |
| إعادة دخول صامتة | `RefreshToken` صالح ⇒ `AutoLogin()` |
| **لا يوجد ضيف** | ⭐ نفي — لا مسار guest/anonymous |
| **لا يوجد دخول بهاتف/OTP** | `phone` حقل تسجيل فقط |

> «كود المستخدم» (`uc`) ليس وسيلة دخول — متغيّر مستخدم للعرض والإضافة الاجتماعية.

### ٣.٢ ⭐ السلسلة: تحدٍّ + إثبات نزاهة ثم رمز ✅

```
GetAuthTokens(credentials) @0x50A07C8
 ├ AccessToken صالح  ⇒ إرجاع فوري بلا شبكة
 ├ RefreshToken صالح ⇒ تحويل إلى RefreshAuthTokens
 └ وإلا:
     POST api/AppCheck/GetLoginChallenge → ServerChallengeResult { UserKey, ServerChallenge, AttestationRequested }
     AppCheckManager.GetToken(...) → AppleDeviceCheck  (Secure Enclave)
     POST api/token  (UserCredentials + IntegrityModel) → AuthModel

RefreshAuthTokens @0x50A0B84
     GET  api/AppCheck/GetRefreshChallenge
     POST api/token/refresh { RefreshToken, DeviceId, IntegrityModel }
```

**إثبات النزاهة** = Apple DeviceCheck / App Attest عبر إضافة أصلية
(`DeviceCheckPlugin_GenerateKey` · `AttestKey` · `GenerateAssertion`)، والبديل `EmptyAppCheck`.
`AppCheckManager.MAX_ATTEMPTS = 3`.

> ⚠️ `AppIntegrityRequestModel.ValidationKey` و`Token` مادّة توقيع تُولَّد وقت التشغيل من
> Secure Enclave — **لم تُستخرَج**.

### ٣.٣ ⚠️ تخزين الرموز — ملاحظة أمنية مُثبتة

`Authentication.SetToken` @`0x52692AC` يكتب عبر `Prefs.SetString`/`SetDate` ⇒
الرموز تُخزَّن **بنصّ صريح في `PlayerPrefs`** (أي `NSUserDefaults`/plist على iOS)
بالمفاتيح `AccessToken` · `AccessTokenExpires` · `RefreshToken` · `RefreshTokenExpires` —
**بلا تشفير ولا Keychain**.

> **عند بنائك**: ضع الرموز في Keychain لا في `PlayerPrefs`.

و`AccessToken` هو **JWT** ✅ — مُثبت من `SegmentClaims` @`0x526DE74` و`DecodeBase64Url` @`0x526E364`
اللتين تقرآن مطالبة `"SegmentId"` من داخله.

### ٣.٤ `[AuthenticatedRequest]` — كيف يُطبَّق ✅

```csharp
// WebRequestExtensions.ApplyDecorators<T> @0x3107644
request.GetType().GetCustomAttributes<WebRequestDecoratorAttribute>()
       .OrderBy(d => d.Priority)
       .Aggregate(request, (req, d) => d.MakeDecoratorInstance(req));
```
أولوية `AuthenticatedRequestAttribute` = **100** (القاعدة 0) ⇒ تُطبَّق **أخيرًا** فتكون
**الغلاف الخارجي** — أي أن مزخرِف المصادقة يلفّ الكاش والـbackoff.

`TokenAuthenticatedRequestDecorator<T>`:
* `InitializeAuthHeader` @`0x3EB54AC`: رمز صالح ⇒ `Authorization: Bearer <jwt>`؛
  وإلا إن `CanLogin()` ⇒ `Bearer DummyValueRequiredByAsp` (علامة «جدِّد أولًا»).
* `HandleAuthenticationFailed` @`0x3EB52A0`: نافذة ⚪ «Session Expired!» ثم `SFS.Logout` ثم استثناء.

**١٣٢ صنف طلب** يحمل السمة. **طلبات الإقلاع ليست منها** ✅:
`GetAuthTokenRequest` · `RefreshAuthTokenRequest` · `GetLoginChallengeRequest` ·
`GetRefreshChallengeRequest` · `LoadServersRequest`.

### ٣.٥ ترويسات كل طلب ✅ — `ClientContext.GetRequestHeaders` @`0x52727CC`

`game` · `version` · `platform` · **`X-Km-Caps`** · **`X-Km-Build`** ·
`gameType`/`tournamentId`/`tournamentType` (اختيارية) · `Authorization` (من المزخرِف) ·
`If-None-Match` (من `CachedRequestDecorator`).

```csharp
[Flags] enum ClientCapability {          // القيمة الابتدائية 0x3F = كلها مفعّلة
```

| الأمر | الأثر |
|---|---|

`luh` تلميحات · `lusp` منتجات · `lusi` أصناف · `luspg` هدايا · `lusig` مجموعات · `lule` شعارات العشائر.

## ٥. بوّابات الإيقاف ✅

| البوّابة | الشرط | الأثر |
|---|---|---|
| **تحديث إجباري** | `new Version(Application.version) < new Version(ForcedVersion.PlatformSpecificValue)` | `NewVersionPopup` — **حاجزة** |
| **مفتاح الإيقاف** | `Config.IsDown = DownMessage != null` | ⭐ **مجرّد وجود `DownMessage` في رد `api/Servers` يوقف التطبيق** — والقاموس لكل منصّة، فيمكن إسكات iOS وحدها 🟡 |
| **فحص الأصالة** | `!Application.genuine` | نفس `DownPopup` |
| **صيانة** | `MaintenanceInfo` | زمنيّة أو انتقائية بالخادم |

> 📌 هذه النسخة من الـIPA **مُعاد توقيعها بـESign** وتحوي `CydiaSubstrate.framework` —
> ففحص الأصالة ذو صلة مباشرة بها.

## ٧. مفاتيح `PlayerPrefs`

| المفتاح | يُمسح عند |
|---|---|
| `AccessToken` / `…Expires` · `RefreshToken` / `…Expires` | `Authentication.Clear` |
| **`ServerId`** | ⭐ **لا يُمسح عند الخروج** — الخادم لصيق بالجهاز لا بالحساب |
| `DevelopmentHostOverride` | `"default"`/`"reset"` |
| `Password` · `SocialID` · `TwitterID` | `SFS.Logout` |

> ⚠️ **`LanBackendScanner`** (`BackendPort=5000`, `ProbePath="api/servers"`) — ماسح شبكة محلّي
> **شُحن في نسخة الإنتاج**. أداة مطوّرين.
