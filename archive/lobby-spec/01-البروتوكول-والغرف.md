## ١. ⭐ المغلّف — كل شيء `ExtensionRequest`

**`CreateRoomRequest` و`JoinRoomRequest` الأصليتان من SFS2X لا تُستعملان إطلاقًا** —
موجودتان في الثنائي بلا مستدعٍ من كود اللعبة. ✅

| الدالة | العنوان | التنفيذ |
|---|---|---|
| `SFS.SendZoneExtensionRequest(cmd, params)` | `0x5261CC8` | `ExtensionRequest(cmd, params)` بلا غرفة |
| `SFS.SendRoomExtensionRequest(cmd, params)` | `0x5261B2C` | `ExtensionRequest(cmd, params, LastJoinedRoom)` |
| `SFSExtensions.GetCommand(evt)` | `0x4EC6754` | `evt.Params["cmd"]` |
| `SFSExtensions.GetResponseParams(evt)` | `0x4EC6858` | `evt.Params["params"]` |

### ⭐ مطابقة الطلب بالاستجابة — `rid`

`SfsRequestListener.SendZoneRequest` @`0x52A62D4` · `SendRoomRequest` @`0x52A653C`
يضيفان مفتاح **`rid`** (مُولَّد في `GenerateRequestId` @`0x52A64D8`)، والاستجابة تُعيده في
`params.rid` فيُطابَق المستمع (@`0x52A6740`).

> **خادمك يجب أن يعكس `rid` كما استلمه** — هذه آلية الـrequest/response correlation.

### موزّع استجابات النطاق — `SFS_OnExtensionResponse` @`0x525EAF0` ✅
`lz` (مغادرة النطاق ⇒ `SwitchServer("0")`) · `announceLockDown` · `join_room` · `set_seat` ·
`reloadConfigs` · `chat` · `maintenance`.

لـ`join_room`/`set_seat`: يقرأ `params.roomId` → `GetRoomById`؛ وإن وُجد `params.error`
(افتراضي `"Unknown Error"`) ⇒ `SFS_OnJoinRoomFailed`.

### ٢.٢ ⭐ الطلب — `SFS.CreateRoom` @`0x526255C` ✅

```csharp
var p = new SFSObject();
p.PutUtfString("name",     roomName ?? "");
p.PutUtfString("password", password ?? "");
p.PutInt       ("r",       rankLimit);
p.PutInt       ("timer",   timer);
p.PutBool      ("ch",      cheatingAllowed && Preferences.CurrentGame.SupportsCheating());
p.PutBool      ("vc",      isVoiceRoom);
p.PutBool      ("vcs",     voiceForSpectators);
p.PutInt       ("jcr",     jackarooCustomRules);
if (tvUserId < 0)                  p.PutInt("gs",      tvUserId);      // بِت الإشارة
if (clanId   >= 1)                 p.PutInt("clan_id", clanId);
if (!testDeckCsv.IsNullOrEmpty() && !Config.IsProduction)
                                   p.PutUtfString("td", testDeckCsv);
SendZoneExtensionRequest("create_room", p);     // أمر نطاق لا غرفة
```

| المفتاح | النوع | المعنى | شرط الإرسال |
|---|---|---|---|
| `name` | string | اسم الغرفة (≤٢٠٠ حرفًا بعد التعقيم) | دائمًا |
| `password` | string | `""` = بلا قفل | دائمًا |
| `r` | int | الحدّ الأدنى للرتبة | دائمًا |
| `timer` | int | مهلة الدور | دائمًا |
| `ch` | bool | القطع والتقييد | دائمًا (**يُجبَر `false`** إن كانت اللعبة لا تدعمه) |
| `vc` / `vcs` | bool | الصوت / الصوت للمشاهدين | دائمًا |
| `jcr` | int | قواعد جكارو المخصّصة | دائمًا |
| `gs` | int | معرّف شاشة TV | **فقط إن `tvUserId < 0`** |
| `clan_id` | int | غرفة عشيرة | **فقط إن `clanId ≥ 1`** |
| `td` | string CSV | كومة ورق اختبار | **فقط في غير الإنتاج** |

### ٢.٣ التحقّق — `CreateGamePopup.ValidateOptions` @`0x5112AEC` ✅

1. `name = InputSanitizer.SanitizeHtmlTags(name.Trim(), maxLen: 200)` ثم يُعاد كتابته في الحقل.
2. ⭐ **`if (name.Length == 1 || name.Length == 2) → خطأ "Short room name"`**
   ⇒ **الاسم إمّا فارغ أو ≥ ٣ أحرف؛ الفارغ مسموح** (الخادم يسمّيها 🟡).
3. ⭐ إن `clanId > 0` ⇒ **تُتخطّى محاسبة الآص كليًّا** — غرف العشيرة مجانية.
4. وإلا `MySelf.GetAces() >= GetRoomCreationPrice(isVoiceRoom)` وإلا
   `NotEnoughAcesPopup.ShowNotEnoughAces(deficit, tab: isVoiceRoom ? 12 : 6)`.

### ٢.٤ التسعير — `RoomCreator.GetRoomCreationPrice` @`0x50AA62C` ✅

```csharp
if (SFS.MySelf.IsSubscribed(includeTemp: true))  return 0;
if (voiceChat)  return RemoteConfig.Current.CreateVoiceRoomPrice;   // حقل @0x20
if (SFS.MySelf.HasPaidRoomTheme())               return 0;
return RemoteConfig.Current.CreateRoomPrice;                        // حقل @0x1C
```
> ⭐ `HasPaidRoomTheme` يُعفي من سعر الغرفة **العادية فقط**، لا الصوتية.

### ٢.٥ التتبّع بعد الإنشاء — `RoomCreator.CreateRoom` @`0x50AA46C` ✅
`SFS.CreateRoom(...)` → `FirebaseTrack.Event("Created_Game", voiceChat ? "VoiceChatRoom" : "NormalRoom")`
→ `TrackerLibrary.MenuRoomCreated` → إن `clanId ≥ 1`: `ClanServerConnector.NotifyActivityCreated`
→ `Tracker.ResourceEvent(price)`.

## ٣. قائمة الغرف والفلترة

### ٣.١ الطلب — `SFS.LoadRoomsList<T>` @`0x301E1A4` ✅
أمر نطاق **`rl`**، الحمولة = `RoomsFilterModel.ToSfsObject()` @`0x515B700`:

| المفتاح | النوع | الحقل | شرط الإرسال |
|---|---|---|---|
| `ftrT` | string | `Text` | إن لم يكن فارغًا |
| `ftrG` | int `GameType` | `GameType` | إن `HasValue` |
| `ftrC` | bool | `CheatingAllowed` | إن `HasValue` |
| `ftrS` | int | `PlayingSpeed` | إن `HasValue` |
| `ftrL` | bool | `IsLocked` | إن `HasValue` |
| `ftrV` | bool | `IsVoice` | إن `HasValue` |

الاستجابة (`<LoadRoomsList>b__0` @`0x31DF1F0`): `params.rl` = SFSArray → `ToModelList<GameRoomData>`؛
والخطأ `KammelnaError` enum يُحوَّل بـ`Enum.ToString`.

### ٣.٢ ⚠️ `GameRoomData` — مخطّط مختصر يختلف عن متغيّرات الغرفة ✅

| `n` | `Name` | 0x28 |

| `s1` / `s2` | `TeamScore1` / `TeamScore2` | 0x34 / 0x38 |

**الخنق**: `RoomsListUI.ThrottleInterval = 5s` (@`0x515BE5C`: `fmov d0, #5.0`) ✅.
