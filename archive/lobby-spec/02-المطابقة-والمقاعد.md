## ١. المطابقة (Matchmaking)

### ١.١ الإرسال — `SFS.SendFindMatch` @`0x5265868` ✅

```csharp
var p = new SFSObject();
p.PutInt ("gt", (int)gameType);
if (skipAd) p.PutBool("sk", true);      // يُرسَل فقط عند true
p.PutUtfString("cmd", "find_match");
SendZoneExtensionRequest("mmkr", p);
```

| الغلاف | العنوان | ما يفعله |
|---|---|---|
| `SFS.RankedMatch(skipAd)` | `0x5265C54` | `FirebaseTrack("Play_Game_Ranked")` ثم `SendFindMatch(Ranked=1, skipAd)` |
| `SFS.FriendlyMatch()` | `0x5265CCC` | `FirebaseTrack("Play_Game_Friendly")` ثم `SendFindMatch(Friendly=0, false)` |
| `FastTrack.MatchMe` | `0x52E5F6C` | 🟡 `SendFindMatch(FastTrack=3)` |
| `LeaveRoomPopup.TryFindGame` | `0x4F9C900` | إعادة بحث بعد مغادرة غرفة |

### ١.٢ الإلغاء — `SFS.SendStopFindMatch` @`0x526599C` ✅

```csharp
SfsRequestListener.SendZoneRequest(lifecycle, "mmkr",
    SfsObjectUtil.FromOneValue("cmd", "leave"), once:false, callback, null);

// المعالج @0x5268E7C:
if (resp.GetBool("success", false)) onSuccess();
else if (resp.GetUtfString("error","") == "cannot_leave_queue") onError(error);
// ⚠️ أي خطأ آخر يُتجاهَل بصمت
```

> `SFSCommands.MatchMakerCannotLeaveQueue = "cannot_leave_queue"` هو **الخطأ الوحيد** الذي يظهر للمستخدم.

**المستدعون**: `HintsPopup.MatchMakingCancel` @`0x51183C8` (يعطّل الزر أولًا، وعند الخطأ
يشغّل `AnimationExtensions.ErrorFeedback` ويعيد تفعيله؛ وعند النجاح `HintsPopup.Close`) ·
`FastTrack.StopMatching` · `FastTrackPopupManager.StopMatching`.

### ١.٣ ⭐ الحدث الوارد — العميل لا يقرأ الحمولة ✅

الخادم يرسل أمر **`mmkr`** على **قناة الغرفة** (لا النطاق). الموزّع `KGame.OnExtensionResponse` @`0x5311314`:

```csharp
var cmd  = evt.GetCommand();          // params["cmd"]
var prms = evt.GetResponseParams();   // params["params"]
if (cmd != "game_state" && cmd != "sr" && !IsSpectator) TrySeatPlayer();
switch (cmd) { case "mmkr": OnMatchMakerEvent?.Invoke(prms); ... }
```

```csharp
// KGameUiControls.OnMatchMakerEvent @0x4F9B65C
HideLoader();
gameEventsChannel.Trigger<ShowAnimation>();
```

> ⭐ **العميل لا يقرأ حمولة `mmkr` إطلاقًا.** الخادم يكون قد نقل اللاعب للغرفة فعلًا؛
> الحدث مجرّد إشارة «تمّت المطابقة».

### ١.٤ ⚠️ اكتشاف مُتحقَّق — `CancelMatchMaking` == `ExitGame`

```asm
0x53134FC  b  #0x5313500        ; KGame$$CancelMatchMaking — تعليمة واحدة
0x5313500  stp d9, d8, …        ; KGame$$ExitGame
```
الدالة **٤ بايت فقط**: قفزة ذيلية إلى `ExitGame` — طواها المترجم لأن جسديهما متطابقان.
و`ExitGame` محلّي بالكامل: `UnRegisterEvents()` → `VivoxManager.DestroySelf()` → تحميل مشهد القائمة.

> ⚠️ **لا يُرسل أي شيء للخادم.** الإلغاء الحقيقي هو `SendStopFindMatch` وحده.

### ١.٥ أوامر ذات صلة ✅

`KGame.SendResumeLastGame` @`0x5313464` → غرفة `resume_game`.

## ٢. المقاعد

| الدالة | العنوان | الأمر | الحمولة |
|---|---|---|---|
| `SFS.JoinGameRoom` | `0x5262FD4` | نطاق `join_room` | `{ roomId: int, seat: int, password: string }` |
| `KGame.SendSwitchRequest` | `0x53132F8` | غرفة `switch_seat` | `{ seat: int }` |
| `KGame.SendApproveTeammate` | `0x5313230` | غرفة `approve` | `{ approve: bool, teammateId: int }` |

> `approve` نفس النص مُستخدَم أمرًا **ومفتاحًا**.

### ٢.١ ⭐ `set_seat` — دفعة من الخادم لا طلب ✅

`SFSCommands.SetSeat = "set_seat"` **لا يُرسَل من العميل قط** (تحقّق بالمراجع المتقاطعة:
مذكور فقط في `SFS_OnExtensionResponse` وفي معالج `gmt`).
هو **إشعار الخادم بالمقعد المخصَّص**، ويُعالَج بنفس مسار `join_room` (قراءة `roomId` و`error`).

### ٢.٢ ⭐ `TrySeatPlayer` — مصالحة حالة محلّية بلا شبكة ✅ @`0x5311AFC`

```csharp
if (Room == null) { LogWarning("TrySeatPlayer: Room is null (lastJoinedRoom) is null"); … }
var me = SessionModel.Instance.LocalUser;
if (Room.GetPlayerIndexByUser(me) >= 1) {              // فهرس 1-based من pinfo
    LogWarning("TrySeatPlayer: Player re-seat successfully");
    return true;
}
if (Room != SessionModel.Instance.CurrentRoom && CurrentRoom.IsGame) {
    LogWarning("TrySeatPlayer: Player is in different game room, reloading scene");
    ScreenManager.ReloadScene(); return false;
}
GameEventsChannel.TriggerLeaveRoom(false);
return false;
```

سلاسل التشخيص الستّ المقروءة حرفيًّا:
`Player seating fail, exit room` · `Player re-seat successfully` · `Player is in lobby, exit room` ·
`Room is null (lastJoinedRoom) is null` · `Player is in different game room, reloading scene` ·
`Player is in lobby or a corrupted game room, exit room`.

> ⭐ **ليست «مطالبة بمقعد»** بل **مصالحة حالة** تُنفَّذ عند كل استجابة أمر غرفة
> (عدا `game_state` و`sr`) وعلى غير المشاهد. تسوية المقعد نفسها يقرّرها الخادم عبر `pinfo`.
