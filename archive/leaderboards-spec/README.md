## خمس نتائج جوهرية

1. ⭐ **أربع قنوات لا واحدة**: SFS · ملفات JSON على CDN · REST العشائر · REST الأصدقاء.
2. ⭐ **لوحات الترتيب المصنّفة ملفات ثابتة على CDN** (`topLastWeek/topLastMonth/topOverall.json`)
   بترويسة `If-None-Match` — لا API حيّ.
3. ⭐ **لا تدوير مواسم في العميل إطلاقًا** — لا مؤقّت ولا مقارنة تاريخ. كله خادميّ.
4. ⭐ **العميل لا يحسب أي نسبة مئوية**، ولا يرتّب إلا في حالتين (`RankedOverall` والأصدقاء).
5. ⭐ **بطولات كملنا الشهرية في البلوت فقط** — `TournamentCurrentMonth/LastMonth` تتجاوزان
   `IsAvailableForCurrentGame` بـ`CurrentGame == Baloot`.
