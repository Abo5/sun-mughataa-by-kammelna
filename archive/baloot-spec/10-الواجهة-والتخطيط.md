## 3. تخطيط الطاولة

```
                    ┌───────────────┐
                    │  المقعد 3      │   ← الخوي (المقابل)
                    │  (Userbox)     │
                    └───────────────┘
   ┌────────┐         ┌─────────┐          ┌────────┐
   │المقعد 4 │         │ الميدان  │          │المقعد 2 │
   │Userbox  │         │playGround│          │Userbox  │
   └────────┘         └─────────┘          └────────┘
                    ┌───────────────┐
                    │  المقعد 1 (أنا)│
                    │   Hand (8 ورقة)│
                    └───────────────┘
```

✅ مراجع الميدان `[CS: CardGameVisualControls.cs]`:
```csharp
private Transform playGround;        // الميدان كاملًا

private SpriteRenderer[] eatingCardsSprites;    // 4 نسخ للأكلة

private SpriteRenderer[] _eatingsCount;

public  Transform allUserboxes[5];   // ← 5 مراجع (4 لاعبين + مشاهد)
private Transform bottomWatcher;
```
