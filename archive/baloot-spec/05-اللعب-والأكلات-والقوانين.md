> 🛑 **§٢.١ أُعيدت كتابتها بالكامل** من تفكيك ARM64 كامل لـ`PlayableCards` (١٠٠٪ من المسارات)

> تعتمد [١٥ §٣٤.٤](15-تدقيق-ARM64.md).

**الفروق التي صحّحها التفكيك عن نسخة Cpp2IL الأصلية** (محفوظة للسياق):

| البند | هنا (Cpp2IL) | [١٥ §٣٤](15-تدقيق-ARM64.md) (ARM64) |
|---|---|---|
| القائد والحكم المقفل | 🟡 «شرط إضافي» | ✅ **ممنوع افتتاح اللفة بنوع الحكم** |
| الاحتياطي عند تعذّر التكبير | عُمِّم على `cards` | ❌ **يختلف**: داخل الحكم ⇒ `suitCards` · عند الدق ⇒ `cards` |
| «الخوي فائز» | ذُكر جزئيًّا | ✅ موجود في **المسارين**، والعتبة = أقصى **الخصمين** لا الثلاثة |
| **إعفاء الإكة** | **غائب تمامًا** | ✅ قاعدة كاملة: خويّي معه إكة + من قبلي لم يدقّ ⇒ **كل أوراقي مسموحة** |
| قاعدة الدق | «العب حكمًا مع التكبير إن أمكن» | ✅ **حكم أعلى من عتبة الخصمين**؛ وإن تعذّر ⇒ **كل الأوراق** (لا إلزام بحكم أضعف) |
| ترتيب الرتب | جدول واحد | ✅ **جدولان بمجالين منفصلين**: الصن `1..8` والحكم `9..16` |

`CheckWhoEats` أي مقارنة صريحة «هل هذه حكم؟».

وأضافت الجولة الأخيرة فوق ذلك: **نفي أثر `isHokomClose` على المتابِع** · **حصر إعفاء الإكّة
في المنطقة A** · **الفرق في شرط «الخوي فائز» بين المنطقتين** · **الحالة الافتراضية لفهرس خارج ١..٤**.

## 1. دورة اللفة (Trick / لفّة)

```
اللاعب المبتدئ يلعب ورقة  →  تُحدَّد CurrentSuit من ورقته
   ↓
باقي اللاعبين يلعبون بالترتيب عكس عقارب الساعة
   ↓
بعد الورقة الرابعة: Stage = WaitingForEating
   ↓
CheckWhoEats → الفائز «يأكل» الأربع أوراق
   ↓
الآكل يبدأ اللفة التالية
```

| البند | المفتاح | المصدر |
|---|---|---|
| النوع الحالي (المطلوب اتباعه) | `[SFS: "current_suit"]` | ✅ `[CS: CardGame.cs → CURRENT_Suit]` |
| نوع الحكم | `[SFS: "ts"]` | ✅ `TRUMP_Suit` |
| الأوراق الملعوبة | `[SFS: "played_cards"]` | ✅ `PLAYED_CARDS` |
| الأوراق الملعوبة مرتّبة | `[SFS: "opc"]` + `[SFS: "opi"]` | ✅ `ORDERED_PLAYED_CARDS` / `ORDERED_PLAY_INDEX` |
| رقم الحركة | `[SFS: "mn"]` | ✅ `MOVE_NUMBER` |
| صاحب الدور | `[SFS: "mover"]` | ✅ `[CS: KGame.cs → MOVER]` |
| لعب ورقة | `[SFS: "card"]` | ✅ `CARD` |
| **الأوراق المسموح لعبها** | `[SFS: "ppcs"]` | ✅ `[CS: CardGamePlayer.cs → PLAYABLE_CARDS]` |

> ⭐ **معلومة معمارية حاسمة**: الخادم هو الذي يحسب قائمة الأوراق المسموح لعبها ويرسلها
> في `ppcs` إلى صاحب الدور. الواجهة **تعتم** (dim) بقية الأوراق ولا تسمح بلمسها.
> نفس المنطق مُنفَّذ محليًا في وضع الأوفلاين عبر `PlayableCards` أدناه — استعمله كمصدر الحقيقة.

## 2. ⭐ خوارزمية الأوراق المسموح لعبها (`PlayableCards`)

✅ التوقيع الكامل مقروء حرفيًا:

```csharp
// [CS: KammelnaOffline.Baloot.BalootUtils.cs → PlayableCards]
public static List<Card> PlayableCards(
        List<Card> cards,                       // أوراق اللاعب
        Card[]     playedCards,                 // أوراق اللفة الحالية على الأرض
        bool       firstPlayer,                 // هل هو أول لاعب في اللفة؟
        int        playerIndex,
        BalootGame.BalootGameMode gameMode,
        Suit       currentSuit,                 // النوع المطلوب
        Suit       trumpSuit,                   // نوع الحكم
        bool       isHokomClose,                // هل اللعب دبل مقفل؟
        bool[]     ekkahFlags);
```

### 2.1 ⭐⭐⭐ الخوارزمية كاملة — مفكوكة ١٠٠٪ ✅

> **`BalootUtils.PlayableCards` @`0x51FAA34` (4,420B، 1,105 تعليمة) — فُكّت كل مساراتها.**
> لم يبقَ فرع واحد غير مفكوك. هذا القسم يَجُبّ ما كان هنا سابقًا ويُكمل [١٥ §٣٤](15-تدقيق-ARM64.md).

#### 🛑 تصحيح التوقيع
الوسيط الثاني **`Card[]` لا `Dictionary<Suit, List<Card>>`** ✅ — تحقّقت بنفسي من تخطيط
مصفوفة il2cpp: `ldr w8,[x23,#0x18]` (`max_length`) ثم `ldr x0,[x23,#0x20]` (`elements[0]`)،
ولا وجود لأي `get_Item` على قاموس.

```csharp
public static List<Card> PlayableCards(
    List<Card> cards, Card[] playedCards, bool firstPlayer, int playerIndex,
    BalootGameMode gameMode, Suit currentSuit, Suit trumpSuit,
    bool isHokomClose, bool[] ekkahFlags)
```
⚠️ **`playedCards.Length` يجب أن يكون ٤** — كل المسارات تقرأ خانة بفهرس ≥ 2، وبعضها ≥ 3.

#### 🛑 نفيان مُثبَتان — تحقّقتُ منهما بنفسي

| النفي | الدليل |
|---|---|
| **`isHokomClose` لا تُقرأ إطلاقًا خارج فرع القائد** | مسحتُ كل ذكر لـ`w19` في الـ4,420 بايت: **٧ مواضع، واحد منها فقط قراءة** (`cbz w19` @`0x51FAB40`)؛ الستّة الباقية عدّادا حلقتين ودهس. |
| **`ekkahFlags` تُحمَّل مرّة واحدة في الدالّة كلّها** | `ldr x28, [x29, #0x10]` @`0x51FAD7C` — **موضع وحيد**، وهو داخل المنطقة A. |

⇒ ⭐ **«الحكم المغلق» لا أثر له البتّة على المتابِع** — لا على اتّباع النوع ولا على الدق ولا على
التكبير. أثره الوحيد: **منع القائد من افتتاح اللفة بنوع الحكم**.
⇒ ⭐ **إعفاء الإكّة يخصّ «الدق بالحكم» حصرًا** — لا وجود له في فرع القائد ولا في المنطقة B.

#### الشجرة الكاملة

```csharp
// ── (أ) القائد ──
if (firstPlayer) {
    if (!isHokomClose) return cards;                         // @0x51FAB40
    foreach (var c in cards) if (c.Suit != trumpSuit) list.Add(c);
    return list.Count == 0 ? cards : list;                   // csel @0x51FAD10
}

// ── (ب) المتابِع ──
foreach (var c in cards) if (c.Suit == currentSuit) list.Add(c);
var suitCards = list;

int me = playerIndex - 1, mate = (me+2)%4, prev = (me+3)%4;
int o1 = (me+1)%4, o2 = (me+3)%4;                            // الخصمان

if (suitCards.Count != 0) {
    if (gameMode.IsSunOrAshkal()) return suitCards;          // Sun / Ashkal
    if (gameMode != Hokom)        return cards;              // NotDetermined
    if (currentSuit != trumpSuit) return suitCards;          // اتّباع نوع غير الحكم
    /* المنطقة B */
} else {
    if (gameMode != Hokom) return cards;
    if (cards.Count(c => c.Suit == trumpSuit) < 1) return cards;
    /* المنطقة A */
}
// playerIndex ∉ {1..4} في أي منطقة ⇒ return cards   ✅ (الحالة الافتراضية)
```

> ⭐ **حلقتا الترشيح الأوليان `for` يدويّتان لا LINQ**، وتكتبان في القائمة نفسها (واحدة تُنفَّذ).

#### 🅑 المنطقة B — إجبار التكبير داخل الحكم
الشرط: `!firstPlayer && suitCards.Count != 0 && gameMode == Hokom && currentSuit == trumpSuit`

```csharp
int r(i) = (playedCards[i] != null && playedCards[i].Suit == currentSuit)
           ? GetCardValueRank(playedCards[i], Hokom) : 0;
int oppMax = Math.Max(r(o1), r(o2));                 // ⭐ الخصمان فقط
if (r(mate) > oppMax) return suitCards;              // الخوي فائز — بلا أي شرط إضافي
foreach (var c in suitCards)
    if ((uint)(c.Rank-5) <= 7 && HOKOM[c.Rank-5] > oppMax) result.Add(c);
return result.Count == 0 ? suitCards : result;       // ⭐ الاحتياطي suitCards
```
الدليل الحرفيّ على «الخصمان فقط» — ذيول الدمج الأربعة ✅:
`cmp w20,w0 ; csel w21,w20,w0,hi ; cmp w24,w21 ; b.hi` عند
`0x51FB530` (pi=1) · `0x51FB0AC` (pi=2) · `0x51FB61C` (pi=3) · `0x51FB444` (pi=4).
**الخوي = `(me+2)%4` في الأربعة، وورقته مستثناة من العتبة بلا استثناء.**

#### 🅐 المنطقة A — إجبار الدق بالحكم
الشرط: `!firstPlayer && suitCards.Count == 0 && gameMode == Hokom && أملك حكمًا`

```csharp
int r(i) = playedCards[i] == null             ? 0
         : playedCards[i].Suit == trumpSuit   ? GetCardValueRank(c, Hokom)   // 9..16
         : playedCards[i].Suit == currentSuit ? GetCardValueRank(c, Sun)     // 1..8
         :                                      0;                           // ⭐ ثلاثيّة

int oppMax = Math.Max(r(o1), r(o2));
if (r(mate) > oppMax && الثلاثة الآخرون لعبوا) return cards;     // ⭐ شرط إضافي هنا

bool prevNotTrump = playedCards[prev] == null || playedCards[prev].Suit != trumpSuit;
if (ekkahFlags[mate] && prevNotTrump) return cards;             // ⭐ إعفاء الإكّة

foreach (var c in trumpCards)
    if ((uint)(c.Rank-5) <= 7 && HOKOM[c.Rank-5] > oppMax) result.Add(c);
return result.Count == 0 ? cards : result;           // ⭐ الاحتياطي cards
```

> ⭐⭐ **الفرق الجوهريّ بين المنطقتين** — انسخه بدقّة:
> | | المنطقة A (الدق) | المنطقة B (التكبير) |
> |---|---|---|
> | شرط «الخوي فائز» | **يشترط أن يكون الثلاثة الآخرون قد لعبوا** | **بلا أي شرط إضافي** |
> | دالّة الرتبة | **ثلاثيّة** (حكم/نوع مطلوب/صفر) | ثنائيّة (نوع مطلوب فقط) |
> | إعفاء الإكّة | ✅ موجود | ⛔ غير موجود |
> | الاحتياطي | **`cards` الكاملة** | **`suitCards` فقط** |

**صياغة «الثلاثة لعبوا»** ✅ محسومة: العدّاد يزيد لكل خانة غير فارغة من أول خانتين مقروءتين،
والخانة الثالثة (خانة «السابق») إن كانت `null` يُقفَز فوق الفحص كليًّا
⇒ الشرط يتحقّق **⇔ الخانات الثلاث الأخرى كلّها غير فارغة ⇔ أنا اللاعب الرابع**.

**فهرس الخوي في إعفاء الإكّة — دليل مزدوج** ✅: الإزاحات المقروءة من `ekkahFlags`
هي `0x22, 0x23, 0x20, 0x21` (أي الفهارس **2, 3, 0, 1** للاعبين ١..٤) = `(me+2)%4` بالضبط؛
وفحوص الطول المرافقة (`≥3, ≥4, ≥1, ≥2`) تؤكّد الفهرس مستقلًّا.

#### الجداول والدوالّ المساعدة ✅ (قرأتُها بنفسي)

| العنوان | المحتوى | الاستعمال |
|---|---|---|
| `0x7253448` | `{1, 2, 3, 7, 4, 5, 6, 8}` | رتب الصن |
| **`0x7253468`** | **`{9, 10, 15, 13, 16, 11, 12, 14}`** | **رتب الحكم — الجدول الوحيد الذي تستعمله `PlayableCards` مباشرةً** |
| `0x7253488` | `{10, 2, 3, 4, 11}` | نقاط الصن |

```csharp
// GetCardValueRank @0x520A394
uint i = (uint)(c.Rank - 5);
int v = (i > 7) ? 0 : SUN[i];
if (mode == Hokom && i <= 7) v = HOKOM[i];

// IsSunOrAshkal @0x52FBB50  (١٦ بايت — قرأتُها بنفسي)
and w8, w0, #0xfffffffd ; cmp w8, #1 ; cset w0, eq      // (m & ~2) == 1 ⇒ Sun(1) أو Ashkal(3)

// GetSuitCards @0x51FC084
=> cards.Where(c => c.Suit == suit).ToList();            // ⚠️ قائمة جديدة دائمًا
```

> ✅ **لا سلسلة نصّيّة ولا عدد سحريّ في الدالّة كلّها.** الثوابت الوحيدة: `2` (Hokom) · `1` (Sun) ·
> `5` و`7` (إزاحة الرتبة ونطاقها) · `2` (عتبة العدّاد).

### 3.1 في الصن / أشكل ✅

```
المرشّحون = الأوراق التي Suit == currentSuit فقط.
الفائز = أعلى رتبة قوة حسب جدول الصن  [BIN: 0x7253448]
         (SEVEN=1, EIGHT=2, NINE=3, JACK=4, QUEEN=5, KING=6, TEN=7, ACE=8)
```
أي ورقة من نوع مختلف **لا تدخل المنافسة إطلاقًا**.

### 3.2 في الحكم ✅

```
① إن وُجدت أي ورقة Suit == trumpSuit:
      المرشّحون = أوراق الحكم فقط
      الفائز = أعلى رتبة حسب جدول الحكم  [BIN: 0x7253468]
               (SEVEN=9, EIGHT=10, QUEEN=11, KING=12, TEN=13, ACE=14, NINE=15, JACK=16)
② وإلا:
      المرشّحون = أوراق currentSuit
      الفائز = أعلى رتبة حسب جدول الصن  [BIN: 0x7253448]
```

> ✅ العنوانان `119878728` (= base+1096 = جدول الصن) و`119878760` (= base+1128 = جدول الحكم)
> يظهران حرفيًا داخل `CheckWhoEats` المفكوكة — تأكيد قاطع لأي جدول يُستخدم متى.

### 3.3 ⚠️ مسار مختصر — **لا وجود له**

~~الكود يفحص `cards.Length == 1` مبكرًا.~~

🛑 **مُصحَّح بالتدقيق**: تفكيك `CheckWhoEats` @`0x520584C` كاملًا (1,880B) **لم يجد أي فحص طول**.
البنية هي `Value(cards[0..3])` ← `Max` ← `IndexOf` بلا اختصار.
المقارنات `cmp w8,#1/#2/#3` هي **فحوص حدود مصفوفة** لا مسارات مختصرة.
الصيغة الصحيحة في [١٥ §٣٤.٤](15-تدقيق-ARM64.md).

## 7. ملخص جدول القرار (نسخة قابلة للتنفيذ مباشرة)

```
function playableCards(hand, trick, isFirst, mode, currentSuit, trumpSuit, hokomClosed):
    if isFirst:
        return hokomClosed ? applyClosedDoubleRestriction(hand) : hand

    same = hand.filter(c => c.suit == currentSuit)

    if mode == SUN or mode == ASHKAL:
        return same.length ? same : hand

    // mode == HOKOM
    if same.length:
        if currentSuit == trumpSuit:
            highest = maxTrumpRankOnTable(trick)
            higher  = same.filter(c => hokomRank(c) > highest)
            return higher.length ? higher : same
        return same

    // لا يملك النوع المطلوب
    if teammateIsWinning(trick): return hand
    trumps = hand.filter(c => c.suit == trumpSuit)
    if !trumps.length: return hand
    highest = maxTrumpRankOnTable(trick)
    higher  = trumps.filter(c => hokomRank(c) > highest)
    return higher.length ? higher : trumps
```
> ✅ متوافق مع بنية `PlayableCards` المفكوكة ومع قائمة أنواع القيد الثمانية.
> 🟡 شرط «الخوي فائز» مستنتج من وجود قيد `ModeCut` («ما دق بالحكم») دون غيره،
> وهو القاعدة المعتمدة في البلوت السعودي.
