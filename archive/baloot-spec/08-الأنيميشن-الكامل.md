# ٠٨ — الأنيميشن الكامل ⭐

[↩ العودة للفهرس](README.md)

> كل رقم في هذا الملف مأخوذ إمّا من الكود المفكوك أو من القيم المُسلسلة داخل مشهد Unity.
> المحرّك: **DOTween** + منحنيات `AnimationCurve` + عدد قليل من مقاطع `AnimationClip`.
>
> **قاعدة عامة**: الحركة في هذه اللعبة **مكتوبة بالكود** لا بالـ Timeline.
> لإعادة بنائها في أي محرّك آخر يكفي تنفيذ نفس التسلسلات بنفس المدد والـ eases.

## 4. أنيميشن الورقة في اليد (اختيار / تعتيم / لعب)

هذا هو الجزء الذي سألت عنه تحديدًا: **كيف تُظهر اللعبة الأوراق الصالحة للعب**.

✅ `[CS: GameCard.cs]` — الصنف الذي يتحكّم بورقة واحدة في اليد.

### 4.1 الدالة المركزية

```csharp
// [CS: GameCard.cs → AnimateCardState]
private void AnimateCardState(Color targetColor,
                              float targetY,
                              float targetScale,
                              float colorDuration  = 0.25f,
                              float moveDuration   = 0.1f,
                              float scaleDuration  = 0.1f,
                              float moveDelay      = 0f)
{
    sprite.DOKill();
    _activeStateAnimation?.Kill();
    _activeStateAnimation = DOTween.Sequence()
        .Append(sprite.DOColor(targetColor, colorDuration))
        .Join(transform.DOLocalMoveY(targetY, moveDuration))
        .Join(transform.DOScale(targetScale, scaleDuration));
}
```

**القيم الممرَّرة** 🛑 مُصحَّحة: ليست «افتراضية» — كل مواقع النداء الخمسة تمرّر القيم صراحةً،
و**`Prepared` وحده يستعمل `0.05`** للحركة والتحجيم. الجدول الكامل في [١٥ §٢٨.٣](15-تدقيق-ARM64.md).

### 4.2 حالات الورقة

✅ `[ENUM: CardStatus]` — `[CS: CardStatus.cs]`
```csharp
public enum CardStatus { InHand, Prepared, PreparedForClick, Preplay }
```

| الحالة | الدالة | السلوك |
|---|---|---|
| `InHand` | `CardInHand()` | الوضع الطبيعي: لون أبيض (أو أحمر إن `_isHighlightedForDiscard`)، `y = _cardPositionY`، `scale = 1` |
| `Prepared` | `CardPrepared()` | **مُختارة**: ترتفع وتكبُر + صوت + إظهار بطاقة السعر |
| `PreparedForClick` | `CardPreparedForClick()` | مُهيّأة للنقر (وسيط) |
| `Preplay` | `CardPreplay()` | مُجدوَلة للّعب مسبقًا (pre-play) |

### 4.4 ⭐ تعتيم الأوراق غير الصالحة للعب

```csharp
// [CS: GameCard.cs]
private static readonly Color ColorGray;     // ← لون التعتيم
private static readonly Color ColorRed;      // ← لون التمييز للرمي
private bool _isDimmed;
private bool _isHighlightedForDiscard;

private void DimCard(bool isDimmed)            { _isDimmed = isDimmed; OnStatusChange(); }
private void HighlightForDiscard(bool value)   { _isHighlightedForDiscard = value; ...
                                                 sprite.DOColor(ColorRed, 0f); }
```

**آلية العمل الكاملة**:
```
① الخادم يرسل قائمة الأوراق المسموح لعبها  [SFS: "ppcs"]
      → CardGamePlayer.PlayableCards
② Hand يقارن كل ورقة في اليد بالقائمة
③ كل ورقة غير موجودة  → DimCard(true)   → لونها ColorGray
   كل ورقة موجودة      → DimCard(false)  → لونها أبيض
④ الانتقال اللوني يتم عبر DOColor بمدة 0.25 ث (colorDuration الافتراضي)
⑤ الأوراق المُعتَّمة لا تستجيب للنقر  ([CS: Hand.cs → CanClickGoThrough])
```

> ⭐ **هذه بالضبط «الأنيميشن في اختيار الأوراق التي تصلح أن تُلعب»**:
> ليس وميضًا ولا إطارًا، بل **تدرّج لوني إلى الرمادي خلال 0.25 ثانية** للأوراق غير الصالحة،
> وترك الصالحة بلونها الكامل. عند لمس ورقة صالحة ترتفع 100 وحدة وتكبُر إلى 1.2×.
>
> **في نسختك**: غيّر `ColorGray` و`ColorRed` فقط، واحتفظ بالمدد كما هي.
