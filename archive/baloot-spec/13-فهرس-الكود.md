# ١٣ — فهرس الكود الكامل للبلوت

[↩ العودة للفهرس](README.md)

> **المسار الجذر لكل الملفات أدناه**:
> `source-code/cpp2il-cs-full/KammenlaAssembly/<اسم الملف>`
>
> الأسماء التي تحتوي `.` (مثل `BalootGame.BalootGameMode.cs`) هي **أنواع متداخلة**،
> وملفها يحتوي نص الصنف الخارجي كاملًا (لذلك تتساوى أعداد الأسطر).
> الملفات التي تحتوي `<>c` أو `d__` أو `DisplayClass` هي أصناف مولّدة من المترجم (lambdas / iterators)
> ولا تحتاج قراءتها إلا لتتبّع تفاصيل تعبير lambda معيّن.

### كيفية قراءة جدول ثابت من الثنائي

```python
import struct
f = open("UnityFramework", "rb")
f.seek(0x7253488)                       # العنوان الافتراضي = إزاحة الملف (__TEXT يبدأ من 0)
print(struct.unpack("<5i", f.read(20))) # → (10, 2, 3, 4, 11)  = أبناط 10/J/Q/K/A في الصن
```
