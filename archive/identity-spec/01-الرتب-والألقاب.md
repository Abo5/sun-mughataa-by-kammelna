## ✅ ما تحقّقتُ منه بنفسي

مسحتُ `PlayerRank..cctor` @`0x50B1FD8` (688B) واستخرجت كل أزواج `(rank, points)` الممرّرة
إلى `Dictionary.Add` — **ثلاث مجموعات من ستّ**، مطابقة تمامًا لما ورد:

```
balootRanksLimits    : 1000 · 4000 · 10000 · 20000 · 40000 · 59995
tarneebRanksLimits   :  500 · 1500 ·  3500 ·  6000 · 10000 · 15000
jackarooRanksLimits  :  500 · 1500 ·  3500 ·  6000 · 10000 · 15000   ← متطابق مع الطرنيب
```

وتناقض `×4` / `×5` **حقيقيّ ومؤكَّد**:
```asm
PlayerRank$$GetTotalSubRank @0x50B1A00 (16B)
  ldp w9, w8, [x0, #0x10]      ; w9=SubRanksCount  w8=Rank
  add w8, w9, w8, lsl #2       ; SubRanksCount + Rank×4
  sub w0, w8, #4

UserListComparer$$GetRankValue @0x4F0F4F0 (52B)
  add w8, w8, w8, lsl #2       ; Rank×5
  add w8, w8, w9               ; + SubRanksCount
  sub w0, w8, #4
```

## ٢. ⭐ جدول العتبات — مُستخرَج بالبايت

| الرتبة | **بلوت** | **طرنيب وجكارو** |
|---|---|---|
| Beginner | 1,000 | 500 |
| Intermediate | 4,000 | 1,500 |
| Advanced | 10,000 | 3,500 |
| Professional | 20,000 | 6,000 |
| Expert | 40,000 | 10,000 |
| Master | **59,995** | 15,000 |

> 🟡 **لماذا 59,995؟** خطوة الرتبة الفرعية = `(max−min)/5` بقسمة صحيحة.
> `(59995−40000)/5 = 3999` بالضبط، و`40000 + 5×3999 = 59995` — قيمة مُختارة لتُقسَم بلا باقٍ.

`GetRanksLimit(Games)` @`0x50B0FA4`: `Baloot→baloot · Tarneeb→tarneeb · Jackaroo→jackaroo ·
default→ArgumentOutOfRangeException`.

## ٣. ⭐ الرتبة الفرعية — `CalculateRank` @`0x50B15B0` (1104B) ✅

```csharp
int min = (rank == 1) ? 0 : limits[rank-1];
int max = limits[rank];
int step = (max - min) / 5;                              // قسمة موقّعة
SubRanksCount   = Math.Min(4, (Points - min) / step);    // الحقل 0x10
MinSubRankLimit = SubRanksCount * step + min;            // 0x1C
MaxSubRankLimit = MinSubRankLimit + step;                // 0x20
```
⇒ **كل رتبة = ٥ رتب فرعية (0..4)**.

| الرتبة | بلوت: المدى / الخطوة | طرنيب وجكارو |
|---|---|---|
| Beginner | 0–1,000 / **200** | 0–500 / **100** |
| Intermediate | 1,000–4,000 / **600** | 500–1,500 / **200** |
| Advanced | 4,000–10,000 / **1,200** | 1,500–3,500 / **400** |
| Professional | 10,000–20,000 / **2,000** | 3,500–6,000 / **500** |
| Expert | 20,000–40,000 / **4,000** | 6,000–10,000 / **800** |
| Master | 40,000–59,995 / **3,999** | 10,000–15,000 / **1,000** |

> ⚠️ `PlayerRank..ctor(points, isNew)` @`0x50B1404` يقرأ `Prefs.GetEnum<Games>("CurrentGame")`
> ⇒ **الرتبة المعروضة تعتمد على اللعبة المختارة حاليًّا**.

### ⚠️ خلل مُثبت — تصادم الرتب الفرعية

بما أن كل رتبة فيها **٥** فرعيات، فالصيغة الصحيحة `SubRanksCount + 5×Rank − 4`.
لكن `GetTotalSubRank` يستعمل **×4** ⇒ تصادم: `Beginner-sub4 = 4 = Intermediate-sub0`.
وهو **مستعمل فعليًّا** في `KGame.IsGameBalanced` @`0x53147CC`:

```csharp
var teamA = new PlayerRank(p[0] + p[2], false);   // المقعدان ٠ و٢
var teamB = new PlayerRank(p[1] + p[3], false);   // المقعدان ١ و٣
return Math.Abs(teamA.GetTotalSubRank() - teamB.GetTotalSubRank()) < 4;
```

> ⚠️ **كود ميّت**: `MinPointsToRank` @`0x50B1354` و`MaxPointsToRank` @`0x50B2288` — **بلا مُستدعٍ**.

## ٤. ⭐ كسب النقاط — `rank_report`

| المفتاح | المعنى |
|---|---|
| `pp` / `cp` | النقاط قبل/بعد |
| **`gp`** | **الدلتا** (موجبة أو سالبة) |
| `sp` | نسبة مكافأة سلسلة الفوز (٪) |
| `bg` | هل المباراة متوازنة |
| `tm_pts` · `opo1_pts` · `opo2_pts` | نقاط الشريك والخصمين |
| `ps` / `cl` / `oa` | أسلوب اللعب / القطع / التقييم العام |
| **`aa`** | الإنجازات المكتسَبة — **`Take(4)` فقط** ✅ |

**`get_BonusPoints`** @`0x5301B3C`:
```
BonusPoints = (int)( ((sp/100f) / (sp/100f + 1f)) * gp )
```
> ⭐ **`gp` يشمل المكافأة أصلًا**؛ الأساس = `gp / (1 + sp/100)`.
> أي **سلسلة الفوز مضاعِف ضربي `×(1 + sp/100)`**.

> ⭐ **نفي صارم**: لا توجد أي صيغة «كم نقطة لكل فوز/خسارة» في الثنائي — الحساب خادميّ بالكامل.

## ٥. الألقاب ✅

**اللقب ليس نوعًا مستقلًّا — هو إنجاز نوعه `Title`**:
```csharp
enum AchievementType { Achievement=0, Title=1, Trophy=2 }
```
⇒ `agt` = `id` إنجاز نوعه `Title` · `atl` = مستواه المفعَّل.

```csharp
class AchievementLevelModel {
  int levelId@0x10;    // رقم المستوى
  int levelCap@0x14;   // العتبة العددية
  int points@0x18;     // نقاط الإنجاز الممنوحة
  string description@0x20; FileInfoModel image@0x28;
}
```
`UserAchievementModel.isUnlocked` @`0x50AFD7C` = **`levelId > 0`** (لا شيء آخر) ✅.
⚪ `ORDINAL_LEVELS` = «المستوى الأول … العاشر» ⇒ حتى **١٠ مستويات**.

**التفعيل**: `PUT api/Users/ActivateTitle/{titleId}` ✅ ·
والعرض يربط حيًّا على `agt` (`TitleSetter.Initialize` @`0x50CDB28`).

### `TitleRestriction` في البطولات ✅

`TournamentAddonType.TitleRestriction = 4`. الإعداد من JSON: `Price` · `AllowedTitles` (string[]) ·
`Availability { Disabled=0, Public=1, Private=2 }`.

**`IsEligible()`** @`0x502DBA0` — **دلالة OR**: لقب واحد مطابق بمستوى كافٍ يكفي.
```csharp
if (TournamentTitles.IsNullOrEmpty()) return true;      // بلا قيد
foreach (i) if (myProfile.gameAchievements.Any(a =>
        a.gameAchievementId == TournamentTitles[i]
     && a.isUnlocked && a.levelId >= RequiredLevels[i])) return true;
```
> ⚠️ **مزلق سلوكيّ**: `RequestMyProfile` غير متزامنة ورد الاتصال يكتب في متغيّر محلّي،
> بينما `IsEligible()` يُرجع فورًا ⇒ **يُرجع `false` إن لم يكن الملف في الكاش مسبقًا**.

## ٦. ⭐ الإنجازات — كتالوج خادميّ بالكامل

`AchievementsManager.OnLogin` @`0x500EDB0` يسجّل في `ContentSyncService` بالمفتاح **`"achievements"`**،
ونقطة الجلب **`api/Achievements/Since`** (تسليم تفاضليّ).

**كتالوج مفاتيح المزامنة الكامل** ✅ (`ContentPushService.BuildCatalog` @`0x5247838`):
```
remote_config · achievements · store_profile_gifts · store_products · store_home ·
store_items · store_item_groups · notifications · app_announcements · predictions ·
hints · mass_events
```

> ⭐⭐ **نفي قاطع**: لا قائمة إنجازات ولا عتبات ولا مكافآت في الثنائي إطلاقًا.
> الاسم والوصف و`levelCap` و`points` والصورة — **كلها من الخادم**.
> المعرّفات الوحيدة المشفّرة هي ثلاث جوائز شهرية:
> `monthly_winner` · `monthly_second` · `monthly_ranker`.

**الاستلام**: `POST api/Achievements/Claim?achievementId=…&levelId=…` ✅
**الأيقونات**: `achievements/{achievementId}_{level}` @`0x4EE10C8`

> ⚠️ **تسمية مضلّلة**: `GetAchievementCount` @`0x4ED04B0` يقرأ **`achp`** وهو
> **نقاط الإنجاز لا عددها**. العدّ الحقيقي يُحسب في العميل.
