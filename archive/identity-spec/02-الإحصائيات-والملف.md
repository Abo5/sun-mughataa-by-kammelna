## ١. ⭐ صيغة السلك `sts` ✅

`CardGameStatistics.SetStatistics` @`0x52FF2B8` (1936B). الثوابت: `Statistics="sts"` · `PlayerKey="p"` · `TeamKey="t"`.

```csharp
var sts = data.GetSFSObject("sts");
foreach (string key in sts.GetKeys()) {
    int index = int.TryParse(key, out v) ? v : -1;       // csinv ⇒ -1 عند الفشل
    var inner = sts.GetSFSObject(key);
    players = inner["p"] → List<double>   (كلها Math.Round)
    teams   = inner["t"] → List<double>
    StatisticsList.Add(new Statistic(index, teams, players));
}
```

**التسلسل الكامل**: `gameResult["gst"]["sts"]["<statIndex>"]{ "p":[×4], "t":[×2] }`

### ⭐ اشتقاق الفرق في العميل — `AddStat` @`0x52FFA48` ✅
```csharp
if (TeamsStatistic.IsNullOrEmpty() && PlayersStatistic.Count >= 4)
    TeamsStatistic = [ p[0] + p[2],      // المقعدان ٠ و٢
                       p[1] + p[3] ];    // المقعدان ١ و٣
```
⇒ **إن أرسل الخادم `p` فقط، العميل يشتقّ `t` بنفسه.**
وأي إحصائية بـ`p.Count != 4` وبلا `t` **تُحذف** من القائمة.

# ٥. الملف الشخصي

## ٥.١ ⭐⭐ `ad` — آلية كسر الكاش

**`ad` ليس لاحقة URL ولا معامل استعلام.** `LocalUnityWebRequestAssetLoader.ValidateCachedFile`
@`0x5098C44` (216B):

```csharp
static bool ValidateCachedFile(string localPath, DateTime? timeStamp) {
    if (!File.Exists(localPath))  return false;
    if (!timeStamp.HasValue)      return false;          // ⭐ null ⇒ الكاش غير صالح أبدًا
    return !(timeStamp.Value > File.GetLastWriteTime(localPath));
}
```

> ⭐ **`ad` طابع زمنيّ يُقارَن بـ`mtime` للملف المحلّي.** إن كان `ad` من الخادم **أحدث** من
> زمن تعديل الملف ⇒ الكاش باطل ⇒ إعادة تنزيل (فيصير `mtime` ≥ `ad`).
> رفع صورة جديدة ⇒ يرفع الخادم `ad` ⇒ **يُبطل كاش كل الأجهزة تلقائيًّا**.
> و`ad = null` ⇒ **لا صورة إطلاقًا**.

**المسارات**: `avatars/{userId}` · `avatars/{userId}_thumbnail`
**العمليات**: `api/Users/UploadAvatar` · `api/Users/RemoveAvatar` · `api/Moderators/RemoveAvatar/{0}`
🟡 عنوان الـCDN من حقل ساكن في `Config` — لا سلسلة حرفية في الثنائي.

## ٥.٣ الخانة المميّزة `fsa`/`fsl` ✅

```csharp
// GetFeaturedSlot @0x4ED095C (384B)
if (!user.ContainsVariable("fsa")) return null;
string id = user.GetVariable<string>("fsa", "0");   // مُعرّف الإنجاز/الجائزة

```
**التعديل**: `PUT api/GameStore/SetFeaturedSlot?slotId=…&slotLevel=…` · `PUT …/ResetFeaturedSlot`

> ⚠️ **نفي صارم**: الثابت `FeaturedSlotsCount = 6` يعود لصنف **`EmoteSaveData`** (ترتيب الإيموتات)
> **ولا علاقة له بالملف الشخصي**. خانة الملف الشخصي **واحدة فقط** (نموذج مفرد لا مصفوفة).

## ٧. ما لم يُحسَم 🟡

1. ~~عنوان CDN الأصول.~~ ✅ الحقل `Config.BlobHost` (ساكن @`0x28`)، يُقرأ عبر `ImageCacher.GetRemoteImagePath`
   @`0x4EE1C90` = `Concat(BlobHost, imageId)`. **مخبوزٌ ثمّ يُستبدل من الخادم**: `LoadServersConfig` يزرع
   `defaultBlobUrlFallback` (= `defaultBlobUrl + environment + "/"`)، ثمّ يُستبدل من `ConfigsModel.BlobHost`.
   المخبوز من `ScriptableObject` = مضيف تخزين سحابيّ + `environment=Production` ⇒ الجذر `…/production/`.
   **لا رمز خاصّ ولا SAS token في المسار.**
2. ~~`GetNearestFTAwardStage` @`0x50B1DA8` (560B) — لم تُفكّ.~~ ✅ **مفكوكة كاملةً في [٠٤ §١](04-المسار-السريع-والرتب.md)** — و🛑 «الأقرب» **ليست أقرب مسافة** بل أوّل عتبة أكبر من النقاط في مسح متسلسل؛ وتُعيد `{-1,-1}` بعد آخر مرحلة.
3. هل `gp` صفر في المباريات الودّية؟ لا شرط في العميل — خادميّ.
4. الفرق الدقيق بين `pts` و`tpts` في الترقية.
5. ~~قيم `MonthlyTournamentEligibilityType`.~~ ✅ **[٠٤ §٣](04-المسار-السريع-والرتب.md)**: `NotEligible=0 · Platinum=1 · Gold=2 · Silver=3 · Bronze=4` — ⚠️ الأرقام تصاعديّة والجدارة تنازليّة.
6. ~~معيار «الرتبة الصالحة» في `GetHighest/Lowest/AverageRank`.~~ ✅ **[٠٤ §٤](04-المسار-السريع-والرتب.md)**: المعيار `Rank != 0` ⇒ **إقصاء البوتات** (`Ranks.AI = 0`)؛ والمتوسّط `fdiv` بلا تقريب؛ و🛑 `count==0` ⇒ **`NaN`**، و`FirstOrDefault` يعيد `0` = AI.
7. ~~جدول `GetStatisticType` لكل إحصائية.~~ ✅ `int[18]` ساكنة @`0x72536D4` =
   `[0,0,0,2,0,0,0,0,2,0,2,0,0,2,0,0,0,0]` — السلبيّات: `LostBiddings(3)` · `PictureWithAce(8)` ·
   `ReverseKaboot(10)` · `UpsideDownKaboot(13)`. وجكارو جدولٌ مستقلّ @`0x7253728` (١٢ مدخلًا، `FastToBase = PositiveLowest`).
8. شرط فتح مستوى الإنجاز (`value >= levelCap`) — الشكل المعروض مُثبت، التقييم خادميّ.
9. هل يقبل `agt` لقبًا غير مملوك؟ (⚪ `No such title owned` بلا مُستدعٍ في العميل).
10. ~~بنية `RemoteConfig.Current.FastTrack` لجوائز النقاط.~~ ✅ **[٠٤ §٢](04-المسار-السريع-والرتب.md)**: `TicketPrice=85` · `MaxWaitingTimeSeconds=10` · `MatchMakerTimerSeconds=15` · والعتبات المخبوزة (١٤ عتبة في مستويين، وفيها الشذوذ `10500`).
