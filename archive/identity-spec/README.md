## خمس نتائج جاهزة للنقل إلى خادمك

1. **جدولا العتبات**: بلوت `{1000, 4000, 10000, 20000, 40000, 59995}` ·
   طرنيب وجكارو `{500, 1500, 3500, 6000, 10000, 15000}` — و**٥ رتب فرعية** بخطوة `(max−min)/5` صحيحة.
2. **`Elite` و`King` غير قابلتين للبلوغ** — بلا عتبة وبلا ترجمة. أعلى رتبة = **نابغة**.
3. **مكافأة سلسلة الفوز مضاعِف ضربي**: `gp` يشمل المكافأة، والأساس `gp / (1 + sp/100)`.
4. **`ad` مقارنة `mtime` لا معامل URL**: ارفعه عند تغيير الصورة وسيُبطل العميل كاشه بنفسه؛
   وإن أرسلته فارغًا فلن يُستعمل أي كاش.
5. **الإنجازات والألقاب كتالوج خادميّ** عبر `api/Achievements/Since`؛ لا شيء منها في التطبيق
   عدا `monthly_winner` · `monthly_second` · `monthly_ranker`.

## ⚠️ خلل مُثبت

`GetTotalSubRank` يستعمل **×4** بينما الصحيح **×5** (خمس فرعيات لكل رتبة) ⇒ تصادم
`Beginner-sub4 = Intermediate-sub0`. وهو مستعمل في `KGame.IsGameBalanced`.
