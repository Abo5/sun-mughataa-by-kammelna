## ست نتائج جوهرية

1. ⭐ **لا بادئة ولا لاحقة**: `PlayerPrefsScope.Suffix` هو السلسلة الفارغة حرفيًّا.
2. ‼️ **غلاف ثانٍ مهمَل: `PlayerPrefsGame`** يضيف `_<Game>` — ومنه `SoundActor_<Game>`.
3. ✅ **`Prefs.DeleteAll` بلا مستدعين** — لا «مسح شامل» للتفضيلات في التطبيق كلّه.
4. ⭐ **`AccessTokenExpires` ليست سلسلة في الثنائي** — تُشتقّ بـ`key + "Expires"`.
5. 🚩 **`DevelopmentHostOverride`** يحوّل التطبيق إلى أي خادم خلفي عند الإقلاع.
6. 🚩 **`UsedReplayTrails`** بوابة استحقاق محليّة بلا توقيع (مقابل `MaxReplayFreeTrials = 2`).
