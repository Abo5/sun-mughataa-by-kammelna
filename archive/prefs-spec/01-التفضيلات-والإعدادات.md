# ٠١ — `PlayerPrefs` وشاشة الإعدادات

[↩ الفهرس](README.md)

> **لم تُقرأ ولم تُطبع أي قيمة مخزَّنة.** المفاتيح الحساسة (التوكنات، كلمة المرور) بالاسم فقط.
> كل مفتاح موسوم «حيّ» تحقّقتُ من وجوده في `ScriptString`.

## ✅ ما تحقّقتُ منه بنفسي

| الادّعاء | النتيجة |
|---|---|
| `PlayerPrefsScope.Suffix` = السلسلة الفارغة | ✅ `STR[0x8D157D0] == ''` |
| `PlayerPrefsGame.Suffix` = `"_" + CurrentGame` | ✅ `"_"` @`0x8CFD390` ثم `Preferences.get_CurrentGame` → `Enum.ToString` → `String.Concat` |
| `Prefs.DeleteAll` بلا مستدعين | ✅ **صفر** في المدى `0x2700000–0x6D00000` |
| كل أسماء المفاتيح أدناه حيّة | ✅ موجودة في `ScriptString` بعناوينها |

## ١. ⭐ لا بادئة ولا لاحقة

`Prefs.GetString` @`0x4FFCF60` (108B):
```asm
adrp/add x21, #0x8D157D0          ; ← فتحة السلسلة الحرفية ""
ldr  x1, [x21]                    ; x1 = PlayerPrefsScope.Suffix
bl   System.String$$Concat        ; Concat(key, "")
b    UnityEngine.PlayerPrefs$$GetString
```

> ⭐ **`Prefs.X("K")` ⇒ مفتاح `PlayerPrefs` اسمه `K` حرفيًّا.**
> سطر `Concat(key, "")` باقٍ في الكود المُولَّد — فاللاحقة كانت **مُصمَّمة لتكون قابلة
> للتبديل** لكنها فارغة في هذا البناء. (نقطة حقن مجّانية لو أردت فصل بيانات نسختك.)

`PlayerPrefsScope.get_Suffix` @`0x4FFD36C` (68B) · `Key(string)` @`0x4FFD3B0` (92B).
