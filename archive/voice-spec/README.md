## خمس نتائج جوهرية

1. ⭐ **`KUtil.GetPlatform()` ثابت `2` على iOS** ⇒ كل فروع WebGL (`== 3`) كود ميّت.
2. ⭐ **الغرفة تقرّر لا المستخدم**: متغيّرا SFS `vc` و`vcs`؛ والمشاهد **مكتوم قسرًا**.
3. ⭐ **اسم القناة** = `{بيئة}_{خادم}_{غرفة}_` ← قصّ ٢٥٦ محرفًا ← `SanitizeChatMessage`.
4. ⭐ **أمر SFS واحد للصوت في البروتوكول كلّه**: `mm` بمعامل `ism`.
5. 🔴 **`Util.VivoxAuthUtil` كود ميّت (صفر مستدعٍ) يحمل مفتاح توقيع مخبوز** — القيم لم تُنسخ هنا.
