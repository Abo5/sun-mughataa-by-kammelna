## خمس نتائج جوهرية

1. ⭐⭐ **ثلاث طبقات لونية منفصلة** — نظام ثيم مركزيّ (١١٠٧ مكوّن) · صور بعيدة · ألوان لكل عنصر.
2. ⭐ **لا أطلس ولا جدول `id → sprite`** — المعرّف يصير مسار ملف بعيد.
3. ⭐ **استبدال ملفّ لوحة واحد يعيد صبغ ~١١٠٧ عنصر** بلا سطر كود.
4. ⚠️ **الصبغة (hue) مثبَّتة على صفر** في `ApplyHsvMultiplier` — الهوية من اللوحات والصور حصرًا.
5. ⭐ **ثيم الغرفة يغيّر صورة واحدة فقط** — الجوخ والحدود والخانات لا تتغيّر برمجيًّا.
