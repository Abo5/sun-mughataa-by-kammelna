## ١. ⭐⭐ ثلاث طبقات لونية منفصلة

|---|---|---|

## ٢. نظام الثيم اللوني

```csharp
enum PaletteColor { Primary=0, PrimaryEffect=1, PrimaryText=2, Secondary=3,
                    SecondaryEffect=4, SecondaryText=5, Accessory1=6, Accessory2=7 }
```

```asm
ThemeColorPalette$$GetColor @0x516AA78 (200B)
  cmp  w1, #8 ; b.hs → ArgumentOutOfRangeException
  adrp x8, #0x7253000 ; add x8, x8, #0x28 ; ldr x8, [x8, w1, uxtw #3]   ; r-offsets
  …  #0x68 (g) · #0xA8 (b) · #0xE8 (a)
  ldr s0,[x0,x8] ; ldr s1,[x0,x9] ; ldr s2,[x0,x10] ; ldr s3,[x0,x11]
```
> ⚠️ **حافظ على ترتيب `PaletteColor` (0..7) حرفيًّا** — جدول القفز معتمد عليه.

### `ThemeableGraphic.OnThemeUpdated` @`0x516AF5C` (248B) ✅

```csharp
Color c = profile.GetColor(this.color);          // PaletteColor @+0x30
c.r *= multiplier.r; c.g *= multiplier.g;
c.b *= multiplier.b; c.a *= multiplier.a;        // Color @+0x34
c = ColorExtension.ApplyHsvMultiplier(c,
        hueShift  : 0f,          // ⭐ fmov s4, wzr — مثبَّت صفرًا دائمًا
        saturation: this.saturation,  // @+0x44
        value     : this.value,       // @+0x48
        alpha     : 1f);
this.themeable.color = c;
```

> ⭐ **الصبغة لا تُزاح برمجيًّا أبدًا** — لا يمكن تدوير الهوية اللونية عبر هذا المسار.
> التغيير يجب أن يكون في أصول `ThemeColorProfile`.

**أولوية اختيار اللوحة** (`get_ActiveProfile` @`0x516B1E4`):
`overrideProfile` ?? `serializedProfile` ?? `GlobalThemeColorProfile.Instance`.

## ٣. أظهر الورق

```
user "c" (GetActiveCardbackID @0x4ED089C) │ room "cb" (GetCardbackID @0x4ECA370)
  → CardBackSetter.Initialize @0x50C9B28 ← يربط حيًّا على "c"
  → AssignCardBackHelper @0x50C8F64
       ├ AssignMaterial @0x50C9188 : isUnique ? UniqueCard : BasicCard
       ├ AssignEffect   @0x50C92E0 : isUnique ⇒ استنساخ UniqueCardPsEffect + SetAsFirstSibling
       └ AssignImage    @0x50C94B4 : id ≥ 1 ⇒ items/{id}_InGame ، وإلا defaultCardBack
```

> ⭐ **ترتيب الرسم**: `SetAsFirstSibling` ⇒ الجسيمات **خلف** الورق لا أمامه.

**الاحتياطي**: `defaultCardBack` (@`0x58`) **يُلتقط تلقائيًّا من `cards[0].sprite`** عند أول
استدعاء — أي أن «الافتراضيّ» هو ما وُضِع يدويًّا في الـPrefab، لا أصل مسمّى ✅.

**الخامات**: `MaterialStore { BasicCard@0x18, UniqueCard@0x20 }`.
🟡 المرجّح: `CardbacksMaterial` = Basic و`Shine` = Unique.
`Shine.mat`: `_BorderColor (1, 0.864, 0, 0)` · `_GlowColor (1, 0.8136, 0, 0)` · `_Speed` **−2.0** (يسير عكسيًّا).

**الجسيمات** (`UniqueCardPsEffect`، ثلاث نسخ): `startLifetime` 1.75–2.0 · `startSpeed` 2.0–8.0 ·
`startColor` نطاق ذهبيّ دافئ · تدرّج ألفا 1→0 · `ColorBySpeedModule` **معطَّل**.

## ٤. ثيمات الغرف

> 🛑 **تصحيح مهمّ**: داخل الغرفة الرسم يعتمد متغيّر **الغرفة `rTheme`** لا متغيّر المستخدم `r`.
> `r` تفضيل يُرسَل للخادم الذي يضع `rTheme` على الغرفة.

`RoomThemeChanged` @`0x4F9F080` (880B) ✅:
```
1) rst موجود ⇒ SportTeamRoomTheme.SetRoomTheme(team) ؛ انتهى
2) sprite = RoomThemesSprites.GetRoomTheme(isFastTrack, ftLevel, isTutorial)
   إن وُجد ⇒ roomTheme.sprite = sprite ؛ انتهى
3) HasTheme(room) ⇒ LoadItemImage(roomTheme, id, (ItemImageType)IsTablet(), …)
4) الاحتياطي ⇒ DOFadeChildren(roomTheme, 0f → 0.3f)
```

> ⚠️ **اختيار الهاتف/التابلت يحوّل `bool` مباشرةً إلى الـenum** (`mov x2, x21`) ⇒
> **`InGame = 0` و`InGameLandscape = 1` يجب أن تبقيا بهذا الترتيب** وإلا انكسر الاختيار.

### ⭐ ماذا يتغيّر بالضبط؟

**صورة واحدة فقط**: `roomTheme` (`Image` @`0x28`).
* `background` @`0x20` **لا يتغيّر** — خلفية ثابتة من المشهد.
* `dimmingLayer` @`0x30` طبقة تعتيم مستقلّة.
* **جوخ الطاولة والحدود وخانات الورق لا تتغيّر برمجيًّا** — كلها جزء من صورة الثيم الواحدة أو
  ثابتة في المشهد. (رصد سلبيّ صارم: لا مكوّن يبدّل sprite أيًّا منها استجابةً لـ`rTheme`.)
* العناصر المتحرّكة تُضاف **فوقها** كأبناء لـ`AnimatedElementsParent`.

`RoomThemesSprites` يحوي **ثلاثة حقول فقط**: `FastTrackLevel1` · `FastTrackLevel2` · `Tutorial`.
والهاتف/التابلت **أصلان منفصلان** يُسنَد أحدهما في كل مشهد 🟡.

### ثيم الفريق الرياضي — أوضح نقطة حقن لونيّ ✅

```csharp
// SportTeamRoomTheme.SetRoomTheme @0x4F7EB44 (612B)
roomTheme.sprite = BackGround;
layerOne.sprite  = PrimaryColor;    // قناع رماديّ
layerOne.color   = ColorUtility.TryParseHtmlString(team.colorOne, out c) ? c : Color.white;
layerTwo.sprite  = SecondaryColor;
layerTwo.color   = …team.colorTwo…
```
> **صورتان قناعيّتان تُلوَّنان بلونين قادمين من الخادم كنصّ `#RRGGBB`.**
>
> ⭐ **نفس النمط يتكرّر في [محرّر شعار العشيرة](../social-spec/05-محرر-شعار-العشيرة.md)**:
> كل عنصر شعار له صورتان `Main` و`Mask`، والقناع وحده يُلوَّن، واللوحة تأتي من
> `RemoteConfig.Current.Clans.EmblemColorPresets`. ⇒ **«قناع رماديّ + لون من الخادم» هو
> النمط المعياريّ للتلوين في هذا التطبيق كلّه** — اعتمده في نسختك.

## ٨. ⭐ أقصر طريق لإعادة التلوين

1. **استبدل `Kammelna Theme` بألوانك الثمانية** ⇒ ~١١٠٧ عنصر يُعاد صبغه بلا سطر كود.
2. أنشئ نظيرَي `Monthly Tournaments` و`Official Championship`، و**احذف `STC Theme`**.
3. **حافظ على ترتيب `PaletteColor` (0..7)** — جدول القفز معتمد عليه حرفيًّا.
4. **حافظ على `InGame = 0` و`InGameLandscape = 1`** — التفريع يحوّل `bool` مباشرةً.
5. استبدل `items/{id}_InGame` و`_InGameLandscape` على الخادم، **وحدِّث `lastModified`** فقط.
6. أعد تصميم `Pattern_*.mat` (فتحة `_Effect`، `_Size` 1044×493، `_EffectAlpha` 1.1).
7. للأظهر الفريدة: `_BorderColor`/`_GlowColor` في `Shine.mat` و`startColor` في الجسيمات.
8. **تذكّر: الصبغة لا تُزاح برمجيًّا** — الهوية من اللوحات والصور حصرًا.

   وفيها أخطر تصحيح: 🛑 **`ThemeColorPaletteToggler` معكوس** — `SetAlternative`(مُشغَّل) يقرأ `offColor` والعكس؛
   من يعيد بناء المُسبَقات بأسماء الحقول سيقلب ألوان كلّ تبويب. و`CardbackUIElement` **لا يلمس لونًا** (غلاف اختيار).
   و`TournamentCardRoomThemeSetter.defaultColor = #B29A80` مخبوز في ٦ مُسبَقات وهو حرفيًّا `Primary`.

## ⚖️ ترخيص

لم يُستخرَج أي عمل فنّي نقطيّ — التوثيق وظيفيّ بحت.
**ألوان `SportTeam`** تمثّل أندية حقيقية (ملكية للغير)، و**`STC Theme`** علامة راعٍ،
و**الخطوط العربية** تحتاج ترخيصك المستقلّ.
